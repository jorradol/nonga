## 5. Kill Switch Verification Contract

อนาคตต้อง verify kill switch แบบปลอดภัย — **v6.4U does not execute kill switch verification**

| Requirement | Contract |
|-------------|----------|
| Default state | kill switch must default to OFF / provider disabled state |
| Pre-network block | kill switch can block next provider request before network |
| Fallback | kill switch can force deterministic fallback |
| No raw data exposure | kill switch must not expose raw data |
| No secret printing | kill switch must not require printing secret/env |
| No business mutation | kill switch must not mutate lead/payment/reveal/outcome |
| Owner control | kill switch must be owner-controlled |
| Reversibility | kill switch must be reversible only by explicit approval |
| Metadata representation | kill switch state must be represented as metadata only |
| Fail closed | if kill switch state is unknown, system must fail closed |

**v6.4U note:** ไม่มีการ execute kill switch จริงใน slice นี้ — contract เป็น plan only
