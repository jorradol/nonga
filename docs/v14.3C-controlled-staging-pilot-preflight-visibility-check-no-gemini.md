## 8) Stop/HOLD rules for v14.3C visibility slice

Stop immediately and set HOLD when any condition occurs:

- required visibility field missing from static packet
- evidence field exists but meaning is ambiguous for owner decision
- wording implies pilot/public/production/real-lead already active

- wording suggests retry or second run is allowed
- synthetic/sanitized-only boundary is missing
- no-real-data or no-PII boundary is missing

- static validator test failure

No progression to pilot dry-run planning packet is allowed until all HOLD conditions are closed.
