## 5. Preview Gates (Default-Deny)

Preview แสดงเมื่อ **ทุกเงื่อนไข** เป็นจริง (v6.3B.2):

| Gate ID | Condition | Default |
|---------|-----------|---------|
| PG-01 | `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED === "true"` | **false** |
| PG-02 | Staging hostname (`a.nongbot.org` or project `nonga-ce93c`) | deny on prod domain |
| PG-03 | **Signed-in** Firebase Auth session | required |
| PG-04 | **Allowlisted** UID (reuse v6.1L allowlist pattern — server env list mirrored at build for staging only) | required |
| PG-05 | Helper `guardPass === true` OR safe fallback path | no unsafe preview text |

**Guest path:** แม้ PG-01/02 ผ่าน — **PG-03/04 fail → ไม่แสดง preview**

## 8. Guardrails & Fallback UX

### 8.1 Inherited from v6.3B helper

- `buildBuyerFriendlyListingCopy()` — deterministic/template-only
- Seller overclaim policy: **soften + omit** ("ไม่เคยชน", "ไมล์แท้", "ประหยัดแน่นอน", "รับประกัน")
- Safety disclaimer: `BUYER_FRIENDLY_SAFETY_DISCLAIMER`

### 8.2 UI fallback (v6.3B.2)

| Helper result | UI behavior |
|---------------|-------------|
| `source: "empty"` | Hide preview panel |
| `guardPass: true` | Show preview via `ListingDescription` |
| `guardPass: false` | Show banner "ใช้ข้อความต้นฉบับ — preview ไม่พร้อม" — **no rewritten text** |
| `warnings` includes `seller-overclaim-omitted` | Small badge "ข้อความฟันธงจากผู้ขายถูกลดน้ำหนัก" |

### 8.3 Privacy prohibited in preview output

ห้ามปรากฏ: `licensePlate`, wholesale/internal price, phone, LINE, UID, secret, raw image URL

### 8.4 Unsupported claim guard (preview output)

ห้ามสร้าง/amplify: ไม่เคยชน, ไมล์แท้, ประหยัดแน่นอน, km/l, รับประกัน/warranty, ฟรีดาวน์
