## 5. Mock vs Live Verdict

| Subsystem | Verdict | Evidence |
|-----------|---------|----------|
| **v6.4C `AiControlStatusPanel`** | **Read-only / OFF / safe** | Static `aiControlDefaults.ts` — no writes |
| **Analytics metrics deck** | **MOCK / placeholder** | Hardcoded `99.82%`, `1.28s`, `74.2%`, `1,480`, `8,420/10,000`, moderation counts |
| **`LIVE SYNC` badge** | **MOCK / misleading** | CSS pulse only — no sync service |
| **`Gemini 3.5 Flash` label** | **MOCK / misleading** | String in JSX — no Gemini client |
| **Fine-Tuning pipeline UI** | **MOCK / future-ready** | Static progress bar width `84.2%` |
| **Prompt sandbox (`handleSimulatePrompt`)** | **MOCK local compile** | `setTimeout` string assembly — no API |
| **Config CRUD (prompts/personas/moods/…)** | **LIVE persistence layer** | Firestore + localStorage writes on save/delete — **not connected to real Gemini runtime** |
| **`AISkillControlCenter` evaluate** | **LIVE local rule engine** | `evaluateAndChainSkills` — keyword/sentiment matching — **no LLM call** |
| **Real Gemini provider** | **NOT ENABLED** | Consistent with v6.4C.A — provider OFF |

**Overall legacy verdict:** **Hybrid mock dashboard + real admin config persistence** — ห้ามตีความว่า Gemini/fine-tuning/analytics ทำงานจริง

## 6. Risks

| ID | Risk | Severity |
|----|------|----------|
| R-01 | **Disclosure gap** — `LIVE SYNC` + Gemini + % metrics ทำให้ admin เข้าใจว่า AI production live | **High** |
| R-02 | **Cognitive dissonance** — panel ใหม่บอก OFF แต่ legacy ด้านล่างมี write UI + “live” copy | **High** |
| R-03 | **Ungated Firestore writes** — admin save ลง `ai_*` collections โดยไม่ผ่าน v6.4B control plane / kill switch | **Medium** |
| R-04 | **localStorage side effects** — config ถูก cache ใน browser โดยไม่มี disclosure | **Medium** |
| R-05 | **Nested skill module** — `AISkillControlCenter` เพิ่ม CRUD + sandbox อีกชั้น — audit surface กว้าง | **Medium** |
| R-06 | **Prompt templates in repo** — `INITIAL_PROMPTS` มี instruction text — ไม่ใช่ runtime leak แต่ต้อง guard ใน future audit | **Low** |
| R-07 | **No linkage to v6.4C OFF state** — legacy แสดงและเขียนได้ไม่ว่า provider OFF | **High** |

## 7. Recommendations

### 7.1 Disclosure labels (propose — UI change = separate slice)

| Location | Proposed label |
|----------|----------------|
| Legacy header (`Enterprise Co-Pilot Core` / `LIVE SYNC`) | **`Demo / Not connected`** — แทน `LIVE SYNC` |
| Analytics tab title | **`Mock analytics — no live data source`** |
| Each metric card | **`Placeholder`** badge |
| `Gemini 3.5 Flash Core Speed` footnote | **`Not connected — no Gemini runtime`** |
| Fine-Tuning block | คง **`Future-ready`** + เพิ่ม **`Not connected`** |
| Memory profiles footnote | แก้ copy ที่อ้าง `localStorage + FireStore` ให้ชัดว่าเป็น **admin config cache only** |
| Before write buttons | **`Config draft — does not enable real AI`** banner |

### 7.2 Hide / disable / write-protect (propose)

| Action | Target |
|--------|--------|
| **Hide by default** | Analytics tab ทั้งหมด จนกว่า v6.4D+ mock provider harness พร้อม |
| **Collapse** | `AIControlCenter` ทั้งก้อนใต้ accordion “Legacy admin config (demo)” |
| **Write-protect** | ปิด save/delete เมื่อ `DEFAULT_AI_PROVIDER_STATUS === "OFF"` (v6.4B gate) |
| **Superadmin-only** | พิจารณาย้าย legacy CRUD ให้ superadmin เท่านั้น (admin = read-only อย่าง panel ใหม่) |
| **Disable** | `รีบูตประสาทวิทยา` / `สร้างคอนฟิกใหม่` จนกว่า audit remediation slice อนุมัติ |

### 7.3 Keep as future control modules

| Module | Keep? | Reason |
|--------|-------|--------|
| Prompt templates registry | ✅ concept | Align กับ v6.4B prompt boundary |
| Personality / mood presets | ✅ concept | Future mock provider personas |
| Rules / phrases guards | ✅ concept | Output guard readiness |
| Workflows / skills registry | ⚠️ partial | ต้อง reconcile กับ v6.4B surface registry |
| Analytics mock deck | ❌ hide | ไม่มี data source — misleading |

## 8. Future Consolidation with v6.4C Panel

### Target architecture (future slices — not v6.4C.1)

```text
ai-control tab (single authority)
  ├─ AiControlStatusPanel (v6.4C)     ← always visible, authoritative OFF/readiness
  ├─ [optional] SmartSales preview      ← superadmin, read-only
  └─ Legacy config (v6.4C.2+)         ← disclosed, gated, or hidden
        ├─ Mock/Demo banner mandatory
        ├─ Write actions gated by v6.4B effective status
        └─ Analytics tab removed or replaced with real telemetry (v6.4D+)
```

| Phase | Slice | Goal |
|-------|-------|------|
| **v6.4C.1** (this) | Audit doc + static test | Map risks — **no UI change** |
| **v6.4C.2** (proposed) | Disclosure UI remediation | Mock/Demo/Not connected labels + hide analytics |
| **v6.4D** | Mock provider harness | Wire mock runtime under v6.4B gates |
| **v6.4E** | Staging real Gemini pilot | Separate approval — never from legacy dashboard |

### Consolidation principles

1. **v6.4C panel = single source of truth** สำหรับ provider OFF / staging-only / forbidden production
2. Legacy ต้อง **ไม่ขัด** panel ใหม่ — ถ้า OFF ต้องไม่มี “live” copy หรือ ungated writes
3. ทุก metric ต้องมี **named source** หรือถูกลบ
4. Config persistence ต้องผ่าน **v6.4B role matrix + audit event** ในอนาคต
