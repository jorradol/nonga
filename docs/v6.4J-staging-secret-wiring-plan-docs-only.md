## 3. Future Secret Boundary

ขอบเขต secret ในอนาคต — **v6.4J ไม่สร้างหรืออ่าน secret จริง**:

| Rule | Requirement |
|------|-------------|
| SM path only | Secret must exist only in approved Secret Manager path |
| No commit | Secret value must never be committed |
| No docs/tests/logs copy | Secret value must never appear in docs/tests/logs |
| Staging first | Secret must be staging-scoped before any production consideration |
| Least privilege | Secret access must be least privilege (IAM review required) |
| Rotation owner | Secret rotation owner must be identified before wiring |
| Rollback path | Secret rollback/removal path must be documented |
| Blocked until gates | Secret use blocked unless owner approval, allowlist, cap, kill switch, redaction, deploy approval pass |

### Approved resource-name placeholder (non-secret only)

**This is a non-secret resource-name placeholder only — not a real path, not a secret value:**

```
projects/<approved-staging-project>/secrets/<approved-gemini-staging-secret>
```

Logical env var name (reference only, not a value): `GEMINI_API_KEY`  
SM resource alias (v6.4F alignment): `gemini-api-key` — version selector: `latest`

**Forbidden in v6.4J:** API keys, tokens, `AIza...`, `sk-...`, env dumps, values that resemble real credentials

## 4. Approval Gates Before Future Secret Wiring

ก่อน wire secret ในอนาคต (post v6.4J) ต้องผ่าน **ทุก gate** — approval แยก:

| # | Gate | Required Evidence | Pass Criteria | Blocker if Missing | Owner / Approval |
|---|------|-------------------|---------------|-------------------|------------------|
| SW-01 | **Owner approval for secret wiring** | Signed owner record (out-of-band) | Owner approves staging secret wiring | No approval → **STOP** | Owner |
| SW-02 | **Staging-only environment** | `environment === "staging"` | Production forbidden | Production → **HARD BLOCK** | Owner + ops |
| SW-03 | **Approved Secret Manager resource path** | Placeholder path reviewed + project confirmed | Path matches approved staging project | Unapproved path → **BLOCK** | Owner + ops |
| SW-04 | **IAM least-privilege review** | IAM binding scope documented | Minimal SA access only | Over-broad IAM → **BLOCK** | Ops + security |
| SW-05 | **No env dump/logging policy** | Policy: never log env values | No env dump in logs | Env dump risk → **STOP** | Engineering |
| SW-06 | **No raw prompt / PII logging policy** | Redacted audit schema | No full UID / raw prompt | PII in logs → **STOP** | Engineering + owner |
| SW-07 | **Redaction verification** | Synthetic fixture redaction test pass | Redaction verified | Redaction fail → **BLOCK** | Engineering |
| SW-08 | **Cost cap confirmed** | Caps non-null and approved | Budget ceiling set | Caps unset → **BLOCK** | Superadmin |
| SW-09 | **Kill switch confirmed** | Operator named, tested OFF path | Kill switch works | No operator → **BLOCK** | Superadmin |
| SW-10 | **Allowlist confirmed** | Masked tester UIDs (out-of-band) | Allowlist configured | Missing → **BLOCK** | Superadmin |
| SW-11 | **Rollback/removal plan approved** | §8 acknowledged | Rollback owner named | No plan → **BLOCK** | Owner + ops |
| SW-12 | **Rotation plan approved** | Rotation schedule + owner | Rotation owner identified | No rotation plan → **HOLD** | Owner + ops |
| SW-13 | **Separate Cloud Run env update approval** | Explicit env update approval record | No env change without approval | Assumed auto-env → **REJECT** | Owner + ops |
| SW-14 | **Separate deploy approval** | v6.4I AP-15 / v6.4H G-15 acknowledged | Deploy approval separate | Deploy without approval → **STOP** | Owner |
| SW-15 | **Post-wiring verification plan** | Metadata-only verification steps | Verify binding without value exposure | No verification plan → **BLOCK** | Engineering |
