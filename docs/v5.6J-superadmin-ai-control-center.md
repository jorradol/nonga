# v5.6J — SuperAdmin AI Control Center / Smart Sales AI Mode Foundation

**สถานะ:** Foundation only — **ยังไม่ commit/deploy** จนกว่าลุง review  
**หลักการ:** เล็ก ปลอดภัย ไม่เปลี่ยน behavior ที่ผ่าน manual smoke แล้ว

## ทำไมต้องมี

- น้องเอเริ่มมีเส้นทางรายได้ (lead → reveal → outcome → pending sale)
- ต้องการให้ SuperAdmin **เปิด/ปิด/จำกัดพลัง AI** ตาม flow ที่สร้างรายได้
- ต้องคุมต้นทุน API และความปลอดภัยก่อนเปิด Smart Sales AI จริง

### สิ่งที่ยังไม่มี (ก่อน v5.6J)

- โมเดล `AiControlMode` + flow toggles แบบรวมศูนย์
- Persistence ค่า AI control บน Firestore/admin API
- SuperAdmin ปรับ `maxTokens` / `maxCalls` จาก UI จริง

### สิ่งที่ไม่ควรเปิดตอนนี้

- `full_ai` เป็น default
- `NONGA_AI_CONTROL_MODE=full_ai` บน staging/production
- Gemini ใน buyer lead submit / seller reveal / outcome routes
- เปิด `BUYER_LEAD_AI_TEXT_PARSE_ENABLED` โดยไม่มี cost monitor

## AI Control Model (v5.6J)

### Modes (`AiControlMode`)

| Mode | ความหมาย |
|------|----------|
| `off` | เทมเพลต/พาร์เซอร์ — ไม่ใช้ Smart Sales AI |
| `economy` | **ค่าเริ่มต้น** — เหมือน staging ปัจจุบัน |
| `balanced` | จำกัดบาง flow (foundation; ยังไม่เปิด API) |
| `smart_sales` | เฉพาะ flow รายได้ — ต้อง env + review |
| `full_ai` | ห้ามเป็น default; blocked ใน v5.6J runtime assert |

### Flow toggles (`AiFlowToggleKey`)

- `buyerChatAdvisor` — ห้าม AI แทน orchestrator ในรอบนี้
- `buyerLeadCapture` — **template only** (assert block)
- `buyerLeadTextParse` — Smart Sales parse (อนาคต)
- `priceNegotiation` — hints (อนาคต)
- `alternativeCarSuggestion` — อนาคต
- `sellerCopyAssist` — อนาคต
- `adminLeadQualityReview` — อนาคต

### Config fields

`maxTokensPerReply`, `maxAiCallsPerSession`, `maxAiCallsPerUserPerDay`, `allowLeadAiParsing`, `allowNegotiationAi`, `allowAlternativeSuggestions`, `fallbackToTemplate`, `updatedBy`, `updatedAt`

## Cost / safety guardrails

- mode missing → `economy`
- `full_ai` → blocked ใน `assertAiControlSafeForFlow`
- max tokens / calls per session & day
- `fallbackToTemplate` default `true`
- ห้าม sensitive documents / commission / finance guarantee / guaranteed sale
- ห้าม credit-risk label เช่น “ติดบูโร” ใน copy guard
- `redactPiiForAiLog` สำหรับ log foundation
- API key อยู่ server env เท่านั้น

## Rollout plan

1. **Foundation only** (v5.6J) — types, helpers, tests, docs
2. SuperAdmin read-only preview wired (review แยก)
3. `smart_sales` เฉพาะ staging + monitor
4. Cost/log dashboard
5. Pilot จำกัด dealer/member

## Rollback plan (rollback ทันทีเมื่อต้องการ)

1. ตั้ง `NONGA_AI_CONTROL_MODE=off` หรือ `economy`
2. คง `BUYER_LEAD_AI_TEXT_PARSE_ENABLED=false`
3. `fallbackToTemplate=true`
4. ไม่กระทบ lead submit / reveal / pending sale / relist
