## 2. Solution

| Layer | Behavior |
|-------|----------|
| `opening` | เหตุผลคัดสรร — **ไม่เปลี่ยน** |
| **`featureWeave`** *(optional)* | 1 ย่อหน้าสั้น sales-tone จาก spec ที่ parse ได้ (~180–220 ตัวอักษร) |
| `highlights` | bullet ข้อเท็จจริง — **dedupe** description snippet เมื่อมี weave |
| `closing` | caveat ตรวจรถ/เอกสาร/ทดลองขับ — **ไม่เปลี่ยน** |

Helper ใหม่: `buildCompactInChatSalesWeave()` ใน `buyerFriendlyListingCopy.ts`  
Wire: `buildInChatCuratedAnalysis()` → `ChatCarCuratedAnalysisPanel` → TTS speakable text

## 5. Guardrails

| Guard | Mechanism |
|-------|-----------|
| Junk tokens | `isJunkSpecToken`, `sanitizeListingCopyText`, `isCorruptedMixedThaiLatinSpecLabel` |
| Garbled steering (latin-injected) | repair → `STEERING_WHEEL_MULTIFUNCTION_DISPLAY` (`พวงมาลัยมัลติฟังก์ชัน` pure Thai) or omit |
| Output corruption guard | `containsThaiLatinMixedCorruption` in `passesOutputGuard` + weave builder |
| Overclaims | `softenOmitOverclaims`, `passesOutputGuard`, `assertInChatCuratedSafe` |
| Length | max ~220 chars; trim features from end |
| Min specs | omit weave if < 2 parseable specs |
| TTS | `buildInChatCuratedSpeakableText` — visible fields only |
| Disclaimer | **ไม่ซ้ำ** — ใช้ `closing` เดิม |
