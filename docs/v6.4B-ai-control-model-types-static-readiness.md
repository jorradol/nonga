## 1. Vision & Scope

### เป้าหมาย

แปลง readiness จาก v6.4A ให้เป็น **model/types/static guard ในโค้ด** เพื่อเตรียมสร้าง AI control plane ในอนาคต โดย:

- default provider status = **OFF**
- production real provider = **forbidden**
- Admin ห้ามเปิด real provider
- ทุก surface default = **DETERMINISTIC_ONLY**
- audit event redacted only
- ยังไม่ persist, ยังไม่ wire runtime

### v6.4B ทำอะไร / ไม่ทำอะไร

| ทำ (รอบนี้) | ไม่ทำ (รอบนี้) |
|-------------|----------------|
| `aiControlTypes.ts` | Deploy / env update |
| `aiControlDefaults.ts` + static guards | เรียก Gemini API |
| Static test script | Provider runtime + network |
| Readiness doc | Admin UI จริง |
| package script | DB persist |
| | production touch |

## 4. Environment Guard

| Rule | Static guard |
|------|--------------|
| production real provider | `isProductionRealProviderForbidden()` → **true** |
| STAGING_REAL allowed | `isStagingRealProviderAllowed()` — requires staging + approval + allowlist + caps + kill switch off |
