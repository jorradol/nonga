## 7) Pilot preflight PASS/HOLD matrix

### 7.1 PASS

PASS means:

- staging-only route/config boundary is clear
- owner-admin gate assumptions are explicit
- synthetic-sanitized only pilot scope is explicit
- marker requirements are complete
- one-run approval/lock/no-retry controls are complete
- stop/HOLD rules are complete

PASS is not permission to execute runtime, not permission to open public/production, and not permission to send real lead.

### 7.2 HOLD

HOLD if any condition occurs:

- route/auth gate ambiguity
- missing or inconsistent required markers
- public/production exposure risk
- real lead path risk
- secret/PII risk
- missing one-run control requirements
- test failure

## 8) Stop conditions

Stop immediately and set HOLD when:

- `/api/**` rewrite does not map to staging service as expected
- owner/admin gate assumptions cannot be confirmed from read-only config
- any config indicates production/public activation risk
- any doc/fixture includes sensitive data pattern (secret, token, phone, plate, VIN, email)
- required marker or runSessionLocked requirement is missing

No progression to pilot execution is allowed under HOLD.
