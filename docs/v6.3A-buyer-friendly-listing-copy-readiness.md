## 1. Problem Statement

ผู้ขายบางรายกรอก **รายละเอียดรถ** (`description`) เป็นภาษาวงการรถ ข้อความสั้น ๆ หรือสเปกดิบ (เช่น `บ.+จอ+ฝาท้าย`) ทำให้ **ผู้ซื้อทั่วไป** อ่านเข้าใจยากและไม่เห็นจุดเด่นของรถอย่างชัดเจน

ปัจจุบันระบบแสดงผลรายละเอียดผ่าน `formatListingDescription` — **จัด typography เท่านั้น ไม่ rewrite เนื้อหา** — ดังนั้นข้อความที่ผู้ขายกรอกมาแบบสั้นหรือเทคนิคจะถูกส่งต่อไปยังผู้ซื้อโดยตรง

| Symptom | Impact |
|---------|--------|
| สเปกดิบ / คำย่อวงการรถ | ผู้ซื้อทั่วไปไม่เข้าใจคุณค่า |
| ข้อความสั้น ไม่มีบริบท | ลดความน่าเชื่อถือและ conversion |
| ไม่มีโครงสร้างจุดเด่น | ยากต่อการเปรียบเทียบรถหลายคัน |
| ภาษาขายเกินจริง (จากผู้ขาย) | เสี่ยงเข้าใจผิด — ต้องมี guard ไม่ให้ระบบขยาย overclaim |

## 5. Forbidden Transformations

ห้ามทำการเปลี่ยนแปลงดังต่อไปนี้:

| Forbidden ID | Rule | Reason |
|--------------|------|--------|
| FT-01 | **แต่งสเปกที่ไม่มี** | สร้างข้อมูลใหม่ |
| FT-02 | **สร้างตัวเลข km/l** | ไม่มีแหล่งข้อมูลยืนยัน |
| FT-03 | **บอก "ไม่เคยชน"** ถ้าไม่มีข้อมูล | unsupported claim |
| FT-04 | **บอก "ไมล์แท้"** ถ้าไม่มีหลักฐาน | unsupported claim |
| FT-05 | **บอก "ประหยัดแน่นอน"** | overclaim / ฟันธง |
| FT-06 | **บอก "สภาพนางฟ้า"** แบบเกินจริง | overclaim |
| FT-07 | **เพิ่ม warranty / รับประกัน / ฟรีดาวน์ / ผ่อนเท่าไหร่** ถ้าข้อมูลไม่มี | สร้างข้อมูลการเงิน |
| FT-08 | **ใช้ plate, wholesale, phone, LINE, UID** | privacy leak |
| FT-09 | **ใช้ raw image URL, address, secret** | privacy / security |
| FT-10 | **ดึง hidden/internal fields มาเขียน** | data boundary violation |
| FT-11 | **ลบข้อมูลสำคัญที่ผู้ขายระบุ** | ลดความครบถ้วน |
| FT-12 | **เปลี่ยนราคา / ไมล์ / ปี / ยี่ห้อ / รุ่น** | ข้อมูล structured ต้องมาจาก field จริง |

### Privacy prohibited fields (ห้ามปรากฏใน output)

| Field | Rule |
|-------|------|
| `licensePlate` / ป้ายทะเบียนเต็ม | ❌ internal-only — public **0** |
| wholesale / internal price | ❌ excluded from public |
| `ownerPhone` / เบอร์โทร | ❌ forbidden in public copy |
| LINE ID / @line | ❌ forbidden |
| raw UID / Firebase UID | ❌ forbidden |
| raw image URL (Drive/Storage direct) | ❌ forbidden in copy text |
| full address | ❌ forbidden — province-level only if from public field |
| secret / API key / env value | ❌ forbidden |

### Unsupported claim guard (ห้ามสร้างใน output)

| Claim pattern | Action |
|---------------|--------|
| ไม่เคยชน / ไม่เคยทำสี / ไม่เคยชนหนัก | **block** unless explicit in source |
| ไมล์แท้ / ไมล์แท้ 100% | **block** unless explicit + evidence flag |
| ประหยัดแน่นอน / ประหยัดมาก | **block** — use soft wording only |
| km/l / กิโลลitre ต่อลitre | **block** unless explicit in source |
| รับประกัน / warranty / ฟรีดาวน์ | **block** unless explicit in source |
| สภาพนางฟ้า / สภาพป้ายแดง | **soften or block** — avoid absolute |

## 6. Safety Copy Principles

| Principle ID | Rule |
|--------------|------|
| SP-01 | ใช้คำว่า **"จากข้อมูลประกาศ"** เมื่ออธิบายจุดเด่น |
| SP-02 | ใช้ **"เหมาะสำหรับผู้ที่มองหา…"** แทนการฟันธง |
| SP-03 | ใช้ **"ควรตรวจสอบสภาพรถจริงก่อนตัดสินใจ"** ใน closing |
| SP-04 | **หลีกเลี่ยงคำฟันธง** — ไม่ใช้ "แน่นอน" "100%" "รับประกัน" โดยไม่มีหลักฐาน |
| SP-05 | **ไม่แทนที่ structured fields** — ราคา/ไมล์/ปี แสดงจาก field ไม่ใช่แค่ description |
| SP-06 | **tone ภาษาไทยสุภาพ** — ไม่โอเวอร์ ไม่ aggressive sales |
| SP-07 | **fallback ปลอดภัย** — ถ้า guard fail → แสดงต้นฉบับ + disclaimer |
| SP-08 | **seller review gate (อนาคต)** — ผู้ขาย preview/approve ก่อน publish (optional slice) |

### Safety copy templates (generic — ไม่ใช้ข้อมูลรถจริง)

```text
จากข้อมูลประกาศ รถคันนี้มีจุดเด่นด้าน [category] ตามที่ผู้ขายระบุ
เหมาะสำหรับผู้ที่มองหา [use-case] ตามสเปกที่แจ้ง
ควรตรวจสอบสภาพรถจริง เอกสาร และทดลองขับก่อนตัดสินใจซื้อ
```

## 7. Data Boundary

### Public-safe sources (อนุญาตใช้เป็น input)

| Source ID | Field / Data | Notes |
|-----------|--------------|-------|
| PS-01 | `description` (seller text) | primary input |
| PS-02 | `brand`, `model`, `year` | structured identity |
| PS-03 | `price`, `mileage`, `color`, `fuelType` | structured specs |
| PS-04 | `condition` | soft wording only — no warranty |
| PS-05 | `features[]`, `tags[]` | bullet source |
| PS-06 | `transmission`, `drivetrain`, `bodyType` | if public on listing |
| PS-07 | `province` | location level — not full address |
| PS-08 | `sellerType` (private/dealer) | context only |
| PS-09 | `showroomName` | public dealer name if shown |

### Internal-only / forbidden sources (ห้ามใช้)

| Source ID | Field / Data | Rule |
|-----------|--------------|------|
| IF-01 | `licensePlate` | internal-only masked — public **0** |
| IF-02 | wholesale / dealer cost / internal price | excluded from public |
| IF-03 | `ownerPhone`, `ownerId` | never in copy |
| IF-04 | LINE / social contact raw | never in copy |
| IF-05 | raw UID / session id | never in copy |
| IF-06 | raw image URL / storage path | never in copy text |
| IF-07 | full address | never in copy |
| IF-08 | admin/moderation fields | hidden |
| IF-09 | lead/payment/reveal/outcome data | separate flow — not input |
| IF-10 | secret / env / API key | never |

### Output boundary

| Rule | Description |
|------|-------------|
| OB-01 | Output เป็น **buyer-facing text** เท่านั้น — ไม่มี PII |
| OB-02 | Output **ไม่แทนที่** structured fields ใน database (future: optional `buyerFriendlyDescription` field แยก) |
| OB-03 | Original `description` **คงไว้** — rewrite เป็น derived view |
| OB-04 | Logs **ไม่เก็บ** raw prompt/PII/secret |
