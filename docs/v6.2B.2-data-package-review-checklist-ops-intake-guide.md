## 1. Vision & Scope

### เป้าหมาย v6.2B.2 (ops guide slice)

สร้าง **Data Package Review Checklist / Ops Intake Guide** สำหรับทีมตรวจ data package รถจริง 5–10 คัน ก่อน import เข้า staging controlled pilot:

- กำหนด **intake workflow** — รับ package ผ่านช่องทางปลอดภัย, review นอก repo
- กำหนด **rights/consent checklist**
- กำหนด **PII/forbidden data review**
- กำหนด **vehicle data quality review**
- กำหนด **stale listing review**
- กำหนด **AI grounding readiness review**
- กำหนด **go/no-go decision** + reviewer sign-off
- **Docs/tests/package only** — ไม่ runtime, ไม่ deploy, ไม่ import

### สิ่งที่ v6.2B.2 **ไม่ใช่**

| Item | v6.2B.2 status |
|------|----------------|
| Real stock import | ❌ **blocked** |
| ข้อมูลรถจริงใน repo | ❌ **forbidden** |

## 2. Intake Workflow

### 2.1 รับ data package

| Step | Action | Owner |
|------|--------|-------|
| IW-01 | รับ data package จาก **ลุง/เต็นท์รถ** ผ่าน **ช่องทางที่ปลอดภัย** (ops secure channel) | ops |
| IW-02 | ยืนยัน batch size **5–10 คัน** | ops |
| IW-03 | บันทึกวันที่รับ package + ผู้ส่ง (masked ref — ไม่ใส่ git) | ops |
| IW-04 | **ห้าม commit raw real data เข้า repo** | eng + ops |
| IW-05 | **ห้ามส่งข้อมูลลูกค้าจริง** ใน git / public channel | all |
| IW-06 | ตรวจ package **นอก repo** ก่อน — secure storage / ops workstation | ops |
| IW-07 | **Review data package ก่อน — ไม่ใช่ import ทันที** | ops + product |

### 2.2 Secure channel rules

| Rule | Detail |
|------|--------|
| Real data location | ops secure storage / encrypted share — **never git** |
| Git repo | placeholder template only (`v6.2B.1`) |
| Slack/public chat | ห้าม paste PII, รูปจริง, manifest จริง |
| Review record | masked summary in ops channel — no raw data |

### 2.3 Workflow diagram

```
ลุง/เต็นท์รถ → secure channel → ops intake → review checklist (§3–§7)
    → go/no-go (§8) → reviewer sign-off → approval phrase (§9)
    → v6.2B.3+ import execution (separate slice)
```

**v6.2B.2 stops at review + sign-off — not import**

## 3. Rights and Consent Checklist

ทุกคันใน batch ต้องผ่าน checklist นี้:

| # | Item | Pass criteria | Reviewer | Date/time |
|---|------|---------------|----------|-----------|
| RC-01 | เจ้าของข้อมูล/ผู้ขาย/ดีลเลอร์อนุญาตให้ใช้ประกาศ | written consent on file | ☐ | |
| RC-02 | สิทธิ์ใช้รูป | image rights confirmed | ☐ | |
| RC-03 | รูปไม่ได้คัดลอกจากแหล่งที่ไม่มีสิทธิ์ | no third-party infringement | ☐ | |
| RC-04 | seller consent ครบทุกคัน | `sellerConsent=true` per car | ☐ | |
| RC-05 | imageRightsConfirmed ครบทุกคัน | per v6.2B.1 consent flags | ☐ | |
| RC-06 | ระบุคนรับผิดชอบ review | named reviewer (ops channel) | ☐ | |
| RC-07 | ระบุวันเวลาที่ review | ISO8601 timestamp (ops record) | ☐ | |

**Batch-level sign-off:** reviewer name + date ใน ops record — **ไม่ใส่ git**

## 4. PII and Forbidden Data Review

### 4.1 Text/data fields — must NOT appear in import package

| # | Forbidden item | Action if found |
|---|----------------|-----------------|
| PII-01 | เบอร์โทรจริง | **NO-GO** — remove or reject car |
| PII-02 | ชื่อเจ้าของจริง | **NO-GO** — use sellerDisplayName non-PII only |
| PII-03 | LINE ID จริง | **NO-GO** |
| PII-04 | ที่อยู่จริง (บ้านเลขที่/ซอย) | **NO-GO** — province only |
| PII-05 | เลขทะเบียนเต็ม | **NO-GO** — mask or omit |
| PII-06 | UID จริง (Firebase etc.) | **NO-GO** |
| PII-07 | prompt จริง | **NO-GO** |
| PII-08 | secret / env dump | **NO-GO** — incident if in package |
| PII-09 | เอกสาร / บัตร / ใบเล่ม / สัญญา / หลักฐานการเงิน | **NO-GO** |
| PII-10 | customer data จริง (buyer phone/name) | **NO-GO** |

### 4.2 Image review — must NOT appear in photos

**รูปที่มีเบอร์/LINE/ที่อยู่/เอกสาร — reject หรือ blur ก่อนใช้**

| # | Forbidden in image | Action |
|---|-------------------|--------|
| IMG-01 | เบอร์โทร / LINE / QR contact | reject or blur |
| IMG-02 | ที่อยู่ในรูป/เอกสาร | reject or crop |
| IMG-03 | บัตรประชาชน / ใบเล่ม / เอกสารทะเบียน | **reject** |
| IMG-04 | สัญญา / หลักฐานการเงิน | **reject** |
| IMG-05 | ป้ายทะเบียนอ่านได้ | mask before use |

### 4.3 PII scan checklist (per car)

| # | Check | Pass |
|---|-------|------|
| PS-01 | Text scan — no phone patterns | ☐ |
| PS-02 | Text scan — no LINE patterns | ☐ |
| PS-03 | Text scan — no full address | ☐ |
| PS-04 | Image visual scan — no docs/ID | ☐ |
| PS-05 | `piiReviewed=true` in consent flags | ☐ |

## 5. Vehicle Data Quality Review

ทุกคันต้องผ่าน checklist ตาม v6.2B.1 schema:

| # | Field | Required | Pass criteria |
|---|-------|----------|---------------|
| DQ-01 | make / model / year / trim | ✅ | valid canonical values |
| DQ-02 | price | ✅ | > 0 THB, current |
| DQ-03 | mileage | preferred | present or flagged for AI "ข้อมูลประกาศยังไม่พอ" |
| DQ-04 | transmission | preferred | auto / manual / CVT |
| DQ-05 | fuel | preferred | petrol / diesel / hybrid / EV |
| DQ-06 | color | preferred | no PII embedded |
| DQ-07 | province | ✅ | province only — not full address |
| DQ-08 | photos | ✅ min 3 | sanitized, rights OK, match car |
| DQ-09 | highlights | preferred | sanitized text |
| DQ-10 | check notes | optional | caveats e.g. ต้องตรวจสภาพจริง |
| DQ-11 | listing status | ✅ | `available` at review time |
| DQ-12 | sourceUpdatedAt | preferred | recent timestamp |
| DQ-13 | sellerDisplayName | ✅ | **non-PII** label only |

**Batch:** 5–10 cars max — reject overflow

| SL-03 | ราคาเป็นปัจจุบัน | price verified within 24h of review |

| SL-07 | มีวิธี delist/hide batch | rollback procedure confirmed (v6.2B §6) |
| SL-08 | `staleChecked=true` in consent flags | per car |

## 7. AI Grounding Readiness Review

ก่อน import ต้องยืนยันว่า AI path พร้อมตอบจากข้อมูลประกาศจริง:

| # | Check | Pass criteria |
|---|-------|---------------|
| AG-01 | ข้อมูลครบพอสำหรับ search (make/model/price/province) | per car |
| AG-02 | ไม่มี field ที่จะทำให้ AI hallucinate | no guessed mileage/specs |
| AG-03 | missing fields flagged | AI จะตอบ "ข้อมูลประกาศยังไม่พอ" |
| AG-04 | ห้าม overpromise copy in highlights | no guarantee language |
| AG-05 | compare/refine จะใช้ carCards จาก listing จริง | staging allowlist only |
| AG-06 | guest/non-allowlisted ยัง legacy 100% | unchanged |
| AG-07 | user-visible path ยัง mock only | no real Gemini user-visible |
| AG-08 | `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` | **`false`** |

## 8. Import Go / No-go Decision

### 8.1 GO — อนุญาตให้ขอ approval phrase (not import yet)

**GO ได้เฉพาะเมื่อ rights, consent, PII, image safety, stale, data quality, rollback พร้อมครบ**

All must be ✅:

| # | Criterion |
|---|-----------|
| GO-01 | Intake workflow §2 complete |
| GO-02 | Rights/consent §3 — all RC items pass |
| GO-03 | PII review §4 — all cars pass, `piiReviewed=true` |
| GO-04 | Image safety — no forbidden images |
| GO-05 | Data quality §5 — all DQ required fields pass |
| GO-06 | Stale listing §6 — all SL items pass, `staleChecked=true` |
| GO-07 | AI grounding readiness §7 pass |
| GO-08 | Rollback ready — `rollbackReady=true`, delist/hide batch documented |
| GO-09 | Batch 5–10 cars |
| GO-10 | Staging only, closed pilot, allowlist only |
| GO-11 | No production / public AI / public signup |
| GO-12 | **Reviewer sign-off** recorded (ops channel) |

### 8.2 NO-GO — stop, do not request import approval

| # | Trigger |
|---|---------|
| NG-01 | PII found in data or images |
| NG-02 | สิทธิ์รูปไม่ชัด / no image rights |
| NG-03 | รถขายแล้ว / จองแล้ว |
| NG-04 | ข้อมูลไม่ครบ (required fields missing) |
| NG-05 | Rollback ไม่พร้อม |
| NG-06 | Batch > 10 or < 5 without exception approval |
| NG-07 | Raw real data attempted in git |
| NG-08 | Production touched |
| NG-09 | Public AI enabled |
| NG-10 | Real Gemini user-visible path enabled |
