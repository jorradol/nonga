# v5.6I.4c — Admin Revenue Dashboard Container Fit / No Horizontal Overflow

## ปัญหา (manual smoke)

กล่อง «รายได้ / ค่าบริการเมื่อขายสำเร็จ» ล้นขอบจอ ผู้ใช้ต้องเลื่อนแนวนอนทั้งหน้า หรือเนื้อหาถูกตัด

## Root cause

1. **Flex child ไม่มี `min-w-0`** — แท็บ revenue ใน `AdminDashboardView` ถูกดันจากตาราง `min-w-[720px]`
2. **Section revenue ไม่จำกัดความกว้าง** — ไม่มี `max-w-full` / `overflow-x-hidden` ที่ระดับ card
3. **Summary grid 2 คอลัมน์บนมือถือ** — label ยาวทำให้ cell กว้างเกิน
4. **Table wrapper** — มี `overflow-x-auto` แต่ parent ไม่มี `min-w-0` จึง scroll ทั้งหน้าแทน scroll ใน container
5. **ID / policy string** — `font-mono` ยาวไม่ wrap

## แก้ไข (frontend-only)

### AdminDashboardView

- Root + main tab area: `w-full max-w-full min-w-0 overflow-x-hidden`
- Revenue tab panel: `min-w-0 w-full max-w-full`

### AdminRevenueDashboardPreview

- Section: `w-full max-w-full min-w-0 overflow-x-hidden`, padding responsive
- Summary: `grid-cols-1 sm:2 lg:3 xl:4`, cards `min-w-0 break-words`
- Table container + wrapper: `min-w-0 max-w-full overflow-x-auto overscroll-x-contain`
- Mobile cards + long ids: `break-all` / `truncate`
- ปุ่ม «ปรับยอด» และ scroll hint คงเดิม (v5.6I.4a)

### ไม่แก้

- Settlement rules, API, payment/invoice, modal logic (v5.6I.4b ยังใช้ได้)

## Scroll ที่ตั้งใจให้มี

- **ภายใน** `admin-revenue-preview-table-wrap` เท่านั้น (desktop table)
- **ไม่มี** page-level horizontal scroll จาก revenue section

## Manual smoke checklist

1. Admin → รายได้ / ค่าบริการเมื่อขายสำเร็จ — ไม่มี horizontal scroll ทั้งหน้า
2. Summary cards stack บนมือถือ
3. ตาราง desktop scroll ภายในกล่องตาราง
4. ปุ่ม «ปรับยอด» ยังเห็นใต้ชื่อรถ / ใน mobile card
5. Modal ปรับยอด ยังไม่ล้นแนวนอน
6. ไม่มี payment gateway / invoice
