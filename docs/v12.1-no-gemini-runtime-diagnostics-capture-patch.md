## 5. Diagnostics Capture Contract

v12.1 contract requires report separation:

- `runtimeObservedStages`
- `codePathAvailableStages`
- `missingOrUnknownStages`
- `callerStatus`
- `handlerStatus`
- `providerStatus`
- `httpStatus` (if captured)
- `timeout` / `fallback` flags (if captured)
- `sanitized: true`

Expected shape (contract level):

- `runMode: "admin_shadow_manual_smoke"`
- `diagnosticSnapshotVersion: "v12.1"`
- `runtimeObservedStages`: stages observed in this runtime attempt only
- `codePathAvailableStages`: known stage vocabulary from code-path
- `missingOrUnknownStages`: `codePathAvailableStages - runtimeObservedStages`

This patch enforces that runtime-observed evidence is never inferred from code-path availability.
