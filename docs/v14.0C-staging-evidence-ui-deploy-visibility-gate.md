## 3) v14.0C diagnosis

Read-only staging check on `https://a.nongbot.org` without one-run execution showed:

1. staging page loads normally
2. unauthenticated session shows guest surface only (owner helper hidden by gate)
3. no safe pre-run readiness marker available in owner helper source before execution
4. evidence block was run-dependent, so bundle freshness could not be confirmed safely from UI without a run

Likely causes for HOLD:

- staging may still serve an older hosting bundle, or
- browser/session cache may still serve older assets, or
- render condition made evidence diagnostics visible only after one-run, or
- marker/testid gap prevented safe pre-run verification.

## 6) Safe visibility verification method (no one-run)

Use this checklist before any new owner quality retest:

1. open staging (`https://a.nongbot.org`) in owner/admin session
2. open owner helper panel
3. verify pre-run readiness marker text is visible
4. verify readiness placeholder text is visible
5. verify testids/readiness labels are visible in UI inspection tools
6. confirm one-run button has not been pressed

This confirms fresh bundle/UI readiness without triggering Gemini/provider network.
