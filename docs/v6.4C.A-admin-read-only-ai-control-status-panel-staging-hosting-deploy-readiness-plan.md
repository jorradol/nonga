## 4. Env Update Plan

v6.4C panel ใช้ **static defaults** จาก `aiControlDefaults.ts` — **ไม่ต้องเปิด env ใหม่สำหรับ AI control**

### Deploy session env policy

| Policy | Rule |
|--------|------|
| AI control panel | **No new Vite env keys** — panel reads static model at compile time |
| Staging parity | **Replicate v6.3B.6A live build env** เพื่อไม่ regression golden seller / preview |
| AI/shadow flags | **Do not change** — ห้ามเปิด shadow real provider |
| `VITE_NONGA_PUBLIC_SIGNUP_ENABLED` | คง `false` |
| Cloud Run env | **Do not touch** |
| gcloud secrets | **Do not access** |

### Keys to replicate from v6.3B.6A live (deploy session only — private UIDs)

| Key | Deploy session value | Notes |
|-----|----------------------|-------|
| `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED` | `true` | same as current live `index-CLCq6RnQ.js` |
| `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ALLOWLIST_UIDS` | approved tester UIDs (comma-separated) | **ห้าม commit** — ส่ง private channel เท่านั้น |
| `VITE_FIREBASE_*` | via `build-staging-hosting.mts` default (`nonga-ce93c`) | unchanged flow |

### Keys that must NOT change / must NOT enable

| Key | Rule |
|-----|------|
| `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` | ห้าม `true` (Cloud Run — ไม่แตะ) |
| `NONGA_AI_*` runtime flags | ห้าม env update บน Cloud Run |
| New AI control env | **ไม่เพิ่ม** ในรอบนี้ |

### Env injection (deploy session — choose one)

**Option A — `.env.staging` (gitignored)**

```env
VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED=true
VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ALLOWLIST_UIDS=<MASKED_UID_A>,<MASKED_UID_B>,...
```

**Option B — shell session env** before `npm run build:staging:hosting`

> **Note:** Allowlist UIDs inline ใน client bundle (compile-time gate) — staging-only policy; **ห้าม** ใส่ full UID ใน git/docs/report

### Panel must display (read-only)

| Section | Expected value |
|---------|----------------|
| Provider Status | `OFF` |
| Effective Status | `OFF` (kill switch inactive) |

- `<form>` submit
- `fetch` / network for AI usage
- full UID / secret / raw prompt / env dump display
