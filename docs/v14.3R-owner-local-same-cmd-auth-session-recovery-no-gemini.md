## 4) Same-CMD recovery statement (owner-friendly)

Critical clarification:

`token missing` does **not** automatically mean token value is broken.  
It usually means the token is not present in the same CMD/session that runs the checker or future one-run command.

Required same-CMD rule:

- set token and run checker in one CMD window
- do not set in window A and run checker in window B
- do not close CMD after `set` if that CMD will be used for checks

## 5) Windows CMD same-session checklist

Run in the same CMD window:

```bat
cd /d D:\nonga
set NONGA_ADMIN_API_TOKEN=<paste-token-here>
npm run check:admin-token-session-env
```

Required handling policy:

1. Use one CMD window from start to finish.
2. Keep token in-session only by default (no persistent write by default).
3. Do not run `echo %NONGA_ADMIN_API_TOKEN%`.
4. Do not screenshot token.
5. Do not paste token in chat/report.
6. Do not print full token value anywhere.
