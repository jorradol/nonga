## 1. Executive summary

v6.6O เป็น **Local-Only Execution Gate** — ขั้นสุดท้ายก่อน local-only rehearsal จริง:

- Review ว่า v6.6N approval packet พร้อมสำหรับ local-only path หรือไม่
- Audit ว่า local-only import ทำได้อย่างปลอดภัย (file backend, draft-only, no publish)
- เตรียม guarded script สำหรับรอบถัดไป (`run-thor-local-only-import-rehearsal`)
- Default script mode = **validate-only** (ไม่ import)

**v6.6O ไม่ execute import จริง** — แม้ local-only ก็ต้องขอ approval แยกหลัง Pre-Execution Report

### Deliverable choice: Option B

เลือก **Option B (docs + guarded script)** เพราะ:

- v6.6M ยืนยัน identity/partition แล้ว แต่ยังไม่มี gated path สำหรับ private CSV จริง
- Private CSV มี schema ชัด (`plannedDealerId`, `plateMasked`, `batchId`) — validate ได้โดยไม่ copy เข้า repo
- Script default = validate-only; `--confirm-local-only` ต้อง explicit — ลดความเสี่ยง accidental import
- Guards ปฏิเสธ Firestore env, publish flag, account creation flag
- Output summary อยู่ใน `.private/` เท่านั้น (gitignored)
