## เกณฑ์ผ่าน / ไม่ผ่าน

### ผ่าน (อนุญาตให้ถือว่า enablement สำเร็จ)

- S1–S16 ผ่านครบบน staging test listing
- Firestore Console: docs ใน settlement collections ไม่มี PII
- Client direct Firestore ทั้ง 4 collections = **403**
- Core flow (lead / reveal / outcome / cancel) ไม่พัง
- ไม่มี incident เปิดอยู่

### ไม่ผ่าน (ต้อง rollback ทันที)

- adjustment สร้าง audit ซ้ำเมื่อ replay requestId
- conflict fingerprint ไม่ได้ **409**
- seller เห็นยอดหรือข้อมูลของคนอื่น
- buyer phone / PII ปรากฏใน settlement หรือ admin revenue payload
- health หรือ core flow พัง
- ข้อสงสัยข้อมูล settlement ไม่สอดคล้อง

**เมื่อไม่ผ่าน:** rollback ตามด้านบน → รายงาน incident → **ห้าม** เปิด production
