## 4) Patch summary

### 4.1 Owner-only controlled gate (default-off)

- Added `NONGA_AI_OWNER_ONLY_CONTROLLED_UX_ENABLED` flag read in runtime flags.
- Gate default remains off; eligibility fails closed when flag is not enabled.
- Eligibility now requires owner role (`admin`/`superadmin`) before any provider path.
- Existing user-visible prerequisites (allowlist, staging/non-production, kill-switch, budgets, provider constraints) remain in place.

### 4.2 Guarded Gemini wording layer (safe-zone candidate only)

- Added owner-controlled candidate zone classifier:
  - natural search explanation
  - car fit reason
  - budget/location explanation
  - compare wording
  - seller listing tone polish
  - safe market-context wording
  - friendly follow-up wording
  - lucky/fun disclaimer wording
  - same-chat context-switch wording
- If message is outside safe zones, provider path is denied and deterministic response remains.

### 4.3 Deterministic risk boundary before provider dispatch

- Added deterministic boundary blocker for high-risk intents:
  - lead confirmation / consent-send
  - phone/PII and plate/VIN references
  - secret/token/api-key asks
  - production/public activation requests
  - payment/deposit safety-risk intents
  - legal/finance guarantee-risk requests
  - admin-action-sensitive patterns
  - hard off-topic recovery pattern classes
- If blocked, provider path is not dispatched.

### 4.4 Post-check + fallback deterministic

- Existing structured-output parse + safety checks remain mandatory before display.
- Unsafe output returns deterministic fallback with `real_provider_output_unsafe`.

### 4.5 No automatic retry

- Removed unsafe-output automatic retry behavior from `maybeApplyUserVisibleRealProvider`.
- Behavior is now single-attempt only; on failure it falls back deterministic immediately.
