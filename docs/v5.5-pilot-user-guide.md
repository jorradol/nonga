# Nong A — คู่มือผู้ทดลอง (Closed Pilot)

คู่มือสั้นสำหรับผู้ที่ **ได้รับเชิญ** เท่านั้น — ระบบยัง **ไม่เปิดสมัครสมาชิกทั่วไป**

**ลิงก์ทดลอง:** https://nonga-ce93c.web.app

---

## ก่อนเริ่ม (ทุกคน)

| รายการ | รายละเอียด |
|--------|-------------|
| **บัญชี** | ทีมจะสร้างอีเมล login ให้ และส่งวิธีตั้งรหัสผ่านทางช่องทางส่วนตัว |
| **การสมัครเอง** | หน้า “สมัครสมาชิก” ยังปิด — ถ้าเข้าไม่ได้ แจ้งทีมที่เชิญคุณ |
| **ข้อเสนอ** | รอบนี้เป็นระบบทดลอง — ฟีเจอร์บางอย่างอาจเปลี่ยนตาม feedback |

### ข้อควรระวัง (Pilot Safety)

- **น้องเอ** ช่วยแนะนำและสรุปข้อมูลจากประกาศ — **ไม่ใช่การรับประกันสภาพรถ ไมล์ หรือเอกสาร**
- **ผู้ซื้อ:** ควรดูรถจริง ทดลองขับ และตรวจเล่มทะเบียน/สัญญาก่อนซื้อ
- **ผู้ขาย:** คุณรับผิดชอบความถูกต้องของข้อมูลและรูปที่ส่ง
- **ความเป็นส่วนตัว:** อย่าส่งบัตรประชาชน เล่มทะเบียน สัญญาไฟแนนซ์ หรือข้อมูลอ่อนไหวในแชท
- **การติดต่อ:** แชร์เบอร์หรือ LINE เมื่อจำเป็นและทั้งสองฝ่ายยินยอมเท่านั้น

**มีปัญหา:** แจ้งทีมที่เชิญคุณ (LINE) หรือกรอกแบบ feedback ที่ทีมส่งให้

## A) ผู้ซื้อ

### วิธีถามน้องเอ

1. เปิด https://nonga-ce93c.web.app (หน้าแรกเป็น **แชท**)
2. พิมพ์สิ่งที่ต้องการ เช่น  
   - “อยากได้รถ SUV งบไม่เกิน 8 แสน จังหวัดกรุงเทพ”  
   - “มี Camry ปี 2018 ไหม”
3. รอการ์ดรถหรือคำตอบในแชท — ไม่ต้องรีบกดลิงก์อื่นก่อนอ่านในแชท

**เคล็ดลับ:** บอกงบประมาณ ยี่ห้อ/รุ่น ปี เกียร์ จังหวัด จะได้คำแนะนำตรงขึ้น

### วิธีดูรายละเอียดรถในแชท

1. เมื่อเห็น **การ์ดรถ** ในแชท ให้กด **ดูรายละเอียดในแชท** (ขยายในแชท — ไม่ต้องออกไปหน้าเต็มจอ)
2. อ่านข้อมูลรถ รูป และ **บทสรุปแบบคัดสรรของน้องเอ** (ถ้ามี)
3. ถ้าสนใจ ใช้ปุ่มทดลองบนการ์ด (เช่น สนใจรถ / รายงาน) ตามที่ระบบแสดง — **ยังไม่ใช่การจองหรือซื้อจริง**

### ข้อควรระวังก่อนตัดสินใจซื้อ

- น้องเอสรุปจาก **ข้อมูลที่ผู้ขายลง** — อาจไม่ครบหรือล้าสมัย
- **ต้องตรวจรถจริง** ที่ปลายทาง ทดลองขับ ฟังเสียงเครื่อง ดูรอย
- **ตรวจเอกสาร** ทะเบียน ภาษี ไฟแนนซ์ กับผู้ขายหรือเต็นท์โดยตรง
- ราคาในประกาศเป็น **ราคาที่ผู้ขายระบุ** — ต่อรองและชำระเงินนอกแพลตฟอร์มตามที่ตกลงกัน
- อย่าโอนเงินมัดจำโดยไม่ตรวจรถและเอกสาร

## B) ผู้ขายรถบ้าน (Member)

### วิธีส่งรูป/ข้อมูล

1. Login ด้วยอีเมลที่ทีมให้
2. เปิด **แชทกับน้องเอ**
3. ส่ง **รูปรถ** (แนะนำ 6–10 รูป: หน้า ข้าง หลัง ภายใน ไมล์ ห้องเครื่อง)
4. ส่ง **ข้อความ** ยี่ห้อ รุ่น ปี ราคา ไมล์ เกียร์ สี จังหวัด จุดเด่น

**ความเป็นส่วนตัว:**

- เบลอป้ายทะเบียนถ้าไม่จำเป็น
- อย่าใส่บัตร ใบหน้า เล่มทะเบียน สัญญา ในรูป
- อย่าพิมพ์เลขบัญชีหรือรหัสส่วนตัวในแชท

### วิธีบันทึกประกาศ

1. เมื่อน้องเอสรุปข้อมูลแล้ว ทำตามปุ่ม/คำแนะนำในแชท เช่น **บันทึกประกาศ**
2. ถ้าระบบขอให้ login ก่อน — login แล้วกลับมาในแชททำต่อ
3. ตรวจการ์ด **ประกาศร่าง** ในแชทว่าข้อมูลตรงกับรถจริง

### วิธีแก้ไข/ลงตลาด

1. แก้ข้อความหรือรูปในแชทตามที่น้องเอแนะนำ (ถ้ายังเป็นร่าง)
2. อ่านและ **ติ๊กยืนยัน** เรื่องสิทธิ์รูป/ความถูกต้องของข้อมูล (ถ้ามีขั้นตอน consent)
3. กด **ลงตลาด** เมื่อพร้อม
4. ดูผลที่เมนู **ประกาศของฉัน** หรือหน้าตลาดรถ

### ข้อควรระวัง (ข้อมูลส่วนตัว / ทะเบียน / เอกสาร)

| ทำได้ | ไม่ควรทำ |
|--------|----------|
| รูปตัวรถ ภายใน ไมล์ | รูปบัตรประชาชน / ใบหน้า |
| ข้อมูลรถที่ลงประกาศ | ส่งเล่มทะเบียนเต็มในแชท |
| เบอร์ติดต่อกับทีม pilot ตามที่ทีมบอก | โพสต์เบอร์ในคอมเมนต์สาธารณะโดยไม่จำเป็น |

เบอร์โทรของคุณ **อาจยังไม่แสดงบนหน้าตลาดสาธารณะ** ในรอบทดลอง — ทีมจะประสานการติดต่อ

## C) Dealer (เต็นท์รถ)

### วิธีสร้าง draft จากแชท

1. Login ด้วยบัญชี dealer ที่ทีมเปิดสิทธิให้
2. ใช้ **แชท** อธิบายรถหรือส่งรูป — ระบบช่วยสร้าง **Draft**
3. ตรวจว่า draft ผูกกับ **dealerId** ของเต็นท์คุณ

### วิธีเข้า Dealer Portal

1. หลัง login ไปที่ **Dealer Portal** (เมนูดีลเลอร์ หรือ `/dealer`)
2. เห็นรายการ draft / ประกาศในขอบเขตเต็นท์
3. ถ้าเข้าไม่ได้ — แจ้งทีมตรวจสิทธิ `dealerId` ในระบบ

### วิธีตรวจรูป / draft / publish

1. เปิด draft ที่ต้องการ → ตรวจ **รูป** ว่าครบและชัด
2. แก้ข้อมูล ราคา คำอธิบาย ใน draft editor
3. กด **ลงตลาด** เมื่อครบ — ถ้าไม่ผ่าน ระบบจะบอกว่าขาดอะไร (รูป/ฟิลด์)
4. ตรวจบนตลาดว่ารูปและราคาแสดงถูก

### วิธีใช้ Paste Import (ถ้าทีมเปิดให้)

สำหรับนำเข้าหลายคันจากตาราง/ข้อความ (มักทำโดย admin หรือ staff ที่มีสิทธิ):

1. เข้าเมนู **นำเข้าคลังรถ** (Smart Import / Paste Import) ตามที่ทีมชี้
2. วางข้อมูลตามรูปแบบตัวอย่าง
3. อัปโหลดรูปตามคิว — บันทึกเป็น draft แล้วตรวจก่อน publish

**คู่มือตัวอย่าง:** https://nonga-ce93c.web.app/samples/dealer-import-guide.md  
**ไฟล์ตัวอย่าง CSV:** `/samples/ThorAuto-sample-with-data.csv`
