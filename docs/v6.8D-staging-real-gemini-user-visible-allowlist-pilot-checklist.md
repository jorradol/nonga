## 1. Architecture summary

| Layer | Role |
|-------|------|
| Client | `chatUserVisibleOrchestrateClient.ts` — Bearer auth only; no UID in body |
| Route | `POST /api/ai/chat-user-visible-orchestrate` |
| Bridge | `salesBrainServerUserVisibleOrchestrationBridge.ts` — auth → inventory → orchestrate → pilot mock → **optional real Gemini (v6.8D)** |
| Allowlist gate | `salesBrainUserVisibleGate.ts` — default-deny; production off |
| Mock pilot | `salesBrainUserVisibleChatPath.ts` — `createSalesBrainAdapter({ provider: "mock" })` when real flag off |
| Real provider | `salesBrainUserVisibleRealProvider.ts` — staging + allowlist + explicit flag only |
| Guards | `aiEndpointGuard.ts`, `aiRateLimit.ts` — orchestrate route covered |

**Default:** mock pilot templates. **Real Gemini** only when all gates pass (see §3).

## 2. Required env / flags (manual operator enable)

| Flag | Pilot value | Notes |
|------|-------------|-------|
| `NONGA_AI_PROVIDER` | `gemini` | prerequisite |
| `NONGA_AI_MODE` | `high` | not `off` |
| `NONGA_AI_FIRST_ENABLED` | `true` | prerequisite |
| `NONGA_AI_USER_VISIBLE_ENABLED` | **`true`** | user-visible request |
| `NONGA_AI_USER_VISIBLE_REAL_PROVIDER_ENABLED` | **`true`** | v6.8D real Gemini switch |
| `NONGA_AI_USER_VISIBLE_ALLOWLIST_UIDS` | approved UID(s) | comma-separated; empty = deny all |
| `NONGA_AI_EMERGENCY_KILL_SWITCH` | **`false`** | during pilot window only |
| `NONGA_AI_BUDGET_DAILY_LIMIT` / `MONTHLY` | e.g. `5` / `50` | prerequisite caps |
| `GEMINI_API_KEY` | Secret Manager mount | `gemini-api-key:latest` |
| `NONGA_AI_ADMIN_SHADOW_REAL_PROVIDER_ENABLED` | **`false`** | not in scope |
| `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` | **`false`** | not in scope |

**Never set in v6.8D pilot:** production deploy, guest access, wide user-visible enablement.

## 3. Real provider eligibility matrix

| Condition | Real Gemini |
|-----------|-------------|
| Staging + all flags + allowlisted buyer UID | **Eligible** |
| `NONGA_AI_USER_VISIBLE_REAL_PROVIDER_ENABLED=false` | Mock pilot |
| `NONGA_AI_USER_VISIBLE_ENABLED=false` | Legacy fallback |
| Kill switch `true` | Blocked → mock/legacy |
| Guest / missing UID | Blocked → legacy |
| Non-allowlisted UID | Blocked → legacy |
| Production environment | Blocked |
| Missing `GEMINI_API_KEY` | Mock fallback |
| Provider error / unsafe output | Mock fallback |
| Dealer/admin role on orchestrate | Blocked (buyer only) |
