
### ความปลอดภัยของ diff

## 8) Firestore persistence — ยังไม่เปิด

| Flag | ค่า |
|------|-----|
| `NONGA_SUCCESS_FEE_RECORD_ENABLED` | off |
| `NONGA_SETTLEMENT_DATA_BACKEND` | `memory` |
| `NONGA_SETTLEMENT_FIRESTORE_WRITES_ENABLED` | off |

Runtime settlement repo = **in-memory** — revenue API ไม่พึ่ง client Firestore

Rules deploy รอบนี้ **ไม่สร้าง** collection การเงินใน Firestore และ **ไม่เปิด** Admin SDK writes สำหรับ settlement
