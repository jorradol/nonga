# v9.2 Disabled Admin-Only Runtime Proof Skeleton

> **DISABLED SKELETON ONLY / ADMIN-ONLY ONLY / NO RUNTIME ACTIVATION**
> เอกสารนี้บันทึกโครงสร้าง skeleton สำหรับ admin-only runtime proof ที่ถูกปิดไว้โดย default เท่านั้น

---

## 1. Purpose

v9.2 เพิ่มโครงสร้าง skeleton เพื่อเตรียมเส้นทาง admin-only runtime proof ในอนาคตแบบปลอดภัย โดยยังไม่เปิด runtime จริง

- default OFF
- no provider call
- no Gemini request
- no Gemini activation
- no deploy
- no production
- no public route
- no buyer-facing AI
- no user-visible AI
- no real lead sending
- no real secret/API key in repo

## 2. Scope in v9.2

- เพิ่ม `salesBrainRuntimeProofFlags` เพื่ออ่าน env placeholder เท่านั้น
- เพิ่ม admin-only route skeleton สำหรับ proof path
- route ตอบกลับเป็น read-only disabled payload เท่านั้น
- ไม่มีการเรียก provider network จริง

## 3. Admin-Only Boundary

- route อยู่ใต้ `/api/admin/*` เท่านั้น
- ใช้ boundary เดิมที่ถูกครอบด้วย `adminApiAuth`
- ไม่มี buyer/public path ที่เข้าถึง runtime proof skeleton ได้

## 4. Runtime Safety Baseline

- deterministic flow remains source of truth
- deterministic fallback remains source of truth
- หากไม่ผ่าน preconditions ให้ fallback deterministic เสมอ
- ไม่มี Gemini/provider activation ใน v9.2

## 5. Environment Placeholder Policy

ใช้เฉพาะชื่อ env var:

- `AI_RUNTIME_PROOF_ENABLED`
- `AI_ADMIN_RUNTIME_PROOF_ONLY`
- `AI_RUNTIME_PROOF_QUOTA_LIMIT`
- `AI_LOG_REDACTION_ENABLED`

ข้อกำหนด:

- env names only
- no real values
- no secrets in repo
- no API key in repo

## 6. Forbidden Actions in v9.2

- ห้าม deploy
- ห้าม production
- ห้ามเปิด runtime proof จริง
- ห้ามเปิด Gemini จริง
- ห้ามเรียก provider จริง
- ห้ามเพิ่ม public route
- ห้ามเปิด buyer-facing/user-visible AI path
- ห้ามส่ง lead จริง
- ห้ามใส่ secret/API key จริงใน repo
