## 4) Actual current Lead flow

```text
Buyer selects approved public listing (chat card)
  → CTA 「ให้ผู้ขายติดต่อกลับ」 (visible even when capture OFF)
  → Chat capture collects name / method / budget / window (in-memory draft)
  → Consent modal: phone + consent preview
  → Submit requires login + Firebase auth headers
  → POST /api/buyer-leads
       1) Auth → unauth 401
       2) isLeadCaptureEnabled() → OFF → 403, no write
       3) Parse body (listing + buyer fields + consent only)
       4) Load listing → missing 404; sold/hidden/pending_review 400
       5) createConsentedBuyerLead → sellerId from listing ownership only
       6) Persist lead + consent_recorded log (only when ON)
  → Buyer success (masked self-view)
  → Seller sees lead only via in-app masked queue (poll)
  → Phone unlock only via explicit seller reveal
  → No automatic email / SMS / LINE / webhook / push
```

Staging today stops at step 2 for any authenticated create attempt (capture OFF).
