## 3. Forbidden-to-Log Contract

ข้อมูลที่ **ห้าม log** ใน future real Gemini pilot — ห้ามปรากฏใน logs, repo, tests, fixtures:

| # | Forbidden Category | Examples (categories only — no real samples) |
|---|-------------------|-----------------------------------------------|
| F-01 | **Raw user prompt** | Full prompt text sent to provider |
| F-02 | **Full user message** | Complete chat message body |
| F-03 | **Full UID / user identifier** | Firebase UID, session token with identity |
| F-04 | **Email / phone / contact info** | Contact channels |
| F-05 | **Thai national ID / government ID** | Government identifiers |
| F-06 | **License plate / VIN / chassis number** | Vehicle identifiers |
| F-07 | **Exact car listing text from real user/dealer** | Real listing descriptions |
| F-08 | **Real car images / image URLs / storage paths with identifiers** | Identifiable media paths |
| F-09 | **Dealer private notes** | Internal seller notes |
| F-10 | **Payment / lead / reveal / outcome mutation details** | Business-sensitive mutations |
| F-11 | **Secret values** | API keys, tokens, credentials |
| F-12 | **API keys / tokens / credentials** | Any credential material |
| F-13 | **Env dump / process env** | Environment variable contents |
| F-14 | **Provider request/response body** | Full Gemini API payloads |
| F-15 | **Stack traces containing sensitive values** | Traces with embedded secrets/PII |

**v6.4K rule:** ใช้ synthetic non-PII fixtures เท่านั้นใน tests — ไม่ใส่ตัวอย่างจริงใน repo

## 4. Allowed Metadata Contract

สิ่งที่อนาคต **อาจ log ได้** เฉพาะแบบ redacted/aggregated — **ต้องไม่ reconstruct** raw prompt, PII, secret, full UID, real listing data:

| Field | Type / Form | Notes |
|-------|-------------|-------|
| `providerMode` | enum string | e.g. disabled, blocked, fallback-only |
| `providerStatus` | enum string | v6.4B `AiProviderStatus` |
| `realGeminiEnabled` | boolean | Must be `false` until activation approval |
| `networkCallMade` | boolean | Must be `false` in v6.4K |
| `guardDecision` | reason code | Not raw guard text |
| `blockedReasonCode` | reason code | e.g. `production_forbidden` |
| `fallbackReasonCode` | reason code | e.g. `deterministic_safety_disclaimer` |
| `scenarioId` | test/scenario id | Synthetic harness id only |
| `timestamp` | coarse ISO bucket | Minute-level or coarser |
| `environment` | label | `staging` / `local` — not production |
| `correlationId` | hashed/truncated | Non-reversible — not full UID |
| `tokenEstimateBucket` | bucket label | e.g. `0-100` — not raw tokens |
| `latencyBucket` | bucket label | e.g. `100-250ms` |
| `costBucket` | bucket label | e.g. `under-cap` |
| `outcomeCategory` | success/failure category | Not error body |
| `redactionApplied` | boolean | Must be `true` when logging allowed |
| `killSwitchState` | boolean | Active/inactive |
| `capState` | enum | e.g. `within-cap`, `cap-exceeded` |
| `allowlistState` | enum | e.g. `configured`, `not-configured` |

**Reconstruction prohibition:** Metadata schema must not allow rebuilding forbidden categories in §3

**v6.4B alignment:** `maskedActorId` (e.g. `adm_***xyz`) — never `fullUid` in audit events

## 5. Redaction Rules

Rules สำหรับ future implementation — v6.4K defines placeholders only:

| Rule ID | Redaction Action |
|---------|------------------|
| RR-01 | Replace raw prompt with `[REDACTED_PROMPT]` |
| RR-02 | Replace user identifiers with `[REDACTED_USER]` |
| RR-03 | Replace phone/email with `[REDACTED_CONTACT]` |
| RR-04 | Replace license plate/VIN/chassis with `[REDACTED_VEHICLE_ID]` |
| RR-05 | Replace secret/env with `[REDACTED_SECRET]` |
| RR-06 | Replace provider request/response body with `[REDACTED_PROVIDER_PAYLOAD]` |
| RR-07 | Store only reason codes — not raw content |
| RR-08 | Prefer allowlist logging over denylist logging |
| RR-09 | Redaction must happen **before** logging/persistence |
| RR-10 | Redaction failure → block logging + trigger fallback/stop |

## 6. Logging Approval Gates

ก่อนเพิ่ม runtime logging ในอนาคต ต้องผ่าน **ทุก gate** — approval แยก:

| # | Gate | Required Evidence | Pass Criteria | Blocker if Missing | Owner / Approval |
|---|------|-------------------|---------------|-------------------|------------------|
| LG-01 | **Owner approval for logging contract** | Signed owner record | Contract acknowledged | No approval → **STOP** | Owner |
| LG-02 | **Staging-only logging scope** | Environment = staging | Production logging forbidden | Production → **HARD BLOCK** | Owner + ops |
| LG-03 | **No raw prompt logging approval** | §3 F-01/F-02 acknowledged | Raw prompt never logged | Raw prompt policy missing → **BLOCK** | Owner + engineering |
| LG-04 | **No PII logging approval** | §3 F-03..F-09 acknowledged | PII categories blocked | PII policy missing → **BLOCK** | Owner + engineering |
| LG-05 | **No secret/env logging approval** | §3 F-11..F-13 acknowledged | Secrets never logged | Secret policy missing → **BLOCK** | Owner + security |
| LG-06 | **Metadata-only schema approval** | §4 schema reviewed | No reconstruction possible | Schema allows PII → **REJECT** | Engineering |
| LG-07 | **Redaction function review** | §5 rules implemented in future slice | RR-01..RR-10 pass tests | Redaction untested → **BLOCK** | Engineering |
| LG-08 | **Redaction test fixture review** | Synthetic non-PII fixtures only | No real samples in repo | Real samples → **STOP** | Engineering |
| LG-09 | **Logging sink approval** | Sink destination + access documented | Sink approved | Unapproved sink → **BLOCK** | Ops + security |
| LG-10 | **Retention policy approval** | Retention duration + purge plan | Policy documented | Open retention → **HOLD** | Owner + ops |
| LG-11 | **Access control approval** | Who can read logs | Least privilege | Over-broad access → **BLOCK** | Security |
| LG-12 | **Audit review approval** | Periodic audit schedule | Review calendar set | No audit → **HOLD** | Owner |
| LG-13 | **Stop/rollback approval** | §9 acknowledged | Rollback owner named | No rollback → **BLOCK** | Owner |
| LG-14 | **Separate deploy approval** | v6.4I AP-15 / v6.4H G-15 | Deploy approval separate | Assumed auto-deploy → **REJECT** | Owner |
| LG-15 | **Separate provider activation approval** | Activation approval separate | No provider calls without approval | Assumed auto-activate → **REJECT** | Owner |
