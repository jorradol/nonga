# Nong A — Future roadmap notes

## Guided Vehicle Photo Capture (seller mobile)

**Status:** Future phase — after Buyer Search Intent Polish, API cost control, and mobile chat UX are stable.

**Concept:** In mobile chat, Nong A guides home sellers through a structured photo set (front, side, rear, interior, odometer, engine bay) with optional on-screen framing/templates so listing photos are consistent, vision analysis is more accurate, and duplicate/low-quality uploads drop.

**Photo guidance principles:**

- Do not emphasize “max 10 photos”; focus on **recommended essential shots** (~5–6 minimum for a trustworthy listing).
- Essentials: front, side, rear, interior/console, odometer, engine bay (or one extra important angle).
- Optional: wheels/tires, rear seats, trunk, blemishes, keys/manuals (warn on PII).
- Goals: better UX without photography skill, fewer vision API calls on bad/duplicate images, more credible private listings.
- Privacy: watch license plates, faces, documents, personal data.

**Not in scope until the phase above is done.**
