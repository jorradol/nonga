## 3. Golden seller voice rules

| ID | Rule |
|----|------|
| GV-01 | Hook-first — `จุดที่น่าสนใจ…` / `จุดที่น่าดู…` / `ถ้าเน้นใช้งานประจำวัน…` |
| GV-02 | Data-bound — body/fuel/specs จาก input เท่านั้น |
| GV-03 | Benefit bridge — เชื่อม spec กับประโยชน์นุ่ม (`พอสมควร`, `สะดวกขึ้น`) |
| GV-04 | ไม่ใช้หัวข้อรายงาน (`จุดเด่นด้าน…`) |
| GV-05 | `จากข้อมูลประกาศ` ย้ายไป facts line ท้าย — ไม่เปิดย่อหน้าแรก |
| GV-06 | Deterministic variants จาก `buildStableSeed` + `pickStableVariant` |
| GV-07 | In-chat ≤220 chars — trim specs จากท้าย ไม่ตัด hook |
| GV-08 | Hype/overclaim strip + output guard |

## 4. Before / After (synthetic — no real stock)

**Input (pattern only):**

```text
brand/model/year: synthetic
bodyType: SUV, fuelType: hybrid
description: AB2 + บ.หนัง + พวงมาลัยมัลติฟังก์ชั่n + Cruise Control + Engine Start + Smart Keyless + จอทัช + Bluetooth + USB + กล้องถอย
```

### Detail preview

**Before (v6.3B.4):**

```text
จากข้อมูลประกาศ [brand model year] คันนี้เหมาะกับคนที่มองหา...

จุดเด่นด้านความสะดวกในการขับ มีเบาะหนัง พวงมาลัยมัลติฟังก์ชัน...
```

**After (v6.3B.6):**

```text
คันนี้จุดที่น่าดูคือเป็น SUV ไฮบริดที่เหมาะกับการใช้งานประจำวัน และมีอุปกรณ์ช่วยให้ใช้รถง่ายขึ้นพอสมควร ทั้งเบาะหนัง พวงมาลัยมัลติฟังก์ชัน Cruise Control...

ส่วนจอทัชสกรีน Bluetooth USB กับกล้องถอย ก็ช่วยให้การเดินทางและการจอดรถสะดวกขึ้น — สำหรับคนที่อยากได้รถที่มีความสะดวกครบ ๆ จุดนี้ถือว่าน่าดูต่อ

จากข้อมูลประกาศ ไมล์ ... ราคา ... เชื้อเพลิงไฮบริด

[disclaimer]
```

### In-chat featureWeave

**Before (v6.3B.5):**

เป็น SUV ไฮบริดที่เหมาะกับการใช้งานประจำวัน มีอุปกรณ์ช่วยให้ขับสบายขึ้น เช่น ...
