## 3. Fixture Contract

`SYNTHETIC_REDACTION_FIXTURES` เป็น **synthetic-only**:

| Property | Requirement |
|----------|-------------|
| Scenario id | `SYNTH_REDACTION_SCENARIO_001` — prefix `SYNTH_` only |
| Metadata | `buildSyntheticRedactedMetadataFixture()` — no raw content |
| Allowed labels | Category buckets only (`SYNTH_INTENT_BUDGET_SEARCH`, etc.) |
| Forbidden labels | Field **names** only — no real sample values |
| Markers | `userVisibleAnswer: false`, `dbWrite: false`, `mutationMarker: false` |

**ห้ามมีใน fixture:** ข้อมูลจริง, API key/token, full UID, email/phone, เลขบัตร, ทะเบียน, VIN/chassis, real dealer listing, real image URL, raw prompt, provider payload

**Reconstruction prohibition:** Fixture ต้องไม่ reconstruct real user/dealer/car data

## 4. Helper Contract

| Export | Role |
|--------|------|
| `FORBIDDEN_LOG_FIELDS` | 20 forbidden category names (v6.4K aligned) |
| `ALLOWED_REDACTED_METADATA_FIELDS` | 19 allowed metadata field names |
| `buildSyntheticRedactedMetadataFixture()` | Build metadata with invariants |
| `assertNoForbiddenSensitiveContent()` | Scan text for forbidden patterns |
| `assertSyntheticMetadataInvariants()` | Verify allowlist + `realGeminiEnabled: false` + `networkCallMade: false` + `redactionApplied: true` |
| `assertNoReconstructableRawContent()` | No long free-text in metadata values |

### Required metadata invariants

| Field | v6.4M Value |
|-------|-------------|
| `realGeminiEnabled` | **`false`** |
| `networkCallMade` | **`false`** |
| `redactionApplied` | **`true`** |
| `environmentLabel` | `staging` or `local` — never `production` |
| `syntheticScenarioId` | `SYNTH_*` prefix only |

### Forbidden content categories (17)

1. raw prompt  
2. full user message  
3. full UID  
4. email/contact  
5. phone/contact  
6. Thai national ID  
7. license plate  
8. VIN/chassis  
9. real dealer listing  
10. real car image URL/storage path  
11. dealer private note  
12. payment/lead/reveal/outcome detail  
13. secret value  
14. API key/token/credential-like value  
15. env dump / process env  
16. provider request/response body  
17. identifiable real car data  

### Allowed metadata categories (19)

`providerMode`, `providerStatus`, `realGeminiEnabled`, `networkCallMade`, `guardDecisionCode`, `blockedReasonCode`, `fallbackReasonCode`, `syntheticScenarioId`, `environmentLabel`, `coarseTimestampBucket`, `nonReversibleCorrelationId`, `tokenEstimateBucket`, `latencyBucket`, `costBucket`, `successFailureCategory`, `redactionApplied`, `killSwitchState`, `capState`, `allowlistState`
