## 8. PowerShell Comma Split Incident

### Accidental corrupted revision (discarded)

First env update attempt on Windows PowerShell **without quoting** `--update-env-vars`:

```bash
# FAILED — PowerShell parsed comma as argument separator
gcloud run services update nonga-staging \
  --project=nonga-ce93c \
  --region=asia-southeast1 \
  --update-env-vars=NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED=true,NONGA_AI_EMERGENCY_KILL_SWITCH=true
```

| Field | Value |
|-------|-------|
| **Corrupted revision** | `nonga-staging-00064-zgf` |
| **Observed corruption** | `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` value became `"true NONGA_AI_EMERGENCY_KILL_SWITCH=true"`; global kill stayed **`false`** |
| **Re-test on 00064** | **invalid** — CP-02 still `chat_shadow_real_provider_flag_off` |
| **Resolution** | **discarded** — re-applied with **quoted** `--update-env-vars="..."` → valid revision **`nonga-staging-00065-2lf`** |

**Lesson:** On PowerShell, always quote multi-var `--update-env-vars="KEY1=val1,KEY2=val2"`.
