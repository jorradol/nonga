## 1. Vision & Scope

### เป้าหมาย v6.1D

- **Admin/superadmin only** — gated ด้วย `RequireAdmin` + server `adminApiAuth`
- **Fixed synthetic cases SS-01..SS-08** — ปุ่มเท่านั้น ไม่มี custom input
- **Redacted read-only display** — flags + mock metadata ไม่แสดง secret/env/PII
- **ไม่เปิด** `NONGA_AI_USER_VISIBLE_ENABLED=true`
- **ไม่ deploy** Cloud Run / Hosting / Firestore rules ใน slice นี้

### Out of scope (this slice)

- Cloud Run / Hosting deploy
- Live staging HTTP smoke from UI (future approved slice)
- Wiring shadow result into chat user-visible path
