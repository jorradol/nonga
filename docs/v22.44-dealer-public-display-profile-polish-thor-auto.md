## 2) Root cause

| Layer | Finding |
|-------|---------|
| Public DTO mapping | `toPublicMarketplaceCarDto` / `applySafePublicSellerDisplayFields` reads **listing-baked** `showroomName` / `ownerName` |
| Display rule | `dealerDisplayName = showroomName`; `sellerDisplayName = showroomName \|\| ownerName` |
| Pilot listing state (before) | Both Corollas had `showroomName: ""` and `ownerName: "Unknown Owner"` |
| Why Unknown Owner | Dealer Portal draft create copies `profile?.ownerName \|\| "Unknown Owner"` and `profile?.showroomName \|\| ""` |
| Why profile empty | Existing `nonga-dealer` had **no durable showroom/display profile** on Cloud Run (`data/dealer-profiles.json` path) and user display metadata was not set to Thor Auto |
| Binding | Listings correctly bound to `nonga-dealer` (`sellerType: dealer`, `dealerSlug: nonga-dealer`) — **not** a missing dealer binding |
| Not a duplicate-dealer issue | Same existing dealer; display metadata only |

Public cards therefore showed `sellerDisplayName: Unknown Owner` and `dealerDisplayName: null` even though privacy redaction (no `ownerId` / `dealerId` / VIN / full plate) was already correct.

## 3) Minimal fix applied

Preferred path: update existing dealer/profile/display metadata **and** repair listing-baked display fields (required because public DTO does not live-resolve profile at read time).

| Action | Target | Change |
|--------|--------|--------|
| Listing display repair | Existing published pilot Corolla 2020 | `showroomName` / `ownerName` → `Thor Auto` |
| Listing display repair | Existing published pilot Corolla 2021 | `showroomName` / `ownerName` → `Thor Auto` |
| Dealer user display polish | Existing `nonga-dealer` user record | `dealerName` / `displayName` → `Thor Auto` |
| Cloud Run dealer profile | Existing `nonga-dealer` profile | `showroomName` / `ownerName` → `Thor Auto` (future drafts inherit) |

**Not done:** create dealer, create listing, change approval/status, change price/images/vehicle content, lead capture ON, dealer-facing send, production deploy, public signup.
