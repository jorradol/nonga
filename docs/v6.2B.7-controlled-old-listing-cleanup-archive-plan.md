## 2. Preferred Strategy

| Priority | Strategy | Rule |
|----------|----------|------|
| 1 | **archive / hide / deactivate** | preferred first — reversible |
| 2 | **status or flag rollback** | restore previous status/flag on rollback |
| 3 | **hard delete** | ❌ **requires separate approval later** — not in initial cleanup |
| 4 | **execution record** | separate record when cleanup runs for real (future slice) |

### Strategy principles

- ใช้ **archive/hide/deactivate ก่อน hard delete**
- **hard delete ต้องมี approval แยกภายหลัง** — only after system stable
- **ต้องมี rollback path** — documented restore procedure §5.6
- **ต้องมี execution record แยก** — when cleanup executed (not this planning slice)

## 3. Candidate Identification

### 3.1 Criteria (git-safe — no per-car real data)

ระบุวิธีแยก old/test listings **โดยไม่บันทึกข้อมูลรถจริงลง repo**:

| Criterion ID | Field / signal | Usage |
|--------------|----------------|-------|
| CI-01 | `createdBefore` | cutoff date — ops channel only, not specific dates in git if PII context |
| CI-02 | `sourceTag` | e.g. `mock`, `test`, `synthetic`, `legacy-pilot` |
| CI-03 | `pilotBatchId` | exclude real pilot batch id when assigned post-import |
| CI-04 | `ownerUid` | masked ref in ops — **no raw UID in git** |
| CI-05 | `status` | `published` / `hidden` / `draft` / `archived` |
| CI-06 | `test/demo marker` | explicit test flag on listing metadata |
| CI-07 | `listingOrigin` | synthetic vs dealer-import vs manual test |

**ห้ามระบุ make/model/price/plate/ข้อมูลเฉพาะคันใน git**

### 3.2 Identification workflow (ops — outside detailed git record)

```
query staging listings → apply CI-01..CI-07 filters → candidate set (count N in ops)
→ manual review exclude real pilot batch → dry-run count → approval → execute (future)
```

Candidate **counts** may appear in ops execution record — **not per-car details in git**

### 3.3 Exclusion rules

| Rule | Action |
|------|--------|
| Real pilot batch (10 cars post-import) | **never hide** in cleanup |
| Listings with active lead/reveal/outcome refs | **exclude** — see §4 |
| Revenue/settlement-linked listings | **exclude until finance review** |
