## 1. Pilot scope

| หัวข้อ | แนวทางรอบแรก |
|--------|----------------|
| **จำนวนผู้ขาย** | **3–5 คน** — ไม่รับเกินก่อนทีม support ไหว |
| **จำนวนรถต่อคน** | แนะนำ **1 คันก่อน** (สูงสุด 2 คันถ้าคุ้นระบบแล้ว) |
| **ประเภทรถ** | **รถบ้านเจ้าของขายเอง** — ผู้ขายเป็นเจ้าของหรือผู้มีสิทธิ์ลงประกาศจริง |
| **การสมัคร** | **ยังไม่เปิดสมัครทั่วไป** — `publicSignupEnabled=false` บน staging |
| **ดีลเลอร์** | **รอบนี้ไม่รับดีลเลอร์ใหม่** ยกเว้นมีเหตุผลพิเศษที่ลุงอนุมัติ |
| **ช่องทางรับคน** | Facebook/LINE แบบ **เชิญรายคน** ไม่โพสต์เปิดกว้าง |
| **สิ่งที่ระบบทำได้** | คุยกับน้องเอ → ส่งรูป/ข้อมูล → บันทึกประกาศ → login → ติ๊ก consent → ลงตลาด → ดูใน “ประกาศของฉัน” |
| **สิ่งที่ระบบยังไม่ทำ** | ไม่มี lead จริง, ไม่แสดงเบอร์ผู้ขายบนตลาดสาธารณะ, ฟอร์ม “สนใจรถ” ยังเป็นรอบทดลอง |

## 2. สิ่งที่ผู้ขายต้องเตรียม

### รูปรถ (แนะนำ)

| รายการ | แนะนำ |
|--------|--------|
| **จำนวน** | อย่างน้อย **3–5 รูป**, ดีที่สุด **6–10 รูป** (ระบบรับสูงสุด **10 รูปต่อประกาศ**) |
| **ขั้นต่ำก่อนลงตลาด** | อย่างน้อย **1 รูป** (ระบบอาจขอรูปด้านนอกตัวรถชัดเจนเพิ่ม) |

**มุมภาพที่ควรมี (เช็กจากรูปจริง):**

- [ ] ด้านหน้ารถ (เห็นตัวรถชัด)
- [ ] ด้านข้าง
- [ ] ด้านหลัง
- [ ] ภายใน (เบาะหน้า / คอนโซล)
- [ ] เลขไมล์บนหน้าปัด
- [ ] ห้องเครื่อง (ถ้าถ่ายได้)
- [ ] รูปเสริม: ยาง, รอยตำหนิ, อุปกรณ์แต่ง (ถ้ามี)

### ข้อมูลที่ต้องเตรียม (พิมพ์หรือส่งข้อความให้น้องเอ)

- [ ] ยี่ห้อ / รุ่น
- [ ] ปีจดทะเบียน
- [ ] ราคาที่ต้องการขาย (บาท)
- [ ] เลขไมล์
- [ ] เกียร์ (ออโต้ / ธรรมดา)
- [ ] สี
- [ ] จังหวัด / พื้นที่นัดดูรถ
- [ ] จุดเด่น 2–3 ข้อ (เช่น มือเดียว, ศูนย์ครบ, ยางใหม่)
- [ ] **เบอร์โทรติดต่อลุง** (ใช้ประสานรอบ pilot — **ยังไม่แสดงบนตลาดสาธารณะ**)

### ข้อควรระวัง (ความเป็นส่วนตัว / PDPA)

- [ ] **ปิดหรือเบลอป้ายทะเบียน** ถ้าไม่จำเป็นต้องโชว์
- [ ] **อย่าใส่ใบหน้าคน, บัตรประชาชน, เล่มทะเบียน, สัญญาไฟแนนซ์** ในรูปประกาศ
- [ ] อย่าถ่ายทะเบียนบ้าน / ที่อยู่ / QR โอนเงินในภาพ
- [ ] ถ้ารูปมีเบอร์โทรหรือ LINE ในรูป — ระบบอาจยังแสดงในรูปได้ แม้ API จะไม่ส่งเบอร์แยก — **แนะนำเบลอก่อนส่ง**

## 3. ขั้นตอนสร้างบัญชีให้ผู้ขาย

ทำทีละคน — เก็บรหัสผ่านใน **password manager** เท่านั้น ห้ามส่งรหัสในแชทกลุ่ม

### ขั้นที่ 1 — สร้างผู้ใช้ใน Firebase Authentication

1. เปิด [Firebase Console](https://console.firebase.google.com/) → โปรเจกต์ **`nonga-ce93c`**
2. ไปที่ **Authentication** → **Users**
3. กด **Add user**
4. ใส่ **อีเมล** ที่ผู้ขายใช้ login ได้จริง (แนะนำ Gmail ส่วนตัว)
5. ตั้ง **รหัสผ่านชั่วคราว** (สุ่มยาว) หรือเลือกส่ง **Password reset** หลังสร้าง
6. **คัดลอก UID** เก็บไว้ในตาราง pilot (ข้อ 8)

### ขั้นที่ 2 — ส่งรหัสให้ผู้ขายอย่างปลอดภัย

เลือกอย่างใดอย่างหนึ่ง:

- **ทาง A:** ส่งลิงก์ **Reset password** ทางอีเมล (แนะนำ — ผู้ขายตั้งรหัสเอง)
- **ทาง B:** ส่งรหัสชั่วคราวทาง LINE ส่วนตัว แล้วบังคับเปลี่ยนหลัง login ครั้งแรก

### ขั้นที่ 3 — สร้างข้อมูล role ใน Firestore (`users/{uid}`)

ผู้ขายรถบ้าน = **`role: member`**, **`status: active`**

**ไม่ต้อง** สร้าง `dealerMembers` สำหรับรอบนี้

ตัวอย่างเอกสาร (แทนค่าจริง):

```json
{
  "uid": "<uid จาก Auth>",
  "email": "<อีเมล login>",
  "displayName": "<ชื่อที่แสดง>",
  "role": "member",
  "status": "active",
  "createdAt": "<ISO time>",
  "updatedAt": "<ISO time>"
}
```

**วิธีใส่ข้อมูล:**

- **มือใน Console:** Firestore → collection `users` → document id = `uid` → วางฟิลด์ตามด้านบน  
- **หรือใช้ script (ลุงรันเองหลัง review — รอบเขียนเอกสารนี้ยังไม่รัน):**

```bash
# ตั้ง env ใน shell ปลอดภัย (ดู docs/firebase-role-test-users-v5.md)
# สำหรับ pilot ใช้เฉพาะ member คนเดียวต่อรอบ ไม่ต้องตั้ง dealer/admin env

npm run seed:v50-firebase-role-test-users -- --dry-run --json
# ตรวจ output แล้วค่อย:
# npm run seed:v50-firebase-role-test-users -- --write
```

> **หมายเหตุ:** script เดิมออกแบบสำหรับ member + dealer + admin พร้อมกัน — ถ้ารับแค่ member ให้ตั้ง env เฉพาะ `NONGA_TEST_MEMBER_*` หรือสร้างมือใน Console จะง่ายกว่า

### ขั้นที่ 4 — ตรวจว่า public signup ยังปิด

1. เปิด https://nonga-ce93c.web.app/api/health  
2. ต้องเห็น `"publicSignupEnabled": false`  
3. หน้า login ควรมีข้อความประมาณ **“รอบทดลอง — เปิดให้เฉพาะผู้ที่ได้รับเชิญ”**

### ขั้นที่ 5 — Checklist บัญชี pilot (ต่อคน)

| รายการ | ☐ |
|--------|---|
| สร้าง Auth user แล้ว | |

| ส่งวิธี login + ลิงก์ staging ให้ผู้ขายแล้ว | |

## 4. ข้อความที่ลุงใช้ส่งให้ผู้ขาย (Facebook/LINE)

คัดลอกไปปรับชื่อได้ — โทนเป็นกันเอง ไม่สัญญาขายได้

### 4.1 ข้อความเชิญเข้าร่วมทดลอง

```
สวัสดีครับ/ค่ะ [ชื่อ]
ทีม Nong A เปิดรับทดลองลงขายรถบ้านแบบเชิญเท่านั้น รอบแรกรับจำกัด 3–5 ท่านครับ

ระบบมี “น้องเอ” ช่วยร่างประกาศจากรูปและข้อมูลที่ส่งในแชท
แล้วลงแสดงในตลาดทดลองของเรา (ยังไม่เปิดให้สมัครเองทั่วไป)

ถ้าสนใจ แจ้งกลับได้ครับ จะส่งลิงก์และวิธีเข้าใช้งานให้
```

### 4.2 ข้อความบอกให้เตรียมรูป/ข้อมูล

```
ก่อนเริ่ม รบกวนเตรียมครับ/ค่ะ:

รูปรถ 6–10 รูป (อย่างน้อย 3 รูป) — หน้า ข้าง หลัง ภายใน เลขไมล์ ห้องเครื่องถ้ามี
เบลอป้ายทะเบียน / อย่าใส่บัตร ใบหน้า เอกสารส่วนตัวในรูป

ข้อมูล: ยี่ห้อ รุ่น ปี ราคา ไมล์ เกียร์ สี จังหวัด จุดเด่นรถ

เบอร์โทรใช้ติดต่อทีมงานรอบทดลอง (ยังไม่แสดงเบอร์บนหน้าตลาดสาธารณะ)
```

### 4.3 ข้อความส่งลิงก์ staging + login

```
ลิงก์ทดลอง: https://nonga-ce93c.web.app

1) เปิดลิงก์ → คุยกับน้องเอ (หน้าแรกเป็นแชท)
2) ส่งรูป + รายละเอียดรถตามที่เตรียมไว้
3) เมื่อระบบให้บันทึกประกาศ → เข้าสู่ระบบด้วยอีเมล: [อีเมล]
   (รหัสผ่าน / ลิงก์ตั้งรหัส: [ส่งแยกหรือ reset email])
4) กลับมาในแชท → บันทึก → ติ๊กยืนยันสิทธิ์รูป/ข้อมูล → ลงตลาด
5) ดูผลที่เมนู “ประกาศของฉัน” หรือหน้าตลาดรถ

ติดปัญหาแจ้งลุงทาง LINE นี้ได้เลยครับ
```

### 4.4 ข้อความอธิบาย invite-only / ระบบทดลอง

```
รอบนี้เป็นระบบทดลองแบบเชิญเท่านั้น ยังไม่เปิดสมัครสมาชิกทั่วไป
ข้อมูลบางส่วนอาจปรับได้ตาม feedback

การกด “สนใจรถ” บนหน้ารายละเอียดยังเป็นแบบทดลอง — ยังไม่ส่ง lead จริงไปหาผู้ขาย
```

### 4.5 ข้อความแจ้งว่าไม่รับประกันการขาย

```
ทีมช่วยให้ลงประกาศและทดสอบระบบเท่านั้น
ยังไม่รับประกันว่าจะขายได้ภายในกี่วัน หรือจะมีผู้ซื้อติดต่อทันที
ผู้ขายยังรับผิดชอบความถูกต้องของข้อมูลและรูปรถเองครับ/ค่ะ
```

## 6. ขั้นตอนที่ลุงตรวจหลังผู้ขายลงประกาศ

ทำภายใน **24 ชม.** หลัง publish

| รายการ | วิธีตรวจ | ☐ |
|--------|----------|---|
| รูปตรงกับรถจริง / ไม่สับสนรุ่น | เปิดการ์ดในตลาด + แชท | |
| ข้อมูลสำคัญครบ | ยี่ห้อ รุ่น ปี ราคา ไมล์ เกียร์ | |
| **ไม่มีเบอร์/อีเมล/LINE หลุด** | เปิด `GET /api/cars` หรือดูการ์ดสาธารณะ — ไม่ควรเห็น `ownerPhone` | |
| รูปไม่มีบัตร/ป้ายทะเบียนชัดเกินไป | ดู gallery | |
| ภาษาประกาศเหมาะสม | ไม่มีคำหยาบ / โอ้อวดเกินจริง | |
| รูปไม่เหมาะ / ไม่ใช่รถ | ให้ผู้ขายแก้ หรือลุง **ซ่อนประกาศ** | |

**บันทึกในตาราง pilot:**

- `listingId`
- `uid`
- วันที่ลงตลาด
- หมายเหตุ / ปัญหา

**ถ้าต้องซ่อนประกาผิด:**

- ให้ผู้ขายกด **ซ่อนประกาศ** ที่หน้า **ประกาศของฉัน**  
- หรือลุงใช้ช่องทาง admin / API `PATCH /api/cars/{id}/visibility` ด้วยสิทธิ์ admin (ถ้าคุ้น)

## ความเสี่ยงที่ยังเหลือก่อนรับคนแรก

1. **ไม่มี lead จริง** — ผู้ซื้อกดสนใจแล้วข้อมูลไม่ไปหาผู้ขาย (ตั้งใจในรอบ pilot)
2. **เบอร์ในรูป** — API ซ่อนเบอร์แล้ว แต่ถ้ารูปมีเบอร์ฝังอยู่ยังเห็นได้
3. **Consent ยังไม่เก็บใน Firestore** — เป็น in-memory ต่อ session
4. **ระบบอาจบล็อก publish** ถ้ารูปไม่ผ่าน validation (ไม่มีรูปด้านนอกชัด ฯลฯ)
5. **Support ขึ้นกับลุง** — ยังไม่มี SLA / ticket system
6. **กฎหมาย/PDPA** — ยังเป็น pilot ไม่ใช่นโยบายสมบูรณ์
