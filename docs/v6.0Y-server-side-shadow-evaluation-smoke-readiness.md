## 2. Smoke Targets (Server-side)

When future server-side smoke runs (not in v6.0Y), each case must verify:

| # | Target | Pass criteria |
|---|--------|---------------|
| 1 | **Read `NONGA_AI_*`** | `resolveSalesBrainRuntimeFlags` returns expected flags from env |
| 2 | **Shadow allowed gate** | `shadowEvaluationAllowed=true` only when: provider=gemini, mode=high, aiFirst=true, shadow=true, **user-visible=false**, budget daily=5 + monthly=50, kill switch=false, environment=staging |
| 3 | **User-visible response** | `userVisibleResponse` === `legacyUserVisibleResponse` always — never replaced by shadow/mock/AI |
| 4 | **Debug/shadow log PII** | `summarizeShadowRuntimeFlags` + redaction — **no raw phone/email** in logs |
| 5 | **Paid provider network** | `SALES_BRAIN_REAL_PROVIDER_NETWORK_ENABLED=false` — no outbound AI provider fetch |
| 6 | **Provider error/fallback** | Shadow skip or mock error must **not** change user-visible text |
| 7 | **Kill switch** | `NONGA_AI_EMERGENCY_KILL_SWITCH=true` → shadow inactive, legacy unchanged |
| 8 | **Budget missing/invalid** | Missing caps → `shadowEvaluationAllowed=false`, legacy unchanged |
| 9 | **User-visible attempted** | `NONGA_AI_USER_VISIBLE_ENABLED=true` → blocked by v6.0R, legacy unchanged |
| 10 | **Production default off** | environment=production → shadow off regardless of env |

**Did not run** `gcloud secrets versions access` — no secret values in this record.
