## Summary

Fixed two Owner-reported Staging Pilot defects without creating Leads or touching Production:

1. **Exact vehicle query** (`มีรถ โตโยต้า Corolla 2020 ไหม`) now parses Thai brand + Corolla + bare year, ranks exact matches first, and ties general model copy to Corolla (not Camry).
2. **Budget extraction** (`ตั้งงบเอาไว้ที่ 350,000`) now captures budget so chat no longer falsely asks for งบประมาณ; consent modal can proceed.

## Root causes

| Defect | Cause |
|--------|--------|
| Search | JS `\b` fails on Thai brand; `Corolla` missing from solo-model list; bare year `2020` ignored without `ปี`/`year`; reply used first broad Toyota result (Camry) for model context |
| Budget | `BUDGET_PRICE_PATTERN` / line budget only matched `งบ` immediately before digits — missed `ตั้งงบเอาไว้ที่`; line name matcher greedily overwrote display name |
