## 1. Vision & Scope

### เป้าหมาย v6.1F

เตรียม **manual smoke checklist** และ **decision gate** สำหรับให้มนุษย์ทดสอบหน้า Admin Shadow Debug UI บน staging อย่างปลอดภัย ก่อนตัดสินใจขั้นต่อไปว่าจะเริ่ม real Gemini shadow call หรือยัง โดย:

- **Docs/tests only** — ไม่แก้ runtime, ไม่ deploy, ไม่เปิด AI ให้ public user
- **ไม่เรียก paid Gemini** และ **ไม่ fetch network ไป AI provider**
- **ไม่ใช้ข้อมูลจริง / สต๊อกจริง / PII จริง**
- Checklist ครอบคลุม guest / dealer / admin / public chat smoke

## 5. Decision Gate

หลังทำ manual smoke checklist ครบทุกข้อ (§4.1–§4.4) ให้ตัดสินใจดังนี้:

### PASS — เงื่อนไข (ต้องผ่านทั้งหมด)

- Guest gate ที่ `/admin/shadow-smoke` ✅
- Dealer/member ไม่เห็น admin menu และถูก block ✅
- Admin/superadmin เห็นเมนู + SS-01..SS-08 + SS-01 mock success ✅
- SS-05/SS-06/SS-07/SS-08 guardrail summary safe ✅
- ไม่มี raw PII / secret / env dump ✅
- `/chat` "เริ่มใหม่" → legacy exact response ✅
- ไม่มี AI/Gemini response ต่อ public user ✅

### ถ้า FAIL — หยุดทันที

| Action | Detail |
|--------|--------|
| **STOP** | หยุดขั้นต่อไป — **อย่าเปิด real Gemini** |
| **FIX** | แก้เฉพาะจุดที่ fail (UI gate, routing, redaction, legacy chat) |
| **RE-SMOKE** | รัน manual smoke ใหม่หลังแก้ — ต้อง PASS ก่อนไปต่อ |
| **NO** | ห้าม deploy/env change/paid Gemini เพื่อ "ลองแก้" โดยไม่มี approval |

### ถ้า PASS ทั้งหมด — ไปขั้นถัดไปได้ (เลือก 1 ทาง)

| Path | Slice | เงื่อนไข |
|------|-------|----------|
| **A** | v6.1G — real Gemini shadow provider **dry-run readiness** | docs/tests only — ยังไม่เรียก paid Gemini |
| **B** | v6.1G — staging real Gemini shadow call **admin-only** | ต้องมี **approval phrase แยก** (§7) และ **user-visible ยัง off** |

**v6.1F ไม่รัน path A หรือ B** — บันทึก checklist และ decision gate เท่านั้น

## 6. Real Stock Import — Still Blocked

การนำสต๊อกจริงจากเต็นท์เข้าระบบ **ยังห้าม** จนกว่าจะผ่าน gate ต่อไปนี้ตามลำดับ:

| Gate | Requirement |
|------|-------------|
| 1 | ผ่าน **admin shadow UI manual smoke** (v6.1F checklist — §4) |
| 2 | ถ้าจะใช้ AI จริง — ต้องผ่าน **real Gemini shadow admin-only smoke** (v6.1G + approval phrase §7) |
| 3 | ต้องผ่าน **AI conversation smoke** ก่อนใช้สินค้าจริง |

ข้อห้ามที่ยังมีผล:

- ห้ามนำสต๊อกจริงจากเต็นท์เข้า
- ห้ามใช้ข้อมูลลูกค้าจริง / เบอร์โทรจริง / ข้อมูลรถเต็นท์จริง ใน smoke
- ห้าม listing input / real stock path ใน admin shadow UI
