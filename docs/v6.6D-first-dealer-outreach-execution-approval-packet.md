## 11. Stop / Escalation Rules

| Trigger | Action |
|---------|--------|
| เต็นท์ต้องการ **เริ่มทันที** (pilot/onboard) | **STOP** — ขอ approval onboarding/pilot แยก |
| เต็นท์จะ **จ่ายเงิน** / มัดจำ | **STOP** — ขอ approval payment/manual invoice แยก |
| ส่ง **ข้อมูลรถจริงจำนวนมาก** | **STOP** ก่อนนำเข้า — ยังไม่ import runtime |
| ขอ **AI ตอบลูกค้าเอง** | **ปฏิเสธอย่างสุภาพ** + escalate ถึง owner |
| มี **ค่าใช้จ่าย cloud/AI** เพิ่ม | **STOP** — ขอ owner approval |
| ต้องใช้ **production / deploy** | **STOP** — ขอ approval แยก |
| ขอ **user-visible AI / auto-publish** | **STOP** + escalate |
| Red flag ใน logging template | **STOP** แถวนั้น — ไม่ push ต่อ |
| Owner สั่ง stop | **STOP** ทุก outreach ที่ active |
