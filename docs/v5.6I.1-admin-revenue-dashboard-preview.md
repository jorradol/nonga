# v5.6I.1 — Admin Revenue Dashboard Preview / Success Fee Records Preview

**สถานะ:** Foundation preview — **ยังไม่ commit/deploy** จนกว่าลุง review  
**หลักการ:** แสดงภาพรวมรายได้คาดการณ์ให้แอดมินเท่านั้น — ไม่เปิดเก็บเงินจริง

## ทำไมต้องมี

- v5.6I มี success fee policy (`hundred_thousand_floor_tier`) แล้ว
- ยังไม่มีหน้า Admin ดูภาพรวมรายได้ / settlement
- ลุงต้องการเห็นตัวเลขก่อนเปิดเก็บเงินจริง

## สิ่งที่ทำในรอบนี้

| รายการ | สถานะ |
|--------|--------|
| Tab แอดมิน `revenue-preview` | ✅ read-only |
| Summary cards | ✅ ดีลปิด / pending_sale / ค่าบริการคาดการณ์ / รอชำระ / บางส่วน / ชำระแล้ว / ยกเว้น / disputed+cancelled |
| ตาราง preview | ✅ empty state เมื่อไม่มีแถว |
| นับ `pending_sale` | ✅ จาก `cars` ใน admin dashboard (read-only count) |
| แถว success fee | ✅ `getAdminRevenuePreviewRows()` คืน `[]` — ไม่ persist อัตโนมัติ |
| Helper สร้างแถวทดสอบ | ✅ `buildPreviewRowFromClosedDeal` (tests/tools เท่านั้น) |

## สิ่งที่ยังไม่ทำ

- เปิด `NONGA_SUCCESS_FEE_RECORD_ENABLED` บน runtime
- **ยังไม่เปิด payment** — ไม่มี payment request / gateway
- Invoice จริง / บันทึกยอดรับเงิน / ทวงเงิน
- แสดงต่อ buyer / dealer / member
- Audit log ก่อน admin แก้ยอดจริง (ต้องมีก่อน production)

## Policy (อ้างอิง v5.6I)

- ต่ำกว่า 100,000 บาท → 500 บาท
- ตั้งแต่ 100,000 บาท → `floor(price / 100,000) × 1,000` บาท
- `policyId`: `hundred_thousand_floor_tier`
- คำที่ใช้ใน UI: **ค่าบริการเมื่อขายสำเร็จ** (ห้าม “ค่าคอมมิชชั่น”)

## สถานะ settlement (preview)

`unbilled` · `pending_payment` · `partially_paid` · `paid` · `waived` · `disputed` · `cancelled`

## Role guard

- แสดงเฉพาะ **admin** และ **superadmin** ใน `AdminDashboardView`
- ไม่ wire ใน member / dealer / buyer routes
- ไม่ expose เบอร์ผู้ซื้อ — แสดงเฉพาะ scope id แบบ mask

## Warning (UI)

> รอบนี้เป็น Preview สำหรับแอดมิน ยังไม่มีการเรียกเก็บเงินจริง ไม่มีการออกใบแจ้งหนี้ และไม่มีการเชื่อมต่อ payment gateway
