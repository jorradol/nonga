## 3. Synthetic-Only Data Contract

Future synthetic invocation ต้องใช้ **ข้อมูลปลอมเท่านั้น** — ห้ามส่งข้อมูลจริงจาก user/dealer/car

### Allowed future synthetic data examples

| Field | Example Form | Notes |
|-------|--------------|-------|
| Buyer intent category | `SYNTH_INTENT_BUDGET_SEARCH` | Category label only |
| Vehicle category | `SYNTH_VEHICLE_SEDAN` | No real brand/model |
| Budget bucket | `SYNTH_BUDGET_500K_800K` | Range bucket only |
| Location bucket | `STAGING_REGION_A` | No real address |
| Scenario id | `SYNTH_SCENARIO_001` | Harness identifier |
| Guard state | `SYNTH_GUARD_PASS` / `SYNTH_GUARD_BLOCK` | State enum only |
| Cap state | `SYNTH_CAP_WITHIN` / `SYNTH_CAP_EXCEEDED` | Bucket only |
| Kill switch state | `SYNTH_KILL_ACTIVE` / `SYNTH_KILL_INACTIVE` | Boolean enum |
| Allowlist state | `SYNTH_ALLOWLIST_CONFIGURED` | Metadata only |
| Redaction state | `SYNTH_REDACTION_APPLIED` | Must be true before log |

### Forbidden data (never in synthetic invocation payload)

| # | Forbidden Category |
|---|-------------------|
| FD-01 | Raw user prompt |
| FD-02 | Real chat transcript |
| FD-03 | Full UID / user identifier |
| FD-04 | Email / phone / contact info |
| FD-05 | License plate / VIN / chassis number |
| FD-06 | Real dealer listing text |
| FD-07 | Real car image URL / storage path with identifiers |
| FD-08 | Payment / lead / reveal / outcome data |
| FD-09 | Secret / env value |
| FD-10 | Provider request/response body |
| FD-11 | Production data |

**Reconstruction prohibition:** Synthetic data must not allow rebuilding real user/dealer/car data

**v6.4L rule:** ใช้ synthetic category/bucket/scenario id เท่านั้น — ไม่ใส่ตัวอย่างจริงใน repo

## 4. Pre-Invocation Gates for Future Execution

ก่อน execute synthetic invocation ในอนาคต ต้องผ่าน **ทุก gate** — approval แยก:

| # | Gate | Required Evidence | Pass Criteria | Blocker if Missing | Owner / Approval |
|---|------|-------------------|---------------|-------------------|------------------|
| PI-01 | **Owner approval for synthetic invocation execution** | Signed owner record | Owner acknowledges plan | No approval → **STOP** | Owner |
| PI-02 | **Staging-only environment confirmed** | Environment = staging | Production forbidden | Production → **HARD BLOCK** | Owner + ops |
| PI-03 | **Secret wiring approval completed separately** | v6.4J/N completion record | Secret plan executed with approval | Secret unwired → **BLOCK** | Owner + security |
| PI-04 | **Secret binding verified by metadata only** | Binding metadata, no secret value | No secret in logs/repo | Secret value exposed → **STOP** | Security |
| PI-05 | **Redaction/logging contract passed** | v6.4K contract acknowledged | LG gates satisfied | Contract missing → **BLOCK** | Engineering |
| PI-06 | **Synthetic-only fixture reviewed** | Fixture audit sign-off | No real data in fixture | Real data found → **STOP** | Engineering |
| PI-07 | **No user data guarantee reviewed** | FD-01..FD-11 checklist | All forbidden categories blocked | Gap → **BLOCK** | Engineering |
| PI-08 | **Cost cap set and approved** | Cap values documented | Caps non-null and approved | Cap unset → **BLOCK** | Owner |
| PI-09 | **Kill switch verified** | Kill switch test record | Switch reachable and ON default | Switch unavailable → **STOP** | Ops |
| PI-10 | **Allowlist verified** | Allowlist config metadata | Surfaces limited | Allowlist missing → **BLOCK** | Engineering |
| PI-11 | **Rate limit / quota verified** | Quota policy documented | Limits defined | No quota → **HOLD** | Ops |
| PI-12 | **Fallback behavior verified** | Fallback test record | Deterministic fallback works | Fallback untested → **BLOCK** | Engineering |
| PI-13 | **Monitoring redacted metadata only** | v6.4K §4 schema | No raw content logged | Raw logging → **STOP** | Engineering |
| PI-14 | **Rollback plan approved** | §8 acknowledged | Rollback owner named | No rollback → **BLOCK** | Owner |
| PI-15 | **Separate deploy approval** | v6.4I AP-15 / deploy ack | Deploy approval separate | Assumed auto-deploy → **REJECT** | Owner |
| PI-16 | **Separate invocation approval** | Invocation ack separate | No invoke without approval | Assumed auto-invoke → **REJECT** | Owner |
| PI-17 | **Post-run review plan** | Review checklist documented | Manual review required | No review → **HOLD** | Owner |
