## Rollback plan (ยังไม่รัน)

```text
# Cloud Run staging ONLY — kill-switch ลำดับ
NONGA_SETTLEMENT_FIRESTORE_WRITES_ENABLED=false
NONGA_SETTLEMENT_DATA_BACKEND=memory
NONGA_SUCCESS_FEE_RECORD_ENABLED=false
# → restart / redeploy Cloud Run staging service
```

| ผล | หมายเหตุ |
|----|----------|
| Writes หยุดทันที | `assertWritesAllowed()` throw |
| Runtime กลับ memory | overlay in-process — **ไม่ silent fallback** ขณะ backend=firestore |
| Firestore docs ค้าง | ไม่ auto-delete — memory runtime ไม่พึ่ง Firestore |

**Fail-closed:** ถ้า `backend=firestore` แต่ Admin SDK init ล้มเหลว → **throw** — ห้าม fallback memory เงียบ (ดู `settlementAdjustmentRepositoryFirestore.ts`)
