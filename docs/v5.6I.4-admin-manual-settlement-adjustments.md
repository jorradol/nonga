# v5.6I.4 — Admin/SuperAdmin Manual Settlement Adjustments + Audit Log

## Scope

Foundation สำหรับให้ Admin/SuperAdmin บันทึกการปรับยอดค่าบริการเมื่อขายสำเร็จแบบ **Manual** พร้อม audit log — ยังไม่ใช่ payment gateway และยังไม่ออก invoice จริง

## สิ่งที่ทำในรอบนี้

- Types: `SettlementAdjustmentAction`, `SettlementAdjustmentState`, `SettlementAdjustmentAuditEntry`
- Repository interface + **in-memory default** (`settlementAdjustmentRepository.ts`)
- Pure service: `settlementAdjustmentService.ts` (validation + apply + overlay)
- API:
  - `GET /api/admin/revenue/preview` — overlay adjustment ถ้ามี
  - `POST /api/admin/revenue/adjustments` — admin/superadmin only
  - `GET /api/my/revenue/preview` — seller เห็นยอดหลัง overlay (ไม่มี buyer PII / admin note)
- Admin UI: ปุ่มปรับยอด + modal confirm + audit preview ต่อ row
- Tests: `npm run test:v56i4-admin-manual-settlement-adjustments`

## สิ่งที่ยังไม่ทำ (future)

- Payment gateway / auto debit
- Invoice generation
- Firestore persistence / migration
- Production policy สำหรับ dispute / waive / cancel
- `NONGA_SUCCESS_FEE_RECORD_ENABLED=true` (ยังไม่เปิด)

## Persistence / runtime

- ใช้ **Option 2**: repository interface + **memory store default**
- ข้อมูล adjustment/audit **หายเมื่อ restart server** (staging MVP)
- ก่อน production ต้องมี durable persistence + policy review

## Manual adjustment warning (UI)

> ระบบนี้เป็นการบันทึกยอดแบบ Manual สำหรับแอดมิน ยังไม่มีการชำระเงินจริงผ่านระบบ และยังไม่มีการออกใบแจ้งหนี้อัตโนมัติ

## Audit log

ทุก POST adjustment สร้าง `SettlementAdjustmentAuditEntry` บันทึก:

- `updatedBy`, `updatedByRole`, `createdAt`
- `action`, `reason`, `adminNote`
- `previousFeeAmount` / `newFeeAmount`
- `previousPaidAmount` / `newPaidAmount`
- `previousRemainingAmount` / `newRemainingAmount`
- `previousStatus` / `newStatus`
- `listingId`, `sellerId`, `settlementId`
- `source: admin_manual` (ไม่มี payment gateway reference)

## Actions

| Action | ผลลัพธ์ |
|--------|---------|
| `partial_payment` / `record_payment` | เพิ่ม paid, ลด remaining |
| `mark_paid` | remaining = 0, status = paid |
| `waive_fee` | remaining = 0, status = waived |
| `dispute_fee` | status = disputed |
| `cancel_fee` | remaining = 0, status = cancelled |
| `manual_adjustment` | ตั้ง fee ใหม่ + คำนวณ balance |
| `admin_note` | บันทึก note + audit (ไม่เปลี่ยนยอด) |
