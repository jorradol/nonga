# v5.6E.6 — UI Regression Audit & Restore Listing Display

## Root cause

Seller masked lead queue was added as a **fourth flex child** on the same `lg:flex-row` row as the listing image, details, and action buttons (`w-full lg:basis-full`).

That forced v5.6E.4 to add `lg:flex-wrap` and `grow` on the queue wrapper so the panel could drop to a second line. Side effects:

- Image and actions competed for width on the first flex row before wrap.
- On some viewport widths the cover image could shrink or appear “missing”.
- Queue loading/notice UI lived in the same flex context as the primary card.

Marketplace cards were **not** changed by lead-queue work. Chat car card only gained an optional footer CTA below the gallery (additive).

## Fix (additive)

- Restore pre-queue **main row**: `flex flex-col lg:flex-row` inside `my-listings-card-main` (image + details + actions only).
- Move queue into `ListingLeadQueueSection` **below** the main row with a top border separator.
- Remove `lg:flex-wrap`, `basis-full shrink-0 grow` from the listing article.
- Panel `mt-3` spacing moved to section wrapper (`pt-3` on section).
