## 4) Root cause — `Missing admin API token for server mode`

| Finding | Detail |
|---------|--------|
| Surface | `DealerDraftInventoryView` (`/admin/draft-inventory`) — **admin** Draft Inventory, not Dealer Portal drafts |
| Client call | Sync `adminAuthHeaders()` → `resolveAdminApiTokenForServer()` |
| Failure | Staging browser has **no** `NONGA_ADMIN_API_TOKEN` / `VITE_NONGA_ADMIN_API_TOKEN` in client → throws `Missing admin API token for server mode` |
| Wrong expectation | Dealer/owner should use **Firebase session**, not paste an admin API token |
| Correct dealer path | Dealer Portal → **ยังไม่ลงขาย** → `POST /api/dealer/drafts/:id/publish` (Firebase dealer session) → `pending_review` |
| Why “ลงตลาดสำเร็จ” felt wrong | Admin Draft Inventory Publish had **no** pending-review success notice; green **Publish** button + page copy implied going live |

Approval gate on server for dealer draft publish remains `pending_review` (`publishDealerDraftToMarketplace`).
