# v5.6H — Deal Outcome → Pending Sale Flow

**สถานะ:** Implementation ready for review — **ยังไม่ commit/deploy**  
**อ้างอิง:** [v5.6G](./v5.6G-seller-contact-reveal-mvp.md) seller contact reveal

## สรุป

เมื่อ seller บันทึก outcome **ปิดการขายได้** (`closed_won`) ระบบจะ:

1. อัปเดต lead → `status: closed_won`
2. อัปเดต listing → `saleStatus: pending_sale`, `listingStatus: hidden`, `pendingSaleAt`
3. ซ่อนรถจากตลาดสาธารณะ (marketplace + chat search)
4. เจ้าของยังเห็นใน My Listings พร้อมป้าย **รอดำเนินการขาย**
5. Supersede คิวผู้สนใจอื่น (ข้อความตาม `buildListingUnavailableBuyerMessage` — foundation สำหรับแจ้งผู้ซื้อรายอื่น)

## `pending_sale` หมายถึงอะไร

| ใช่ | ไม่ใช่ |
|-----|--------|
| ซ่อนจากตลาดชั่วคราว | ขายเสร็จสมบูรณ์ (`sold`) |
| รอเดินเอกสาร/ขั้นตอนถัดไป | เก็บเงิน success fee |
| ประกาศยังอยู่ในระบบ (ไม่ลบ) | ออก invoice / admin settlement |
| | โอนกรรมสิทธิ์ยืนยันแล้ว |

## Listing status model (ที่ใช้)

| Field | ค่าเมื่อ closed_won |
|-------|---------------------|
| `saleStatus` | `pending_sale` (ใหม่บน `MarketplaceCarRecord`) |
| `listingStatus` | `hidden` (ซ่อนจากตลาด — ไม่ใช้ `adminHidden`) |
| `isSold` | ไม่เปลี่ยน (ยัง `false`) |
| `pendingSaleAt` | ISO timestamp |

การกรองตลาด: `isVisibleOnMarketplace()` ตัด `saleStatus` เป็น `pending_sale` / `sold` ก่อนเช็ค published/duplicate

## Outcome อื่น

| Outcome | ซ่อนรถจากตลาด? |
|---------|----------------|
| ติดต่อไม่ได้ / ไม่ได้ไปต่อ / รายงานข้อมูลน่าสงสัย | ไม่ |
| กำลังติดต่อ / นัดดูรถแล้ว | ไม่ |
| Skip ก่อน reveal | ไม่ |
