## 5. Env Update Plan (Future — Staging Build Only)

Preview gate เป็น **Vite compile-time** — ต้อง bake ตอน `build:staging:hosting` **ก่อน** hosting deploy

### Keys to enable (deploy session only — **not in this readiness slice**)

| Key | Future deploy value | Notes |
|-----|---------------------|-------|
| `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED` | `true` | เปิดเฉพาะ staging build session |
| `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ALLOWLIST_UIDS` | approved tester UIDs (comma-separated) | **ห้าม commit ลง git** |

### Keys that must NOT change

| Key | Rule |
|-----|------|
| `VITE_FIREBASE_*` | ใช้ flow เดิม — project ต้องเป็น `nonga-ce93c` |
| `VITE_NONGA_PUBLIC_SIGNUP_ENABLED` | คง `false` |
| AI allowlist / shadow flags | **ไม่แตะ** |
| Cloud Run env | **ไม่แตะ** |

### Allowlist policy (masked — no full UID in repo)

| Tester role | UID (masked) | Purpose |
|-------------|--------------|---------|
| Primary smoke (ลุง) | `abc1…xyz9` | allowlisted signed-in — preview **visible** |
| Negative test (optional) | `def2…uvw8` | signed-in non-allowlisted — preview **hidden** |

**Full UIDs:** ส่งทาง private channel ก่อน deploy session เท่านั้น — **ห้าม** ใส่ใน git, docs, tests, execution record แบบ plaintext

### Env injection options (deploy session — choose one)

**Option A — `.env.staging` (gitignored)**

```env
VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED=true
VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ALLOWLIST_UIDS=<UID_MASKED_A>,<UID_MASKED_B>
```

**Option B — shell session env vars** before `npm run build:staging:hosting`

> **Security note:** Allowlist UIDs จะถูก inline ใน client bundle (compile-time gate) — ยอมรับได้สำหรับ staging-only preview visibility ไม่ใช่ secret storage

## 8. Data Boundary & Forbidden Output

### Mapper whitelist (public-safe fields only)

**Allowed:** description, brand, model, year, price, mileage, color, fuelType, condition, features, tags, transmission, drivetrain, bodyType, province, sellerType, showroomName

**Forbidden in preview input/output:**

| Category | Examples |
|----------|----------|
| PII | ownerPhone, phone, LINE |
| Identity | ownerId, UID, licensePlate |
| Internal pricing | wholesale, internal price |
| Media | images, raw image URL |
| Secrets | API keys, tokens |

### Forbidden invented claims (inherited v6.3B)

| Claim | Rule |
|-------|------|
| km/l | ❌ must not invent |
| ไม่เคยชน / never crashed | ❌ must not appear |
| ไมล์แท้ / genuine mileage | ❌ must not appear |
| รับประกัน / warranty certainty | ❌ must not appear |
| ประหยัดแน่นอน / fuel certainty | ❌ must not appear |

Preview ใช้ **soften + omit** seller overclaims — ไม่ amplify

## 10. Rollback Plan

| Trigger | Action | Scope |
|---------|--------|-------|
| Preview visible to wrong audience | Rebuild with `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED=false` → redeploy hosting | **hosting only** |
| Allowlist too broad | Rebuild with reduced allowlist → redeploy hosting | **hosting only** |
| Content/guard issue | Same as flag off rollback | **hosting only** |
| Any production concern | **Stop** — do not deploy production | — |

**Rollback must NOT touch:** Cloud Run, Firestore rules, production API, AI flags
