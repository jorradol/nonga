## 1. Vision & ขอบเขต v6.0H

### เป้าหมาย

เตรียม **readiness plan + guardrails** สำหรับเปิด paid AI provider จริง (Gemini / OpenAI) บน **staging/closed pilot** เพื่อทดสอบศักยภาพสูงสุดของน้องเอแบบ **AI First** โดย:

- ยัง **ไม่เรียก paid AI API** ใน v6.0H
- ยัง **ไม่เปลี่ยน user-visible response**
- กำหนดขั้นตอนเปิดที่ถูกต้อง: SuperAdmin brake, budget monitor, no-go zones, privacy/consent, rollback

## 3. Env & Secrets (design only — ห้ามใส่ค่าใน repo)

> **ห้าม commit ค่า secret จริง** — ใช้ Cloud Secret Manager / server env injection เท่านั้น

### Control flags (non-secret)

| Flag | Values | เก็บที่ |
|------|--------|--------|
| `NONGA_AI_PROVIDER` | `mock` \| `gemini` \| `openai` | Cloud Run env / staging config |
| `NONGA_AI_MODE` | `off` \| `low` \| `standard` \| `high` | Cloud Run env |
| `NONGA_AI_FIRST_ENABLED` | `false` \| `true` | Cloud Run env |
| `NONGA_AI_EMERGENCY_KILL_SWITCH` | `false` \| `true` | Cloud Run env + SuperAdmin |
| `NONGA_AI_BUDGET_DAILY_LIMIT` | number (USD or token cap) | Cloud Run env |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | number | Cloud Run env |

### Server-only secrets (future — **never in client bundle**)

| Secret name | Provider | หมายเหตุ |
|-------------|----------|----------|
| `GEMINI_API_KEY` | Gemini | server-side proxy only — ห้าม `VITE_*` |
| `OPENAI_API_KEY` | OpenAI | server-side proxy only — ห้าม `VITE_*` |

### Client vs server rule

```
Browser (Vite)  →  NEVER holds GEMINI_API_KEY / OPENAI_API_KEY
Cloud Run / API →  reads secret at runtime; redacts logs
```

## 5. Hard No-Go Zones

AI (mock or real) **ห้าม** produce actions or user-facing claims ใน zones ต่อไปนี้:

| Zone | ตัวอย่างที่ห้าม | Fallback |
|------|----------------|----------|
| **revenue write** | record fee, adjust revenue | blocked → deterministic |
| **settlement write** | settlement adjust write | blocked → deterministic |
| **payment** | process payment, charge card | blocked → deterministic |
| **invoice** | generate invoice | blocked → deterministic |
| **contact reveal without consent** | reveal phone, send buyer number | blocked → consent path only |
| **hallucinated listing facts** | price/model not in listingContext | askFollowUp — ไม่เดา |
| **credit-risk label / “ติดบูโร”** | ติดบูโร, blacklist credit label | refuse + template disclaimer |
| **legal/financial advice as final truth** | “ฟ้องได้แน่นอน”, “ผ่อนคุ้มแน่” | disclaimer + orchestrator facts |

### Enforcement layers

1. **Pre-call** — redact PII; strip forbidden intents from tool plan
2. **Post-call** — output scanner for no-go phrases
3. **SuperAdmin** — kill switch on repeated violations

## 6. Budget / Cost Guard

### Limits

| Guard | Flag / mechanism | Behavior |
|-------|------------------|----------|
| **Daily limit** | `NONGA_AI_BUDGET_DAILY_LIMIT` | warning at 80%; stop/downshift at 100% |
| **Monthly limit** | `NONGA_AI_BUDGET_MONTHLY_LIMIT` | warning at 80%; stop/downshift at 100% |
| **Per-conversation max turns** | config (future) | after N AI turns → template fallback |
| **Per-flow quota** | config per CAP/flow | dealer/buyer/seller caps separately |

### Auto downshift ladder

```
budget warning (80%)
    → alert SuperAdmin dashboard

budget stop (100%) OR repeated errors
    → downshift: high → standard → low → off

emergency kill switch
    → off immediately (highest priority)
```

### Metrics

| Metric | ใช้เมื่อ stage M |
|--------|------------------|
| **cost per useful conversation** | primary cost efficiency KPI |
| engagement | product value |
| lead conversion | business outcome |
| hallucination reports | safety |
| SuperAdmin downgrade events | operational control |

## 7. Privacy & Logging

| Rule | รายละเอียด |
|------|------------|
| **No raw phone/contact in AI logs** | redact `0[689]…` → `[phone-redacted]` |
| **Redact PII before provider call** | where possible — minimize payload |
| **Do not send buyer phone** | unless explicit consent **and** necessary for flow |
| **Log prompt metadata** | intent, cap IDs, paramsHash, token count — **not** full sensitive content |
| **Retention policy (concept)** | shadow/debug logs 30d; production AI logs 90d max; PII never raw |

### Consent alignment

- Buyer lead / contact share → existing CAP-09 consent modal — AI ห้าม bypass
- Seller reveal / outcome flows — **ไม่แตะใน v6.0H**

## 8. Fallback & Rollback

| Trigger | User-visible behavior |
|---------|----------------------|
| **Provider error / timeout** | legacy deterministic response (`chatSearchOrchestrator` + templates) |
| **Budget hit** | downshift mode or fallback to orchestrator |
| **Kill switch** | AI off immediately — template 100% |
| **Missing listing facts** | ask follow-up — no guessing |
| **No-go zone detected** | blocked intent → deterministic safe reply |

### Rollback procedure (concept)

1. SuperAdmin sets `NONGA_AI_EMERGENCY_KILL_SWITCH=true`
2. Effective mode = `off`; provider ignored
3. Verify user-visible = legacy path only
4. Post-incident: downshift ladder before re-enable
