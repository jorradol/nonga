## 2. UI Placement

**Decision: wire ใน existing admin route** — ไม่สร้าง public route ใหม่

| Location | Detail |
|----------|--------|
| Entry | `AdminDashboardView` → tab `ai-control` |
| Panel order | `AiControlStatusPanel` (v6.4C) → `SmartSalesAiControlPreview` (superadmin) → `AIControlCenter` |
| Route | ไม่มี route public ใหม่ — ใช้ admin dashboard ที่มีอยู่ |
| Guard | Admin dashboard มีอยู่แล้ว — ไม่เปิด public debug endpoint |

## 4. Role Visibility

### Superadmin read-only view

- เห็นทุก card/section รวม role matrix ทั้ง admin + superadmin
- เห็นว่า real provider ยัง OFF
- เห็นว่า production forbidden
- **ไม่มีปุ่มเปิด real provider**

### Admin read-only view

- เห็น status summary, surfaces, usage/guard/fallback readiness labels
- เห็น admin permission summary
- **ไม่เห็น secret / full UID / raw prompt**
- **ไม่มีสิทธิ์เปิด real provider** (`adminCanEnableRealProvider() === false`)
