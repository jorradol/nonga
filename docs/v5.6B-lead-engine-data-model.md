## Status / Enum

### `BuyerLeadStatus`

`new` → `consented` → `seller_reviewing` → `contact_revealed` → `in_contact` → `viewing_scheduled` → terminal: `not_proceeded` | `closed_won` | `closed_lost` | `reported`

### `ContactRevealStatus`

`locked` | `revealed` | `outcome_required`

### `LeadContactOutcome` (หลัง reveal)

`contacting`, `viewing_scheduled`, `unreachable`, `no_progress`, `not_closed`, `closed_won`, `reported_to_admin`

UI หลักสำหรับ `no_progress`: **ไม่ได้ไปต่อ** (ห้ามใช้ “ไม่จบ”)

### `ListingSaleStatus`

`published`, `pending_sale`, `sold`, `sale_cancelled`, `hidden`

- `pending_sale` / `sold` → ซ่อนจาก marketplace (`shouldHideListingFromMarketplace`)
- `sale_cancelled` → กลับมาขายได้ (`canRelistAfterSaleCancelled`)

### `SettlementStatus`

`unbilled`, `pending_payment`, `partially_paid`, `paid`, `waived`, `disputed`, `cancelled`
