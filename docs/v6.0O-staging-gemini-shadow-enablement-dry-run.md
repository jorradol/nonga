## 8. Guards: Budget, No-go, Fallback

### Budget (required before enable)

| Control | Requirement |
|---------|-------------|
| `NONGA_AI_BUDGET_DAILY_LIMIT` | numeric cap — **ต้องกำหนดก่อนเปิด shadow** |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | numeric cap — **ต้องกำหนดก่อนเปิด shadow** |
| Budget hit | auto downshift / stop shadow Gemini calls |

### No-go zones (hard blocked)

| Zone | Rule |
|------|------|
| revenue write | ห้าม AI ใน revenue write |
| settlement write | ห้าม AI ใน settlement write |
| payment / invoice | ห้าม AI ใน payment/invoice |
| contact reveal | ห้าม reveal โดยไม่มี consent |
| listing hallucination | ห้ามแต่งข้อมูลรถที่ไม่มีใน listing |

### Fallback

- Shadow or Gemini provider error → **legacy deterministic** (`chatSearchOrchestrator` + templates)
- **`userVisibleResponse` ไม่เปลี่ยน** — shadow failure ไม่กระทบผู้ใช้
