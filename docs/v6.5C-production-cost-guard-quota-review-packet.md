## 4. Cost Risk Model

| ID | Risk | Impact | Required Guard | Stop Condition | Owner |
|----|------|--------|----------------|----------------|-------|
| CR-01 | **Accidental real provider activation** | Unbounded AI cost | Kill switch + provider OFF default | `realGeminiEnabled: true` without approval | Owner |
| CR-02 | **Missing quota cap** | Runaway spend | Per-scenario/per-run/per-day caps | Cap unset → **STOP** | Cost cap owner |
| CR-03 | **Missing per-user cap** | Abuse by single actor | Per-user/per-session cap | Per-user cap unset → **STOP** | Engineering |
| CR-04 | **Missing rate limit** | Traffic spike cost | RPM/RPD limits | Rate limit unset → **STOP** | Ops |
| CR-05 | **Runaway loop / repeated retry** | Retry storm cost | Retry cap + timeout cap | Retry loop detected → **STOP** | Engineering |
| CR-06 | **Unexpected high token usage** | Token cost spike | Token estimate bucket + per-run cap | Token bucket exceeds cap → **STOP** | Cost cap owner |
| CR-07 | **Monitoring/logging blind spot** | Undetected spend | Metadata-only cost monitoring | Monitoring blind spot → **HOLD** | Ops |
| CR-08 | **Kill switch unavailable** | Cannot stop spend | Kill switch before network (v6.4U) | Kill switch unavailable → **STOP** | Owner |
| CR-09 | **Provider error retry storm** | Error-driven retries | Retry cap + fail closed | Retry storm → **STOP** | Engineering |
| CR-10 | **Production traffic leakage** | Production cost exposure | Staging-only default | Production traffic detected → **HARD BLOCK** | Owner |
| CR-11 | **Abuse / scripted traffic** | Automated cost drain | Rate limit + abuse prevention | Abuse pattern → **STOP** | Ops |
| CR-12 | **Unapproved user-visible AI feature** | User-triggered cost | Separate UX approval | User-visible path without approval → **STOP** | Owner |
