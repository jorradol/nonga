## 5. Safe session boundary

| ขอบเขต | กฎ |
|--------|-----|
| ใครเป็นคน login | **operator/ลุง เท่านั้น** ในรอบ smoke execution (ไม่ใช่ slice นี้) |
| agent login | **ห้าม** — agent ไม่ login และไม่อ่าน credential |
| credential/session/cookie/token | **ห้ามส่งกลับมา** ทุกชนิด ไม่ลงใน repo/chat |
| ขอบเขต session | จำกัดเฉพาะ dealer portal ของ operator เอง — ไม่ cross-dealer |
| ปิด session | logout หลัง smoke เสร็จ ไม่ทิ้ง session ค้าง |
| evidence ที่ส่งกลับ | non-PII / count-only / status-only เท่านั้น |

**กฎ boundary:** safe session คือ session ที่ operator ควบคุมเองทั้งหมด โดย **ไม่มี credential/session/cookie/token ออกจากเครื่อง operator** มาที่ repo หรือ chat

## 7. Forbidden data list

| Forbidden | Reason |
|-----------|--------|
| Password / token / session / cookie / credential | credential leak |
| Buyer phone number | PII |
| Buyer email | PII |
| Buyer / seller real name | PII |
| Raw lead contact text | PII |
| License plate | sensitive vehicle ID |
| VIN | sensitive vehicle ID |
| Authorization header / API key | credential |
