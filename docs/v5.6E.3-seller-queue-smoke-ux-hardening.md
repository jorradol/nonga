## Smoke checklist (manual on staging)

1. Login as listing owner → **My Listings** → listing with buyer lead.
2. See **คิวผู้สนใจ (N คน)** panel with masked name, purchase method, budget, contact window, summary.
3. Queue #1 shows **ถึงคิวของคุณ** + enabled **ข้ามคิวนี้**; queue #2+ shows **รอผลคิวก่อนหน้า**.
4. No full phone anywhere in panel.
5. Skip requires reason; **อื่น ๆ** requires short note; after skip queue reorders, contact stays locked.
6. Non-owner account must not see seller queue API data (403).
