## 3. Tone direction

| Before (v6.3B.3) | After (v6.3B.4) |
|------------------|-----------------|
| `จุดเด่น` + bullet `- spec` | ย่อหน้าสั้นเล่าประโยชน์ จัดกลุ่มอุปกรณ์ |
| `เหมาะสำหรับผู้ที่มองหารถใช้งานตามสเปกที่แจ้ง` | ประโยคช่วยขายตาม body/fuel + ความสะดวกจากอุปกรณ์ |
| disclaimer ซ้ำ header/body | disclaimer ครั้งเดียวท้าย body |
| แสดง token ไม่รู้ความหมาย | omit token junk (spec code pattern, internal noise) |

### Feature groups (deterministic)

1. ความสะดวกในการขับ (เบาะ, พวงมาลัยมัลติฟังก์ชัน, cruise, ไฟ)

3. ความบันเทิงและการเชื่อมต่อ (จอทัช, FM/AM, Bluetooth, USB — consolidated)
4. ความช่วยเหลือเวลาจอด/ถอย (กล้อง, เซ็นเซอร์)
