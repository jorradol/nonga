# v5.6I.4a — Revenue UX Refresh + Admin Table Action Visibility

## ปัญหา

1. หลัง seller บันทึก outcome `closed_won` — My Listings / ยอดค่าบริการไม่อัปเดตจนกว่า reload browser
2. Admin revenue table — ปุ่ม «ปรับยอด» อยู่ท้ายตาราง ต้อง horizontal scroll จึงมองไม่เห็น

## Root cause (closed_won refresh)

`SellerMaskedLeadQueuePanel.handleOutcomeConfirm` เรียกแค่ `load()` ของคิว lead ภายใน panel — **ไม่แจ้ง** `MyListingsView` ให้ refetch listings / bump `revenueRefreshSignal`

## แก้ไข (frontend-only)

### A) Auto refresh หลัง closed_won

- เพิ่ม `onRevenueRelevantChange` จาก `SellerMaskedLeadQueuePanel` → `ListingLeadQueueSection` → `MyListingsView`
- หลัง `recordSellerQueueOutcome` สำเร็จและ `outcome === "closed_won"`:
  - `refreshListingsAndRevenue()` = `load()` + `fetchCars()` + `setRevenueRefreshSignal(Date.now())`
- ใช้ pattern เดียวกับ v5.6I.3b (cancel pending sale)
- `MyRevenueStatementSection` ยังใช้ stale guard + `refreshSignal` เดิม

### B) Admin action visibility

- ปุ่ม «ปรับยอด» ใต้คอลัมน์ รถ/listing (`admin-revenue-adjust-btn-*`) — มองเห็นโดยไม่ต้องเลื่อนถึงท้ายตาราง
- Mobile: การ์ดต่อแถว (`admin-revenue-preview-cards`) ปุ่มชัดที่หัวการ์ด
- Desktop: ตารางคอลัมน์ audit/note ยังเลื่อนได้ — มี scroll hint
- ไม่เพิ่ม payment / invoice / save
