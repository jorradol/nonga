## 2. AI/Gemini Control Plane

ระบบควบคุมกลางว่า AI provider อยู่สถานะไหน — **default ต้องเป็น OFF** เสมอ

### Provider states

| State ID | Label | ความหมาย | v6.4A |
|----------|-------|----------|-------|
| `OFF` | **OFF** | ไม่เรียก provider — deterministic/template เท่านั้น | ✅ **default** |
| `MOCK` | MOCK | mock provider — deterministic, no network, no paid API | design only |
| `STAGING_REAL` | STAGING_REAL | real Gemini — **staging-only**, allowlist + cap + approval แยก | design only |
| `DISABLED` | DISABLED | kill switch active — บังคับ off ทุก surface | design only |

### Control plane principles

1. **default OFF** — production และ staging ปัจจุบันต้องอยู่ที่ `OFF` จนกว่าผ่าน approval แยก
2. **real provider เปิดได้เฉพาะ staging + approval แยก** — ไม่มีทางเปิด real Gemini บน production ใน phase แรก
3. **kill switch** — Superadmin เปิด `DISABLED` ได้ทันที — highest priority override ทุก flag
4. **fallback deterministic เสมอ** — ทุก path ต้องมี deterministic fallback ก่อนแสดงผล user-facing

### Flag interaction (conceptual — ไม่ wire ใน v6.4A)

```
IF kill_switch = true OR provider_state = DISABLED
  → effective state = OFF, fallback deterministic 100%

ELSE IF provider_state = OFF
  → deterministic/template only (current behavior)

ELSE IF provider_state = MOCK
  → mock provider (no network, no paid API)

ELSE IF provider_state = STAGING_REAL
  → real Gemini ONLY IF:
       environment = staging
       AND surface approved
       AND user/session in allowlist
       AND cost guard not exceeded
  → else fallback deterministic

ELSE
  → fallback deterministic + log provider_blocked
```

### Shadow flag guardrail

| Flag | v6.4A allowed value | หมายเหตุ |
|------|---------------------|----------|
| `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` | **`false` only** | ห้ามตั้ง `true` ใน v6.4A — เปิดใน v6.4E หลัง approval แยก |

## 5. Cost Control

### Cap dimensions

| Cap ID | Dimension | Default (v6.4A design) | On exceed |
|--------|-----------|------------------------|-----------|
| CC-01 | **daily request cap** (global) | unset = block real provider | fallback deterministic |
| CC-02 | **per-surface cap** | unset = block surface real | fallback deterministic |
| CC-03 | **per-user/session cap** | e.g. 10 req/session | fallback deterministic |
| CC-04 | **cost guard (USD/token)** | daily ceiling | fallback + alert Superadmin |

### Cache & skip strategy

| Strategy ID | Rule |
|-------------|------|
| CS-01 | **per-listing cache** — cache deterministic output keyed by listing public fields hash |
| CS-02 | **no repeat generation** — ถ้า deterministic output acceptable แล้ว ไม่เรียก provider ซ้ำ |
| CS-03 | **cache TTL** — configurable per surface — default conservative |
| CS-04 | **cache invalidation** — เมื่อ public fields เปลี่ยน (brand/model/year/price/mileage/description) |

### Fallback when cap reached

```
IF any cap exceeded OR kill_switch = true
  → skip provider call
  → use deterministic fallback (listingDescriptionHelper / template)
  → increment fallback_count metric
  → log audit event (masked, no prompt)
```

### Usage summary (admin-visible, no sensitive data)

| Metric | Visible to Admin | Visible to Superadmin | Contains |
|--------|:----------------:|:---------------------:|----------|
| daily_request_count | ✅ | ✅ | aggregate count only |
| per_surface_count | ✅ | ✅ | surface ID + count |
| fallback_count | ✅ | ✅ | count + surface |
| guard_fail_count | ✅ | ✅ | count + guard rule ID |
| cost_estimate_usd | ❌ | ✅ (rounded) | no per-request detail |
| allowlist_hit_count | ❌ | ✅ | masked session count |

## 6. Prompt/Data Boundary

### Public-safe fields (allowed into AI context)

| Field ID | Field | Sanitization required |
|----------|-------|----------------------|
| PS-01 | brand | normalize |
| PS-02 | model | normalize |
| PS-03 | year | normalize |
| PS-04 | body type | normalize |
| PS-05 | fuel type | normalize |
| PS-06 | price (public listing price) | format only — no wholesale |
| PS-07 | mileage | format only |
| PS-08 | public description | **sanitize** — strip PII, plate, phone, LINE |
| PS-09 | public features | **normalize** — dedupe, expand safe abbreviations |

### Forbidden fields (never send to AI)

| Forbidden ID | Field | Reason |
|--------------|-------|--------|
| FB-01 | `licensePlate` / ป้ายทะเบียน | PII |
| FB-02 | `phone` / เบอร์โทร | PII |
| FB-03 | LINE ID / LINE URL | PII |
| FB-04 | full UID / Firebase UID | identity |
| FB-05 | wholesale / internal price | business secret |
| FB-06 | secret / env values | security |
| FB-07 | raw image URL | privacy + leakage |
| FB-08 | private admin notes | internal |
| FB-09 | raw prompt dumps with PII | privacy |

### Sanitization pipeline (future — v6.4B+)

```
listing public fields
  → strip forbidden fields (hard block list)
  → redact PII patterns (phone, LINE, plate)
  → normalize features/description
  → hash for cache key (no UID in hash)
  → pass to provider OR fallback if sanitization fails
```

## 7. Output Guard

AI output ต้องผ่าน guard ก่อนแสดง — ถ้า guard fail → **fallback deterministic**

### Guard rules

| Guard ID | Rule | On fail |
|----------|------|---------|
| OG-01 | **no forbidden claims** — ไม่เคยชน, ไมล์แท้, สภาพนางฟ้า | fallback |
| OG-02 | **no hype** — ประหยัดแน่นอน, ขายดีที่สุด | fallback |
| OG-03 | **no PII** — phone, LINE, plate, address | fallback |
| OG-04 | **no price/finance claim ที่ไม่มีข้อมูล** — ฟรีดาวน์, ผ่อน 0% | fallback |
| OG-05 | **no km/l unless real data exists** | fallback |
| OG-06 | **no accident/condition ownership claims** | fallback |
| OG-07 | **no secret/raw URL** in output | fallback |
| OG-08 | **no mixed Thai/Latin corrupted tokens** | fallback |
| OG-09 | **caveat required** — จากข้อมูลประกาศ / ควรตรวจสอบสภาพรถจริงก่อนตัดสินใจ | fallback if missing |

### Guard pipeline (conceptual)

```
provider output (mock or real)
  → run output guard rules OG-01..OG-09
  → IF all pass → sanitize display → show
  → IF any fail → increment guard_fail_count → deterministic fallback
```

### Unsupported claim guard (cross-ref v6.3A)

ห้าม output ที่ขยายเกินข้อมูลต้นทาง — อ้างอิง v6.3A Forbidden Transformations และ v6.2D legal compliance

## 8. Audit Log Readiness

Audit log แบบไม่เก็บข้อมูลเสี่ยง — **no full UID, no secret, no raw prompt**

### Audit event schema (design only)

| Field | Format | Example |
|-------|--------|---------|
| `event_id` | uuid | `evt_***` |
| `timestamp` | ISO 8601 | `2026-06-12T10:00:00Z` |
| `actor_id` | **masked** | `adm_***xyz` |
| `actor_role` | enum | `superadmin` \| `admin` |
| `action` | enum | `provider_state_change` \| `kill_switch` \| `cap_change` \| `surface_approval` \| `guard_fail` \| `fallback` |
| `surface` | surface ID or `global` | `S-01` |
| `previous_status` | state enum | `OFF` |
| `new_status` | state enum | `STAGING_REAL` |
| `reason` | free text (sanitized) | `staging pilot approval` |

### Audit redaction rules

| Rule | Detail |
|------|--------|
| AR-01 | **no full UID** — actor และ subject ต้อง masked เสมอ |
| AR-02 | **no secret** — ห้าม log env value, API key, token |
| AR-03 | **no raw prompt** — ห้าม log prompt/response content |
| AR-04 | **no PII** — ห้าม log phone, LINE, plate, address |
| AR-05 | **reason sanitized** — strip PII patterns ก่อน persist |

### Superadmin audit summary (masked/redacted)

- รายการเปลี่ยนแปลง control setting ล่าสุด (masked actor, surface, status transition)
- guard fail / fallback trend (aggregate)
- cost guard trigger events (no per-request detail)

### Admin audit view (limited)

- เห็น aggregate guard fail / fallback count
- เห็น surface status changes (no actor full ID)
- ไม่เห็น cost detail ระดับ request
