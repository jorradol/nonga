# v5.6I.4d — Global Scrollbar Thumb Color Polish

## ปัญหา (manual smoke)

Scrollbar thumb สีจืด มองไม่ชัด — ต้องการให้ผู้ใช้เห็นว่าเลื่อนได้ตรงไหน

## แก้ไข (frontend-only, สีเท่านั้น — ทั้งระบบ)

### Global (`src/index.css`)

- Firefox: `* { scrollbar-color: #f97316 transparent; }`
- WebKit global:
  - thumb: `#f97316` (orange-500)
  - hover: `#ea580c` (orange-600)
  - active: `#c2410c` (orange-700)
  - track: transparent
- ขนาดเดิม: `width/height: 6px` (ไม่เปลี่ยน)

### Header nav (`.header-nav-scroll`)

- อัปเดตสี thumb ให้ตรง global
- `height: 5px` เดิม (ไม่เปลี่ยน)

### Chat

- ลบ `scrollbar-thumb-slate-*` ที่ override สี global (คง `scrollbar-thin` ไว้)

### ลบ scope เฉพาะ Admin Revenue

- ไม่ใช้ `.admin-revenue-scrollbar` อีกต่อไป — global ครอบคลุมแล้ว
