## 3. Incident severity levels

> ใช้จัดระดับความรุนแรงเพื่อกำหนดความเร็วในการหยุดและ escalate ทุกบันทึกต้องเป็น **non-PII**

| Severity | ระดับ | นิยาม / ตัวอย่าง | การกระทำ |
|----------|-------|------------------|----------|
| **SEV-0** | **Critical** | PII / raw contact leak, cross-dealer lead leak, unauth sees lead queue, wrong-scope reveal, production / env / import touched without approval | **STOP ทันที** + immediate stop procedure (§5) + escalate owner |
| **SEV-1** | **High** | masking inconsistent, dealer queue count mismatch, reveal/skip/outcome controls suspicious, SOP violation | หยุด pilot action ที่เกี่ยวข้อง + escalate operator/owner |
| **SEV-2** | **Medium** | UI confusion, incomplete evidence, monitor field missing | บันทึก + วางแผนแก้ใน follow-up slice |
| **SEV-3** | **Low** | docs / runbook wording issue, non-blocking checklist improvement | บันทึกเป็น improvement (non-blocking) |

**กฎ severity:** ถ้าไม่แน่ใจระหว่างสองระดับ ให้เลือก **ระดับที่รุนแรงกว่า** (fail-safe) และห้าม downgrade SEV-0 โดยไม่มี owner sign-off

## 7. Privacy-safe incident log format

> บันทึก incident ด้วย field แบบ **non-PII** เท่านั้น ตัวอย่างเป็น placeholder ไม่ใช่ข้อมูลจริง

| Field | ชนิด | คำอธิบาย (non-PII) | ตัวอย่าง placeholder |
|-------|------|---------------------|----------------------|
| `incident_id` | label | รหัส incident แบบ generic | `INC-001` |
| `date` | date | วันที่พบ | `YYYY-MM-DD` |
| `environment` | label | สภาพแวดล้อม | `staging` |
| `severity` | enum | SEV-0..SEV-3 | `SEV-0` |
| `trigger_id` | label | NG-01..NG-12 | `NG-01` |
| `dealer_scope_label` | label | scope label แบบไม่ใช่ข้อมูลลับ | `scope-A` |
| `affected_rows_count` | count | จำนวน row ที่กระทบ (count เท่านั้น) | `0` |
| `masking_observed` | boolean | masking ทำงานหรือไม่ | `false` |
| `reveal_outside_scope_count` | count | จำนวน reveal นอก scope | `0` |
| `incident_flag` | boolean | ยืนยันเป็น incident | `true` |
| `operator_initials_role` | label | initials/role ไม่ระบุตัวตนละเอียด | `op-1 / dealer-role` |
| `status` | enum | open / contained / resolved | `open` |
| `notes` | text (no PII) | หมายเหตุไม่มี PII | `no raw contact recorded` |

**กฎ log:** ทุก field เป็น count / status / label เท่านั้น `notes` ต้อง **ไม่มี** PII / raw contact / plate / VIN / token / secret
