## 1. Vision & Scope

## 4. Redaction Rules

ก่อน dry-run pass — ทุก field ใน import package ต้องผ่าน redaction:

| # | Data type | Rule |
|---|-----------|------|
| RD-01 | เบอร์โทรจริง | **mask หรือตัดออก** — ห้ามอยู่ใน package |
| RD-02 | ชื่อเจ้าของจริง | **ต้องไม่อยู่** — ใช้ sellerDisplayName non-PII |
| RD-03 | LINE ID จริง | **ต้องไม่อยู่** |
| RD-04 | ที่อยู่จริง | **ต้องไม่อยู่** — province only |
| RD-05 | เลขทะเบียนเต็ม | **mask** ถ้าไม่จำเป็น |
| RD-06 | UID / prompt / secret | **reject** |
| RD-07 | รูปเอกสาร/บัตร/ใบเล่ม/สัญญา/หลักฐานการเงิน | **reject** |
| RD-08 | รูปมีเบอร์/LINE/ที่อยู่ | **reject or blur** |
| RD-09 | customer data | **reject** |

Redaction ทำ **ก่อน** dry-run final pass — ไม่ commit redacted file ลง git ถ้ายังมี real listing refs

## 5. Dry-run Output

Dry-run สร้าง **ops record นอก repo** — template ด้านล่าง (no PII):

### 5.1 Summary fields

| Field | Content |
|-------|---------|
| batchId | masked opaque ID |
| dryRunDate | ISO8601 |
| reviewer | name |
| carsTotal | N (5–10) |
| carsPassed | count |
| carsFailed | count |

### 5.2 Per-car result (no PII in reasons)

| Field | Example |
|-------|---------|
| listingRef | `car-01` (not real ID in git) |
| result | PASS / FAIL |
| failReason | `PII-09`, `DR-20`, `RD-07` (code only) |

### 5.3 No-go reasons (coded — no PII)

| Code | Meaning |
|------|---------|
| NG-PII | PII found — redaction required |
| NG-IMG | Image safety fail |
| NG-STALE | Sold/reserved/stale price |
| NG-DQ | Data quality incomplete |
| NG-RIGHTS | Consent/image rights missing |
| NG-RB | Rollback not ready |

### 5.4 Sign-off and recommendation

| Item | Required |
|------|----------|
| **reviewer sign-off** | name + datetime (ops channel) |
| **rollback readiness status** | ready / not ready |
| **recommendation** | **GO** / **FIX REQUIRED** / **NO-GO** |

### 5.5 Recommendation rules

| Recommendation | Meaning | Next step |
|----------------|---------|-----------|
| **GO** | all DR checks pass, redaction OK | request approval phrase §6 — **still no import** |
| **FIX REQUIRED** | fixable issues (PII, missing field) | ops fixes package, re-run dry-run |
| **NO-GO** | blockers (no rights, sold, no rollback) | stop — do not request import |

**ยังไม่ import แม้ dry-run ผ่าน (GO)** — ต้อง approval phrase + execution record แยก
