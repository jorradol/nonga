## 6. Redaction / Minimization Rules

| Rule ID | Rule |
|---------|------|
| RM-01 | Redact **before** provider payload construction |
| RM-02 | Redact **before** logging |
| RM-03 | Redact **before** persistence |
| RM-04 | Allowlist metadata over denylist text |
| RM-05 | No long free-text in metadata fields |
| RM-06 | No reversible hashing for PII without explicit approval |
| RM-07 | Use non-reversible correlation ID only |
| RM-08 | Coarse buckets for cost/latency/token — no raw values |
| RM-09 | Fail closed if redaction status unknown |
| RM-10 | `redactionApplied: true` required before reviewable metadata |
| RM-11 | `redactionApplied: false` blocks logging/provider/persistence |
| RM-12 | Redaction failure → block + fallback/stop (v6.4K RR-10) |

**v6.4K placeholders:** `[REDACTED_PROMPT]`, `[REDACTED_USER]`, `[REDACTED_CONTACT]`, `[REDACTED_VEHICLE_ID]`, `[REDACTED_SECRET]`, `[REDACTED_PROVIDER_PAYLOAD]`
