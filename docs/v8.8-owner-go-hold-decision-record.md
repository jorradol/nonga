## 4. Decision Options (HOLD / GO / NO-GO)

### 4.1 HOLD

- **meaning:** ชะลอการเดินหน้า runtime proof และคงสถานะเอกสาร/การตรวจสอบเชิง static ต่อไป
- **allowed next action:** อัปเดตเอกสาร, ตรวจรายการ readiness, และทำ static validation only
- **forbidden action:** ห้ามเริ่ม runtime execution หรือ runtime activation ใดๆ
- **risk note:** ความเสี่ยงหลักคือ timeline ช้าลง แต่ลดความเสี่ยงด้านการเปิดระบบก่อน owner พร้อม
- **required owner sign-off text:** `I confirm HOLD. Do not proceed to runtime; continue documentation/checking only.`

### 4.2 GO

- **meaning:** owner อนุญาตให้ไปขั้นเตรียมถัดไปเพื่อ runtime proof แบบ limited admin-only เท่านั้น
- **allowed next action:** เดินหน้าขั้น preparation ถัดไปสำหรับ limited admin-only runtime proof ภายใต้ขอบเขตควบคุม
- **forbidden action:** ห้ามเปิด buyer-facing/user-visible AI, ห้าม production, และห้าม real lead sending
- **risk note:** แม้เป็น GO ก็ยังมี execution risk หาก boundary/guardrail ไม่ครบ จึงต้องคง deterministic precedence และ safety gate
- **required owner sign-off text:** `I explicitly sign GO for the next preparation step toward limited admin-only runtime proof only (not buyer-facing AI).`

### 4.3 NO-GO

- **meaning:** หยุดเส้นทาง Gemini runtime proof ไว้ก่อนในช่วงเวลานี้
- **allowed next action:** ปิด track runtime proof ชั่วคราว, บันทึกเหตุผล, และคง deterministic flow เป็นแกนหลัก
- **forbidden action:** ห้ามเตรียม execution ต่อใน track นี้จนกว่าจะมี owner directive ใหม่
- **risk note:** ความเสี่ยงคือเลื่อนการเรียนรู้จาก runtime proof แต่ลดความเสี่ยงด้านความปลอดภัย/การปฏิบัติการทันที
- **required owner sign-off text:** `I confirm NO-GO. Stop the Gemini runtime-proof track for now.`
