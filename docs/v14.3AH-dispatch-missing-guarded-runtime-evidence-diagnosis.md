## 9) Node async assertion analysis

Observed assertion:

```text
Assertion failed: !(handle->flags & UV_HANDLE_CLOSING), file src\win\async.c, line 76
```

Most likely cause in prior wrapper:

- explicit `process.exit(...)` calls in async flow immediately after fetch/response work
- on Windows, abrupt exit while libuv/undici handles are closing can trigger `async.c` assertions in some runtimes/tooling combinations

v14.3AH mitigation:

- removed abrupt `process.exit(...)` exits from wrapper path
- switched to `process.exitCode` at top-level completion/catch
- HOLD behavior remains fail-closed (non-zero exit), but with cleaner shutdown semantics

Root-cause confidence:

- probable: premature process termination during async handle cleanup
- not claiming absolute certainty without reproducer; mitigation is low-risk and fail-closed safe
