## 9. Static Data Handling Boundary

### Principles

| Rule | Detail |
|------|--------|
| Real vehicle data | ใช้ได้ **เฉพาะ** manual/static/offline **หลัง approval แยก (§21)** |
| End-customer PII | **ห้าม** — ตัดออกหรือหยุดก่อนใช้ |
| Plate number | **Masked only** (e.g. `XX-****`) — ห้าม full plate ใน shared files |
| Detailed live data in repo | **ห้าม commit** ข้อมูลรถจริงละเอียด/อ่อนไหวลง repo |
| Local/private storage | ถ้าต้องเก็บข้อมูลจริง → **ไฟล์ local/private** หรือ template **ไม่ถูก commit** จนกว่าจะมี policy แยก |
| v6.6H itself | **Does not collect** real vehicle data — packet only |

### Sensitive data — do not commit

- Full plate / full VIN
- Owner PII / end-customer contact
- Raw photos with contact overlay in repo
- Financial personal data

**If uncertain → stop → do not commit to repo**
