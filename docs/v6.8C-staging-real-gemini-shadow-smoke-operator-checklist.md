## 5. SS-01 — Admin shadow smoke checklist (primary)

| Step | Action |
|------|--------|
| 1 | ได้รับ operator approval ชัดเจน (บันทึกใน ticket/chat) |
| 2 | ยืนยัน staging service / revision |
| 3 | ยืนยัน `NONGA_AI_USER_VISIBLE_ENABLED=false` |
| 4 | ยืนยัน `NONGA_AI_EMERGENCY_KILL_SWITCH=false` (ชั่วคราว) |
| 5 | ยืนยัน `GEMINI_API_KEY` mounted |
| 6 | ใช้ **admin** Bearer token |

**Request:**

```http
POST https://<staging-host>/api/admin/sales-brain-shadow-smoke
Authorization: Bearer <admin-token>
Content-Type: application/json

{ "caseId": "SS-01" }
```

**Expected success fields:**

| Field | Expected |
|-------|----------|
| `success` | `true` |
| `readOnly` | `true` |
| `userVisibleOff` | **`true`** |
| `providerNetwork` | **`true`** |
| `realProviderGateReason` | `real_provider_call_ok` |
| `data.shadowDebugResult.provider` | `gemini` |
| `adminShadowDiag.geminiKeyPresent` | `true` |
| `adminShadowDiag.geminiModel` | `gemini-3.5-flash` |
| `data.userVisibleResponse` | legacy orchestrator text — **ไม่ใช่ raw Gemini ให้ end user** |

**Failure signals:** `providerNetwork: false`, `adminShadowRealProviderFallbackReason` มีค่า, `geminiHttpStatus` / `geminiErrorCode` ใน diag

## 7. Kill switch drill checklist

| Phase | Action | Expected |
|-------|--------|----------|
| Before smoke | `NONGA_AI_EMERGENCY_KILL_SWITCH=false` | Shadow flags active |
| During smoke | SS-01 (+ optional CP-02) | `providerNetwork: true` |
| Drill | Set `NONGA_AI_EMERGENCY_KILL_SWITCH=true` | |
| Verify SS-01 | POST SS-01 again | `providerNetwork: false`; gate reason kill switch / shadow blocked |
| Verify legacy | POST `/api/gemini/chat` (optional) | mock/fail-closed (v6.8B `legacyGeminiSafety`) |
| Verify orchestrate | POST `/api/ai/chat-user-visible-orchestrate` | mock pilot / legacy — no real Gemini |
| Synthetic offline | SS-05, CP-03 cases | mirror kill switch in harness |
