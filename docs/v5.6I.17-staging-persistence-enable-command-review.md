## Rollback commands — **ใช้เมื่อ smoke fail**

> ⚠️ **ใช้เมื่อ smoke fail** — Cloud Run staging **`nonga-staging`** เท่านั้น

```bash
# ใช้เมื่อ smoke fail — kill-switch กลับ memory
gcloud run services update nonga-staging \
  --project=nonga-ce93c \
  --region=asia-southeast1 \
  --update-env-vars=NONGA_SETTLEMENT_DATA_BACKEND=memory,NONGA_SETTLEMENT_FIRESTORE_WRITES_ENABLED=false,NONGA_SUCCESS_FEE_RECORD_ENABLED=false

# ใช้เมื่อ smoke fail — ยืนยัน revision
gcloud run services describe nonga-staging \
  --project=nonga-ce93c \
  --region=asia-southeast1 \
  --format="value(spec.template.spec.containers[0].env)"
```

| ผล | หมายเหตุ |
|----|----------|
| Writes หยุด | `assertWritesAllowed()` throw |
| Runtime memory | overlay in-process |
| Firestore docs ค้าง | ไม่ auto-delete |
