| เกณฑ์ | ความหมาย |
|-------|----------|

| **NEEDS FIX** | operator ไม่เข้าใจ no-go triggers หรือ evidence safety → ต้องทบทวนก่อน |

- PASS ได้ **เฉพาะ** dry-run understanding/rehearsal เท่านั้น

- dry-run **ไม่สามารถ** unblock Thor runtime import
- dry-run **ไม่สามารถ** ทำให้ pilot-ready หรือ production-ready
- ถ้า operator ไม่เข้าใจ no-go triggers หรือ evidence safety → **NEEDS FIX**
