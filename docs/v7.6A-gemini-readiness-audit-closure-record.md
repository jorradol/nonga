## 9. สรุป guardrails สำคัญจาก v7.6

- **Fail-safe gates:** production บังคับ off, kill switch ⇒ off ทั้งหมด, prerequisites (provider gemini + ai-first + mode != off + budget caps) ไม่ครบ ⇒ fallback deterministic
- **Default-deny user-visible gate:** allowlist ว่าง ⇒ deny ทั้งหมด, ไม่ log raw UID
- **Output safety:** finance guarantee / meta leak / unsourced EV / guessed address / brand voice / non-Thai / pipe echo / too short / incomplete sentence ⇒ retry แล้ว fallback deterministic
- **PII/PDPA:** forbidden prompt fields (licensePlate/phone/line/fullUid/wholesaleInternalPrice/…), log redaction, interest-memory PDPA guard
- **Lead flow:** phone จาก user เท่านั้น, consent จาก modal, createdLeadId หลัง confirmation เท่านั้น — AI ห้ามส่ง lead / สร้าง consent / เดา phone / สร้าง createdLeadId
- **Inventory grounding:** AI ห้ามแต่งราคา/รุ่น/ปี/เลขไมล์/สภาพรถ/ไฟแนนซ์/โปรโมชั่น/availability และห้ามเปิดเผย PII / ทะเบียนเต็ม / VIN
- **No buyer-facing queue count:** คงอยู่ (v7.3)

- **B1:** ยังไม่มี owner sign-off เปิด Gemini จริง (blocker)

blocker เหล่านี้ **ยังไม่ถูกปิด** ใน v7.6A — เป็นเพียงการ record เพื่อ go/no-go รอบถัดไป

## 11. deterministic flow ยังเป็น source of truth

- **deterministic flow เป็น source of truth** — AI เป็นชั้น "ภาษา/น้ำเสียง" บนผลลัพธ์ deterministic เท่านั้น ไม่ใช่ผู้ตัดสินใจ flow และไม่ใช่ source of truth แทน inventory จริง
- ทุก flow สำคัญ (search intent / lead capture / lead escape / preview / final confirmation / payment safety / no-results) ยังเป็น deterministic authority
- inventory จริงเป็น source of truth ของข้อมูลรถ — AI ห้าม override
