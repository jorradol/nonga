## Triple flags (เปิดพร้อมกันเมื่อถึงเวลาจริง)

| Env | ค่า enablement |
|-----|----------------|
| `NONGA_SETTLEMENT_DATA_BACKEND` | `firestore` |
| `NONGA_SETTLEMENT_FIRESTORE_WRITES_ENABLED` | `true` |
| `NONGA_SUCCESS_FEE_RECORD_ENABLED` | `true` |

`isDurableSettlementPersistenceActive()` = ครบทั้ง 3 — ดู `settlementPersistenceFlags.ts`

**Slice แรก (adjustment only):** อาจเปิด backend + writes โดย success fee ยัง off — แต่ durable active ยัง false

## Exact rollback plan (ยังไม่รัน)

```text
# Cloud Run staging ONLY — kill-switch
NONGA_SETTLEMENT_DATA_BACKEND=memory
NONGA_SETTLEMENT_FIRESTORE_WRITES_ENABLED=false
```

| ผล | หมายเหตุ |
|----|----------|
| Writes หยุด | `assertWritesAllowed()` throw |
| Runtime memory | overlay in-process |
