## 3. User-Visible AI Behavior Policy

Future policy — **does not execute in v6.5E**:

| ID | Policy | Requirement |
|----|--------|-------------|
| UVB-01 | **Truthful state labeling** | Every AI surface must show current provider state (mock/demo/not connected/real) |
| UVB-02 | **No silent real answers** | Real provider answers must never appear without explicit approved state + disclosure |
| UVB-03 | **Deterministic fallback first** | When provider blocked, show safe fallback — not empty silence that implies success |
| UVB-04 | **No impersonation** | AI must not claim to be human dealer/owner/support agent |
| UVB-05 | **No guaranteed outcomes** | AI must not guarantee price, availability, financing approval, or legal outcome |
| UVB-06 | **Scope boundary** | AI answers limited to approved product scope — no off-topic authoritative claims |
| UVB-07 | **Privacy-safe display** | No full UID, raw prompt, secret, or PII in user-visible output |
| UVB-08 | **Cost-aware UX** | No UI that encourages unlimited retries or hidden provider calls |
| UVB-09 | **Kill switch visibility** | Admin surfaces must reflect kill switch / provider OFF state accurately |
| UVB-10 | **Consistent cross-surface** | Chat, detail preview, admin legacy, and status panel must not contradict state labels |

**Current state (v6.5E):** All user-facing AI surfaces remain mock/demo/not connected — no real provider answers

## 4. Disclosure Wording Policy

Required disclosure elements for any future AI surface:

| ID | Element | Wording category |
|----|---------|------------------|
| DW-01 | Provider state badge | `Demo`, `Not connected`, `Mock`, or future approved `Real provider (approved)` |
| DW-02 | Capability disclaimer | "This response is [mock/demo/not connected] — not from a live AI provider" |
| DW-03 | Data handling note | "No raw prompts or personal data are sent to a real provider in this state" |
| DW-04 | Limitation note | "Answers may be placeholder — verify with official listing/dealer" |
| DW-05 | Admin-only detail | Technical metadata (providerMode, killSwitchState) — admin read-only only |
| DW-06 | No false urgency | No "LIVE SYNC", "Real-time Gemini", or equivalent without approved real state |

**v6.4C.2 alignment:** Legacy `AIControlCenter` already uses `Demo / Not connected`, mock analytics labels, safety banners — v6.5E policy extends this pattern to all future public surfaces

## 5. Mock / Demo / Not Connected Wording Policy

When `realGeminiEnabled: false` and `networkCallMade: false`:

| State | Required user-visible label | Required admin label |
|-------|----------------------------|----------------------|
| **Mock** | "Mock response" / "Placeholder answer" | `providerMode: mock` |
| **Demo** | "Demo mode — not connected to live AI" | `providerStatus: OFF` |
| **Not connected** | "AI not connected" / "Not connected to real provider" | `realGeminiEnabled: false` |

### Required wording (category examples — not runtime copy)

| Context | Approved pattern | Forbidden pattern |
|---------|-----------------|-------------------|
| Chat bubble | "[Demo] This is a placeholder response" | "I'm analyzing live market data now" |
| Status badge | `Demo / Not connected` | `LIVE SYNC` |
| Analytics panel | `Mock analytics — no live data source` | "Real-time provider metrics" |
| Error state | "AI unavailable — showing safe fallback" | Silent empty response implying success |

**Rule:** Mock/demo/not connected surfaces must **never** use language that implies real provider inference, live sync, or production AI

## 8. Fallback Behavior Policy

When provider blocked, kill switch ON, or cap exceeded:

| ID | Fallback rule | User-visible behavior (future plan) |
|----|---------------|-------------------------------------|
| FB-01 | **Deterministic safe message** | Show labeled fallback — not blank UI |
| FB-02 | **State-preserving label** | Fallback must retain mock/demo/not connected badge |
| FB-03 | **No retry storm UX** | Do not auto-retry provider in user-visible loop |
| FB-04 | **No fake success** | Do not show typing indicator implying real inference when blocked |
| FB-05 | **Admin visibility** | Admin panel shows `fallbackReasonCode` — metadata only |
| FB-06 | **Business path block** | Fallback must not trigger lead/payment/reveal/outcome mutation |
| FB-07 | **Privacy-safe fallback** | Fallback text must not echo raw prompt or PII |
| FB-08 | **Graceful degradation** | Prefer static helpful copy over error dump |

**v6.5E:** Fallback policy is review only — no runtime fallback path changed

## 9. No-User-Confusion Policy

Principles to prevent user misunderstanding:

| ID | Principle | Implementation (future plan) |
|----|-----------|------------------------------|
| NUC-01 | **State visible before answer** | Badge/label shown before or with every AI output |
| NUC-02 | **No mixed signals** | Admin mock label + public "live AI" forbidden |
| NUC-03 | **No stealth upgrade** | Mock→real transition requires approval + disclosure update |
| NUC-04 | **No silent provider switch** | User must not receive real answer without state change visible |
| NUC-05 | **Consistent terminology** | Same state words across chat, admin, status panel |
| NUC-06 | **No analytics theater** | Mock metrics must not look like live dashboards |
| NUC-07 | **No false progress** | Loading states must match actual provider state |
| NUC-08 | **Support clarity** | Future support scripts must align with disclosed state |

**Goal:** User must always know whether they are seeing mock, demo, not connected, or approved real provider output

## 10. Admin-Facing vs Public-Facing Wording Boundary

| Surface | Audience | Allowed content | Forbidden content |
|---------|----------|-----------------|-------------------|
| **Public chat / buyer UI** | End user | Mock/demo/not connected labels, safe fallback copy, scope disclaimers | Raw prompt, full UID, provider body, secret values, "live Gemini" when OFF |
| **Admin read-only status panel** | Admin | providerMode, providerStatus, killSwitchState, guardDecisionCode (metadata) | Raw prompt, PII, secret dump, provider request/response body |
| **Legacy AI Control Center** | Admin | Demo/not connected badges, mock analytics labels, config persistence warnings | "LIVE SYNC", false Gemini speed claims, live analytics theater |
| **Future real provider UI** | Admin + approved public | Approved real-state badge + scope disclaimer | Hidden real state, overclaim, impersonation |

**Boundary rule:** Admin surfaces may show more technical metadata — but never raw prompt, PII, secrets, or provider bodies in any surface
