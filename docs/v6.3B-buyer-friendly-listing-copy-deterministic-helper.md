## 2. Module API

### Input (whitelist — public-safe only)

`BuyerFriendlyListingCopyInput` — รับเฉพาะ fields ที่ buyer-facing ปลอดภัย (ตาม v6.3A §7):

- `description`, `brand`, `model`, `year`, `price`, `mileage`, `color`, `fuelType`, `condition`
- `features[]`, `tags[]`, `transmission`, `drivetrain`, `bodyType`, `province`, `sellerType`, `showroomName`

**ห้ามส่ง:** `licensePlate`, wholesale/internal price, `ownerPhone`, `ownerId`, LINE, UID, secret, raw image URL, full address

### Output

```typescript
interface BuyerFriendlyListingCopyResult {
  text: string;
  source: "template-rich" | "template-structured" | "fallback-minimal" | "fallback-original" | "empty";
  guardPass: boolean;
  warnings: string[]; // e.g. "seller-overclaim-omitted"
}
```

### Entry point

`buildBuyerFriendlyListingCopy(input)` — pure function, no side effects, no network

### Exported helpers (for tests)

- `sanitizeListingCopyText`
- `softenOmitOverclaims`
- `parseBuyerSpecTokens`
- `passesOutputGuard`
- `BUYER_FRIENDLY_SAFETY_DISCLAIMER`

---

## 3. Pipeline

```
Input (whitelist)
  → sanitize (strip phone/plate/URL/LINE/secret/wholesale keywords)
  → soften + omit seller overclaims
  → parse spec tokens (duplicated SPEC_MAP)
  → classify richness (rich | structured | minimal | empty)
  → compose deterministic template
  → output guard scan
  → pass → return template
  → fail → fallback-original + disclaimer
```

## 4. Allowed / Forbidden Rules

### Allowed transformations

| ID | Rule |
|----|------|
| AT-01 | เรียบเรียงภาษา / จัดหัวข้อ "จุดเด่น" |
| AT-02 | ขยายคำย่อปลอดภัย (`บ.` → `เบาะ`) ผ่าน SPEC_MAP |
| AT-03 | จัด bullet จาก features/tags/parsed tokens |
| AT-04 | ภาษาการตลาดสุภาพ — "เหมาะสำหรับผู้ที่มองหา…" |
| AT-05 | Safety disclaimer ทุก non-empty output |

### Forbidden (module ห้ามสร้างเอง)

| ID | Rule |
|----|------|
| FT-01 | แต่งสเปกที่ไม่มีใน input |
| FT-02 | สร้าง km/l |
| FT-03 | ไม่เคยชน / ไมล์แท้ / ประหยัดแน่นอน |
| FT-04 | รับประกัน / warranty / ฟรีดาวน์ / ผ่อน |
| FT-05 | plate / wholesale / phone / LINE / UID / secret / raw URL |

## 5. Seller Overclaim Policy

**Decision (approved): soften + omit**

ถ้า `description` เดิมมีคำฟันธง เช่น "ไม่เคยชน", "ไมล์แท้", "ประหยัดแน่นอน", "รับประกัน":

- **ห้าม amplify**
- **ห้าม copy เป็น claim ใหม่**
- **ตัดออก / ลดน้ำหนัก** ก่อนประกอบ template
- เพิ่ม `warnings: ["seller-overclaim-omitted"]`
- ปิดท้ายด้วย:

> จากข้อมูลประกาศ — ควรตรวจสอบสภาพรถจริง เอกสาร และทดลองขับก่อนตัดสินใจซื้อ

---

## 6. Fallback Tiers

| Tier | Source | Condition |
|------|--------|-----------|
| Rich | `template-rich` | description ≥ 24 chars + identity/specs |
| Structured | `template-structured` | brand/model หรือ structured fields |
| Minimal | `fallback-minimal` | partial identity เท่านั้น |
| Original | `fallback-original` | output guard fail → sanitized original + disclaimer |
| Empty | `empty` | ไม่มีข้อมูลเลย |

## 7. Data Boundary

- Input: public-safe whitelist only (v6.3A §7)
- Output: buyer-facing text — ไม่มี PII

- Logs: module ไม่ log input/output (consumer responsibility ใน slice ถัดไป)
