## 1. Executive summary

v7.0J สร้าง **result shell / evidence intake packet** สำหรับบันทึกผล authenticated dealer smoke จริงในอนาคต โดยเตรียมช่องกรอก (intake fields) แบบ **non-PII / count-only / status-only** ครบทุกขั้นตอนของ execution template ใน v7.0I — ทั้งหมดเป็น **shell ที่เริ่มต้น PENDING / NOT RUN** เพื่อให้ operator นำไปกรอกผลในรอบ smoke execution slice ภายหลัง (หลัง owner approve)

- เตรียม **evidence intake fields** สำหรับ future execution (execution date/time, operator identity แบบไม่มี credential, staging URL, safe pre-checks, login action result แบบไม่มี session/cookie/token, dealer dashboard visibility, lead queue isolation แบบไม่มี PII, cross-dealer leak check, Firestore write confirmation = NOT PERFORMED)

- กำหนด **abort/no-go conditions** + **credential/session prohibition** + **non-PII evidence rules**
- ระบุ **default final verdict = PENDING / NOT RUN** (ห้าม overclaim PASS)
- ระบุ **what this shell allows** และ **what this shell does not allow**
- ระบุ **missing items** ก่อน actual smoke execution, ก่อน Thor runtime import และก่อน Gemini user-visible pilot

slice นี้ **เป็นเอกสาร + static validation + npm script เท่านั้น** ไม่แตะ runtime / deploy / env / Firestore / Thor / Gemini และ **ไม่ใช่** การรัน authenticated smoke การมี result shell **ไม่ทำให้เกิด authenticated smoke PASS** และ **ไม่** unblock Thor/Gemini/public signup/production

## 6. Operator safe session boundary

| ขอบเขต | คำอธิบาย |
|--------|----------|
| operator login เองเท่านั้น | operator login ด้วยบัญชี dealer ของตนเองในรอบ execution เท่านั้น |
| agent ไม่ login | agent ไม่ login และไม่อ่าน credential ทุกกรณี |
| dealer scope เท่านั้น | session จำกัดเฉพาะ dealer ของตนเอง — ไม่ cross-dealer |
| logout หลังเสร็จ | logout / ปิด session หลัง smoke เสร็จทุกครั้ง |
| ไม่มี login ใน slice นี้ | login จริง **ยังไม่เกิด** ใน v7.0J — เป็น result shell เท่านั้น |

**กฎ:** safe session คือ session ที่ operator ควบคุมเองทั้งหมด — agent **ไม่** login, **ไม่** อ่าน credential/session/cookie/token ในทุกกรณี

## 8. Non-PII evidence rules

| กฎ | คำอธิบาย |
|----|----------|
| non-PII เท่านั้น | evidence ต้องเป็น non-PII / count-only / status-only เท่านั้น |
| count-only | บันทึกเป็น "จำนวน" หรือ label เท่านั้น — ไม่บันทึกค่าจริง |
| status-only | บันทึกเป็นสถานะ (accessible / not accessible / PASS / FAIL / PENDING / NOT RUN) เท่านั้น |
| ไม่บันทึก raw data | ไม่บันทึก raw data / un-redacted screenshot / raw lead row |
| ไม่มี PII | ไม่ใส่ phone / email / real name / license plate / VIN / raw contact |
| ไม่มี screenshot | ไม่แนบ screenshot ในเอกสารนี้ |
| บันทึกลง v6.7C-1-G | ผลจริง (ภายหลัง) บันทึกลง v6.7C-1-G แบบ non-PII เท่านั้น |

**กฎ:** evidence ทุกชิ้นต้องเป็น status / count / label เท่านั้น — ถ้ามี lead/contact/plate/VIN/raw buyer data โผล่ ต้อง abort และ **ไม่บันทึกลง repo/chat**
