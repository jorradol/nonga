## สรุป MVP

ให้ **เจ้าของรถ (listing owner / admin)** เปิดดูเบอร์ผู้ซื้อได้ **ทีละ 1 ราย** ตามลำดับคิว หลัง confirm สั้น ๆ ระบบบันทึก `leadContactLogs` (`contact_revealed`) และบังคับ **อัปเดตผลการติดต่อ** ก่อนเปิดคิวถัดไป

## สิ่งที่เปิดในรอบนี้

| รายการ | รายละเอียด |
|--------|------------|
| ปุ่มเปิดข้อมูลติดต่อ | เฉพาะคิวหัวที่ `contactRevealStatus === locked` และไม่มี lead ค้างรอ outcome |
| Confirmation | ข้อความบันทึก + ต้องอัปเดตผลก่อนคิวถัดไป |
| แสดงเบอร์ | เฉพาะ lead ที่ reveal แล้วใน queue response (สูงสุด 1 แถวไม่ mask) |
| Outcome UI | 6 ตัวเลือก: กำลังติดต่อ, นัดดูรถแล้ว, ติดต่อไม่ได้, ไม่ได้ไปต่อ, ปิดการขายได้, รายงานข้อมูลน่าสงสัย |
| API reveal | `POST /api/seller/buyer-leads/:leadId/reveal` → คืน `contactPhone` เฉพาะ lead ที่สำเร็จ |
| API outcome | `POST /api/seller/buyer-leads/:leadId/outcome` → ปล่อยคิวถัดไปเมื่อ terminal outcome |

## กฎนโยบาย (สรุป)

1. เฉพาะ owner ของ listing หรือ admin
2. Reveal ได้เฉพาะ **current queue head** ที่ยัง locked
3. ถ้ามี lead ที่ reveal แล้วแต่ยังไม่มี terminal outcome → **ห้าม** reveal คนถัดไป
4. Outcome แบบ `contacting` / `viewing_scheduled` → ยังบล็อกคิวถัดไป (ต้องอัปเดตผล terminal ภายหลัง)
5. Outcome `no_progress` / `unreachable` / `reported_to_admin` → ปล่อยคิวถัดไป
6. `closed_won` → mark lead `closed_won` (ยังไม่เปิด payment/settlement)
7. `reported_to_admin` → ไม่ auto-penalize buyer (admin review เท่านั้น)
8. Skip ก่อน reveal → ยังไม่เห็นเบอร์ (ไม่เปลี่ยน v5.6E)
9. ทุก reveal → log `contact_revealed`; outcome → log `outcome_updated`

## Privacy / UX

- ข้อความ: เบอร์ใช้เพื่อติดต่อซื้อขายรถคันนี้เท่านั้น
- Queue list ไม่เปิดเบอร์หลายแถวพร้อมกัน (`sellerQueueListNeverShowsFullPhoneOfOthers` ≤ 1 unmasked)
- ไม่มี export / copy ทั้งคิวใน UI

## Manual smoke (หลัง deploy รอบถัดไป)

1. Owner เปิด My Listings → คิวผู้สนใจ
2. คิวแรก → เปิดข้อมูลติดต่อ → confirm → เห็นเบอร์ + privacy notice
3. คิวที่สอง → ปุ่ม disabled + “รอผลคิวก่อนหน้า”
4. บันทึก outcome → คิวที่สองเปิด reveal ได้
5. Skip ก่อน reveal → ไม่เห็นเบอร์
6. Network: `POST …/reveal`, `POST …/outcome` — ไม่มี Firestore client write ไป lead collections
