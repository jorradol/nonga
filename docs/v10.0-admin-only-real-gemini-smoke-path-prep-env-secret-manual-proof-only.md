# v10.0 Admin-Only Real Gemini Smoke Path Prep (Env Secret / Manual Proof Only)

> **PREP ONLY / ADMIN-ONLY / MANUAL PROOF ONLY / FAIL-CLOSED DEFAULT**
> v10.0 รอบนี้เตรียมเส้นทาง manual smoke สำหรับ admin-only เท่านั้น โดยยังคงห้าม production/deploy/public route/buyer-facing AI/real lead และ normal tests ต้องไม่ยิง Gemini จริง

---

## 1. Scope of v10.0

- เพิ่ม manual smoke readiness payload สำหรับ admin runtime-proof path
- คุม gate ก่อน real provider call ให้ครบและ fail-closed
- แยก smoke adapter path สำหรับ admin/manual proof โดย default ยังไม่ยิง real provider
- ย้ำ env-secret only (`GEMINI_API_KEY`) และ block placeholder secret
- คง deterministic fallback เป็น source of truth

## 2. Explicit Non-GO in v10.0

- NOT GO for production
- NOT GO for deploy
- NOT GO for public route
- NOT GO for buyer-facing/user-visible AI
- NOT GO for real lead sending
- NOT GO for default runtime/provider activation

## 3. Manual/Admin-Only Gate Requirements

real provider call (ในอนาคต) ต้องผ่านครบทุกข้อ:

- admin-only route boundary only (`/api/admin/*`)
- manual proof mode required
- owner approval flag required
- kill switch must not be active
- secret env-only policy (`GEMINI_API_KEY`) and placeholder blocked
- quota/cost cap guard ready
- log redaction guard ready
- dry-run/readiness gate passed
- real provider activation flag required
- deterministic fallback always ready
- buyer/public flow has no entry to this path
- real lead sending is unrelated and remains off

## 4. v10.0 Fail-Closed Behavior

- default OFF remains (`AI_RUNTIME_PROOF_ENABLED` not enabled by default)
- `manualSmokeReadiness` payload added for admin diagnostics only
- manual smoke execution flag is required (`AI_RUNTIME_PROOF_MANUAL_SMOKE_EXECUTION`)
- even when readiness is green, process-level explicit enable is still required before any live call path
- deterministic fallback remains active when provider is not attached/disabled/fails

## 5. Secret, Privacy, and Logging Safety

- no real API key/secret in repo
- secret must come from environment only
- placeholder secret is blocked
- env secret value must not be exposed in payload/logs
- redaction guard continues to protect prompt/phone/VIN/token/secret-like value

## 6. Test and Boundary Confirmation

v10.0 test verifies:

- default/normal path still no real Gemini call
- default/normal path still no network/provider call
- normal tests do not depend on real secret
- kill switch blocks provider readiness
- manual/admin proof gate fail-closed
- placeholder secret blocked
- missing quota/cost guard blocked
- admin-only boundary remains
- no public route added
- no buyer-facing/user-visible AI enablement
- no real lead sending path
- deterministic fallback remains source of truth
