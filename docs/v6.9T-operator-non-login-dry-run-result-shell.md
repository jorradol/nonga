## 11. Pass/fail/needs-fix criteria

| เกณฑ์ | ความหมาย |
|-------|----------|
| **PASS (dry-run)** | DR-01..DR-10 + EP/NC understanding ทั้งหมด PASS + เข้าใจ no-go triggers + evidence safety |
| **NEEDS FIX** | มีข้อใดไม่เข้าใจ no-go triggers หรือ evidence safety → ต้องทบทวนก่อน |
| **FAIL** | operator ไม่ผ่านความเข้าใจหลัก เช่น credential safety หรือ non-PII format |

**ข้อจำกัดสำคัญของ PASS (dry-run):**

- dry-run PASS **ไม่ใช่** authenticated smoke PASS
- dry-run **ไม่สามารถ** unblock Thor runtime import
- dry-run **ไม่สามารถ** ทำให้ pilot-ready หรือ production-ready
- dry-run PASS หมายถึง "พร้อมซ้อม/เข้าใจขั้นตอน" เท่านั้น ยังต้องรัน authenticated smoke จริงภายหลัง
