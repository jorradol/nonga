# v5.6I.2 — Lead Success Modal Close + Revenue Preview Derived Rows

**สถานะ:** รอ review — ยังไม่ commit/deploy  
**หลักการ:** UX fix + read-only revenue derive — ไม่เปิด payment/settlement จริง

## A) Buyer lead modal auto-close

**Root cause:** หลัง API สำเร็จ `clearBuyerLeadCaptureContext()` ทำให้ preview เป็น null ขณะ `consentModalOpen` ยัง true — modal ค้างแสดงสถานะว่างจน user ปิดเอง

**Fix:**
- `useChat.submitBuyerLeadConsent` — เรียก `closeConsentModal()` **ก่อน** `addMessage`
- `BuyerLeadConsentModalHost` — เรียก `closeConsentModal()` เมื่อ `result.ok`
- ถ้า fail — modal ยังเปิด + แสดง error

## B) Revenue derived rows

**Helper:** `deriveAdminRevenuePreviewRowsFromListings()`  
**Source:** `adminState.cars` ที่ `saleStatus === "pending_sale"`  
**Price:** `closedDealPrice` ถ้ามี ไม่งั้น `listing.price` + label "ประมาณการจากราคาประกาศ"  
**Fee:** `hundred_thousand_floor_tier` via `calculateSuccessFeeByClosedPrice`  
**Status:** `unbilled`, paid=0, remaining=fee  
**Note:** "Preview จาก pending_sale ยังไม่เรียกเก็บเงินจริง"

**ยังไม่ทำ:** persist successFeeRecord, invoice, payment gateway
