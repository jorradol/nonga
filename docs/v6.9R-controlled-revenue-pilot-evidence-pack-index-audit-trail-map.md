## 4. Audit trail map

> สายหลักฐานจาก smoke runbook → operator result → gate checklist → SOP/playbook → readiness matrix → owner decision เพื่อให้ตรวจสอบย้อนกลับได้ว่า decision ใดอ้างอิง evidence ใด

```
E-02 smoke runbook (v6.7C-1-F)
   └─> E-03 operator smoke result shell (v6.7C-1-G)   [AWAITING OPERATOR RESULT]
          └─> E-06 readiness matrix (v6.9P)           [update after operator result]
                 └─> E-01 owner gate checklist (v6.9M) [PREPARE ONLY]
                        └─> E-07 owner decision packet (v6.9Q) [needs owner input]
                               └─> (separate) Thor runtime import approval  [BLOCKED]

E-04 ops SOP + lead monitor (v6.9N) ──┐
E-05 incident / no-go playbook (v6.9O)┴─> feed operational acceptance into E-06/E-07
```

| Step | From evidence | To evidence / gate | Trigger |
|------|---------------|--------------------|---------|
| A | E-02 runbook | E-03 operator result | operator รัน authenticated smoke |
| B | E-03 operator result | E-06 readiness matrix | บันทึกผล non-PII PASS/FAIL |
| C | E-04 + E-05 | E-06 readiness matrix | accept SOP + playbook |
| D | E-06 readiness matrix | E-01 owner gate checklist | matrix แสดง gate ครบ |
| E | E-01 + E-07 | owner approval | owner กรอก decision form (non-PII) |
| F | owner approval | Thor runtime import | **explicit separate approval** (ยัง BLOCKED) |

ทุก step ในตารางนี้ยัง **ค้างที่ step A** เพราะ operator ยังไม่ได้ส่งผล authenticated smoke จริง

## 10. Non-PII evidence format

evidence ทุกชิ้นบันทึก **เฉพาะ** รูปแบบเหล่านี้:

| Allowed | Example placeholder |
|---------|---------------------|
| Evidence ID + verdict | `E-03 = AWAITING OPERATOR RESULT` |
| Status flag | `TM-1 = MISSING` |
| Count (non-identifying) | `gates passed = 0` |
| Generic role label | `operator = op-1` |
| Redacted screenshot reference | `screenshot = redacted-01.png` |

| Forbidden | Reason |
|-----------|--------|
| Buyer phone / email / name | PII |
| License plate / VIN | sensitive vehicle ID |
| Session token / cookie / password | credential |
| Raw lead contact text | PII |
| Un-redacted screenshot | อาจมี PII/credential |
