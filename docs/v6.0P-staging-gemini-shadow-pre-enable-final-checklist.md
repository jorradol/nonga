## 3. Staging Budget Caps (Required Before Enable)

> **ห้ามเปิด shadow ถ้ายังไม่ใส่ตัวเลข budget cap ชัดเจน**

### Rules

| Rule | Detail |
|------|--------|
| **Must set numbers** | Operator ต้องใส่ **ตัวเลข staging cap** ใน enablement command ก่อนรัน |
| **No budget → no enable** | ถ้าไม่ระบุ `NONGA_AI_BUDGET_DAILY_LIMIT` และ `NONGA_AI_BUDGET_MONTHLY_LIMIT` → **ห้ามเปิด** |
| **Daily cap** | ต้อง **ต่ำพอ** สำหรับ closed pilot (แนะนำเริ่มต้น: **≤ 5 USD** หรือ token equivalent ที่เทียบเท่า) |
| **Monthly cap** | ต้อง **ต่ำพอ** สำหรับทดลอง (แนะนำเริ่มต้น: **≤ 50 USD** หรือ token equivalent) |
| **Budget hit** | auto **downshift → off → legacy deterministic fallback** |

### Placeholder for enablement (operator fills before DO NOT RUN YET command)

| Env var | Staging cap placeholder | Notes |
|---------|------------------------|-------|
| `NONGA_AI_BUDGET_DAILY_LIMIT` | `<explicit small staging cap required>` | e.g. `5` — must be explicit number |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | `<explicit staging cap required>` | e.g. `50` — must be explicit number |

**v6.0P ไม่ apply ตัวเลขใน repo** — operator บันทึกค่าที่เลือกใน ops log (ไม่ใส่ secret)

## 7. Rollback Commands — DO NOT RUN YET

> **⛔ DO NOT RUN YET** — rollback reference when shadow misbehaves or budget/kill switch drill

```bash
# ⛔ DO NOT RUN YET — emergency rollback to legacy deterministic
gcloud run services update nonga-staging \
  --project=nonga-ce93c \
  --region=asia-southeast1 \
  --update-env-vars="NONGA_AI_EMERGENCY_KILL_SWITCH=true,NONGA_AI_SHADOW_MODE_ENABLED=false,NONGA_AI_FIRST_ENABLED=false,NONGA_AI_MODE=off,NONGA_AI_USER_VISIBLE_ENABLED=false"
```

| Rollback lever | Env | Result |
|----------------|-----|--------|
| Kill switch | `NONGA_AI_EMERGENCY_KILL_SWITCH=true` | stop all AI paths |
| Shadow off | `NONGA_AI_SHADOW_MODE_ENABLED=false` | no shadow eval |
| AI First off | `NONGA_AI_FIRST_ENABLED=false` | orchestrator primary |
| AI mode off | `NONGA_AI_MODE=off` | legacy deterministic |
| User visible off | `NONGA_AI_USER_VISIBLE_ENABLED=false` | no AI reply to user |
| Provider/shadow error | automatic | **fallback legacy deterministic** (`chatSearchOrchestrator`) |
