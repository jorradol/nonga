## 3) Root cause

Signed-in staging chat calls Cloud Run:

`POST /api/ai/chat-user-visible-orchestrate`

via `applyChatUserVisibleServerBridge` in `useChat.ts`. That bridge runs `tryOrchestrateChatReplyCore` **on Cloud Run** and **overwrites** the Hosting-bundled orchestrator text with `bridged.userVisibleText`.

v22.21 deployed **Firebase Hosting only**. Cloud Run remained `nonga-staging-00183-z2t` with the old templates, so owner-browser (signed-in) still got:

- `ค้นเจอ 1 คันที่ตรงสเปกครับ…`
- `น้องเอจัดการ์ดไว้ด้านล่างให้แล้ว`
- `กด 'ดูรายละเอียดในแชท'`
- routine `ปังปุริเย่!`

Hosting bundle already had the v22.21 copy; the browser path that matters for signed-in owner was Cloud Run.

Also: v22.21 wording used default “ลุง” — not acceptable for general buyers.

## 4) Fix

1. Neutral buyer-facing inventory copy (no default “ลุง”, no UI CTAs, no routine cheer)
2. Remove old openers from `thaiSalesCopyVariation.ts` as well
