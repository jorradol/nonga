## 4. Adapter Skeleton Contract

### Path

`src/services/ai/realProviderAdapter.ts`

### Default state

| Property | v6.4F value |
|----------|-------------|
| `REAL_PROVIDER_ADAPTER_DEFAULT_ENABLED` | `false` |
| `realGeminiEnabled` | `false` (type literal) |
| `networkCallMade` | `false` (type literal) |
| `providerActivated` | `false` |
| `persistence` | `false` |
| `adminCanEnableRealProvider` | `false` |

### Provider modes

| Mode | Meaning |
|------|---------|
| `disabled` | Adapter not explicitly enabled (default) |
| `blocked` | Guard chain blocked (production, caps, kill switch, etc.) |
| `fallback-only` | All gates pass structurally but adapter still disabled in v6.4F |

### Metadata fields (audit)

| Field | Purpose |
|-------|---------|
| `providerMode` | disabled / blocked / fallback-only |
| `disabledReason` | Primary block reason code |
| `fallbackReason` | Always `deterministic_safety_disclaimer` in v6.4F |
| `guardResult` | Always `block` in v6.4F |
| `realGeminiEnabled` | Always `false` |
| `networkCallMade` | Always `false` |

### Entry point

```typescript
invokeRealProviderAdapterSkeleton(input, guardContext?)
// → always blocked + deterministic safety disclaimer fallback
// → no SDK, no fetch, no env, no secret, no network
```

## 5. Guard / Fallback Rules

Guard chain (priority order) — **ทุก path ใน v6.4F return block**:

| Priority | Condition | Reason code |
|----------|-----------|-------------|
| 1 | `adapterExplicitlyEnabled !== true` | `adapter_not_enabled` |
| 2 | `environment === "production"` | `production_forbidden` |
| 3 | `killSwitchActive === true` | `kill_switch_active` |
| 4 | `capsConfigured === false` | `caps_unset` |
| 5 | `stagingApprovalGranted === false` | `missing_approval` |
| 6 | `allowlistConfigured === false` | `missing_allowlist` |
| 7 | `adminCanEnableRealProvider() === false` | `admin_cannot_enable` |
| 8 | `isStagingRealProviderAllowed(...) === false` | `staging_gates_incomplete` |
| 9 | Fallback | `real_provider_disabled` |

**Fallback text:** `BUYER_FRIENDLY_SAFETY_DISCLAIMER` (deterministic, no provider call)

**Default config block:** `DEFAULT_AI_CONTROL_PLANE_CONFIG` มี caps unset → `caps_unset` หรือ `adapter_not_enabled`
