# v5.6E.4 — Seller Masked Queue UI Layout Fix

**Status:** Local fix (awaiting review — no deploy)  
**Issue:** Manual smoke v5.6E.3 — queue logic OK but My Listings panel buttons overlapped / looked unusable.

## Root cause

1. **My Listings card flex (`lg:flex-row` + `flex-wrap: nowrap`)** — queue panel sat as 4th flex sibling beside image, copy, and action buttons on desktop, squeezing the panel into a narrow column.
2. **`overflow-hidden` on panel root** — could clip skip form / tall action buttons at panel edges.
3. **Horizontal action row** — long Thai reveal label + skip button in one `flex-wrap` row caused cramped overlap on narrow card width.

## Fix (layout only)

- Panel: vertical stack — masked buyer details → queue status → full-width action column (reveal disabled, then skip).
- Skip form: separate block below list with `z-10`, column layout for reasons/note/confirm.
- All action buttons: `w-full`, `min-h-[2.5rem]`, column on all breakpoints inside row actions.
- Removed `overflow-hidden`; added `min-w-0`, `break-words` for long Thai text.
- My Listings article: `lg:flex-wrap` + panel wrapper `basis-full min-w-0` so panel spans full card width on its own row.

## Unchanged

Business logic, API, skip policy, privacy copy, reveal disabled state, payment, rules, migration.

## Manual smoke checklist

1. Owner → My Listings → listing with queue  
2. Reveal + skip buttons stacked, no overlap  
3. Tap skip → reason list + note + confirm visible and tappable  
4. Mobile: vertical layout, no horizontal overflow
