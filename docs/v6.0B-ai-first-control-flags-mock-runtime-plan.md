## 2. AI Mode Flags (env design)

> **หมายเหตุ:** flags ด้านล่างเป็น **design spec** — v6.0B ยังไม่ wire ลง Cloud Run หรือ runtime จริง

### Core flags

| Flag | Values | ความหมาย |
|------|--------|----------|
| `NONGA_AI_MODE` | `off` \| `low` \| `standard` \| `high` | Global AI tier — ควบคุมความลึกของ AI ใน conversation flows |
| `NONGA_AI_FIRST_ENABLED` | `false` \| `true` | เปิด AI First Evaluation Mode — ใช้ AI เป็นหลักใน allowed flows |
| `NONGA_AI_PROVIDER` | `mock` \| `gemini` \| `openai` | Provider ที่ใช้ — **v6.0B อนุญาตแค่ `mock` ใน implementation** |
| `NONGA_AI_BUDGET_DAILY_LIMIT` | number (USD หรือ token cap) | daily spend/token ceiling — trigger warning/stop |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | number | monthly spend/token ceiling |
| `NONGA_AI_EMERGENCY_KILL_SWITCH` | `false` \| `true` | เมื่อ `true` → บังคับ AI off ทันทีทุก flow |

### Mode semantics (`NONGA_AI_MODE`)

| Mode | Conversation AI | ใช้เมื่อ |
|------|-----------------|----------|
| `off` | ไม่เรียก provider — orchestrator/template เท่านั้น | production default, kill switch active |
| `low` | AI เฉพาะ high-value flow (seller copy, dealer draft) | downshift ขั้นแรก |
| `standard` | AI หลาย flow แต่ไม่เต็ม | downshift ขั้นกลาง |
| `high` | AI เต็มใน allowed conversation flows | staging/closed pilot target (เปิดภายหลัง) |

### Provider semantics (`NONGA_AI_PROVIDER`)

| Provider | v6.0B | หมายเหตุ |
|----------|-------|----------|
| `mock` | ✅ allowed (design + future impl) | deterministic responses, no network, no paid API |
| `gemini` | ❌ design only | เปิดใน v6.0D+ staging real high — ต้อง review แยก |
| `openai` | ❌ design only | future optional — ไม่ใน scope v6.0B |

### Flag interaction rules

```
IF NONGA_AI_EMERGENCY_KILL_SWITCH=true
  → effective mode = off, provider ignored, fallback template 100%

ELSE IF NONGA_AI_FIRST_ENABLED=false
  → use orchestrator/template (current behavior)

ELSE IF NONGA_AI_PROVIDER=mock AND NONGA_AI_MODE=high
  → mock runtime (no paid API, no network)

ELSE IF NONGA_AI_PROVIDER=gemini|openai
  → blocked in v6.0B — fallback template + log provider_blocked
```

## 3. Safe Defaults ตาม Environment

| Environment | `NONGA_AI_MODE` | `NONGA_AI_FIRST_ENABLED` | `NONGA_AI_PROVIDER` | `NONGA_AI_EMERGENCY_KILL_SWITCH` |
|-------------|-----------------|--------------------------|---------------------|----------------------------------|
| **Production** | **`off`** | **`false`** | `mock` (unused) | `false` |
| **Staging (current)** | **`off`** | **`false`** | `mock` | `false` |
| **Staging closed pilot (target — เปิดภายหลัง)** | **`high`** | **`true`** | `mock` → then `gemini` | `false` |
| **Local dev (mock default)** | `high` (when testing) | `true` (when testing) | **`mock`** | `false` |

### หลักการ default ที่ปลอดภัย

1. **production default = off** — ไม่มี AI First บน production จนกว่าผ่าน evaluation + ลุง review
2. **staging/closed pilot target = high** — แต่ **ต้องเปิดภายหลัง** ผ่าน staged rollout ไม่ใช่ default วันนี้
3. **local/mock default = mock** — developer ทดสอบ AI First ด้วย mock provider ไม่เรียก paid API
4. **budget limits** — unset = warning only in dashboard; set = enforce warning/stop
5. **kill switch default = false** — SuperAdmin เปิดเมื่อ incident

## 4. SuperAdmin Controls

ขยายจาก v5.6J / v6.0A — map ไปยัง flags ด้านบน

### Global controls

| Control | Maps to | รายละเอียด |
|---------|---------|------------|
| **Global AI mode** | `NONGA_AI_MODE` | off / low / standard / high |
| **AI First toggle** | `NONGA_AI_FIRST_ENABLED` | เปิด/ปิด evaluation mode |
| **Provider select** | `NONGA_AI_PROVIDER` | mock (v6.0B); gemini/openai disabled in UI |
| **Emergency kill switch** | `NONGA_AI_EMERGENCY_KILL_SWITCH` | ปิด AI ทันที — highest priority |

### Per-flow AI mode (downshift แยก flow)

| Flow key | ตัวอย่าง downshift |
|----------|-------------------|
| `buyerChat` | high → standard: ปิด AI polish, ใช้ orchestrator |
| `buyerSearchSummary` | high → off: template search only |
| `sellerDraft` / `sellerCopyAssist` | high → low: template copy |
| `dealerSuggestedReply` | high → standard: ลด generate quota |
| `priceNegotiation` | standard → off: template hint |
| `financeExplanation` | high → low: calculator only |
| `troubleshooting` | high → off: template advisor |
| `buyerLeadCapture` | **always off** — modal only |
| revenue / settlement / payment / invoice | **always off** — no-go zone |

### Downshift ladder

```
high  →  standard  →  low  →  off
         ▲ SuperAdmin manual downshift
         ▲ auto-downshift on budget stop
         ▲ emergency kill switch → off (immediate)
```

### Budget controls (SuperAdmin)

| Control | Flag / behavior |
|---------|-----------------|
| Daily limit | `NONGA_AI_BUDGET_DAILY_LIMIT` |
| Monthly limit | `NONGA_AI_BUDGET_MONTHLY_LIMIT` |
| **Budget warning** | 80% of limit → alert SuperAdmin, AI continues |
| **Budget stop** | 100% of limit → auto-downshift one tier + fallback template |

## 5. Mock Runtime Concept

### เป้าหมาย

จำลอง AI First **high** mode โดย:

- **mock responses** สำหรับ buyer / seller / dealer flows
- **no paid API** — ไม่เรียก Gemini/OpenAI
- **no network** — ไม่ fetch ภายนอก
- **no PII logging** — log แค่ flow/tier/latency/guard result
- **deterministic test outputs** — same input → same mock output (สำหรับ regression)

### Mock runtime architecture (v6.0C+ implement)

```
[Chat message]
      │
      ▼
[resolveAiFlags()] ── kill switch? → off
      │
      ▼
[NONGA_AI_PROVIDER=mock ?]
      │
      ├── NO  → fallback orchestrator (v6.0B behavior unchanged)
      │
      └── YES → [MockAiProvider]
                    │
                    ├── buyerMockResponses
                    ├── sellerMockResponses
                    └── dealerMockResponses
                    │
                    ▼
              [Output guards] → pass/fail → fallback if fail
```

### Mock response categories

| Category | Input signal | Mock output (deterministic) |
|----------|--------------|----------------------------|
| Buyer search summary | budget + body type | สรุปจาก inventory fixture + ถามกลับ 1 คำถาม |
| Buyer negotiation hint | offeredPrice + listingPrice | ข้อความต่อรองในกรอบ (ไม่รับปากราคา) |
| Buyer finance explain | calculator result inject | อธิบายค่างวด + disclaimer |
| Seller listing copy | listing fields | draft description จาก fields จริง |
| Seller lead reply | masked lead snapshot | คำถามถามกลับ + สรุป lead |
| Dealer suggested reply | carTitle + last message | draft ตอบลูกค้า |

### Mock provider contract (design)

```typescript
// v6.0C+ — not implemented in v6.0B
interface MockAiRequest {
  flow: "buyerChat" | "sellerDraft" | "dealerReply" | ...;
  tier: "high" | "standard" | "low";
  contextHash: string;  // no raw PII
  listingIds?: string[];
}

interface MockAiResponse {
  text: string;
  mockId: string;       // deterministic id for tests
  guardPass: boolean;
}
```

### Mock testing requirements

- Unit tests: same `MockAiRequest` → same `mockId` + `text`
- No `fetch`, no `generateContent`, no external SDK
- Fixture inventory ไม่ hallucinate — อ้าง carId จาก fixture เท่านั้น

## 6. AI No-Go Zones

> AI First เปิด AI กว้างใน **conversation** — แต่ zones ด้านล่าง **ห้าม AI เข้าไม่ว่า mode/provider ใด**

| Zone | ห้าม AI | เหตุผล |
|------|---------|--------|
| **Revenue write path** | ❌ | lead submit mutations, fee record creation |
| **Settlement** | ❌ | settlement adjustment write, audit mutations |
| **Payment** | ❌ | payment processing logic |
| **Invoice** | ❌ | invoice generation/mutation |
| **Contact reveal without consent** | ❌ | ห้าม AI reveal buyer phone/contact โดยไม่มี consent |
| **Listing facts not in source data** | ❌ | ห้าม AI แต่งข้อมูลรถที่ไม่มีใน listing/inventory |
| **Buyer lead modal submit** | ❌ | consent modal เป็น source of truth |
| **Seller reveal / outcome routes** | ❌ | flow ที่ใช้งานแล้ว — ห้ามแตะ |

Runtime assert (v6.0C+): ถ้า flow อยู่ใน no-go list → ไม่เรียก provider แม้ mode=high

## 7. Deterministic Fallback & Rollback

### Fallback triggers

| Trigger | Behavior |
|---------|----------|
| **AI fails** (error/timeout) | fallback to deterministic orchestrator/template |
| **Output guard fail** | ทิ้ง AI output → template |
| **Kill switch on** | AI off immediately — 100% template |
| **Provider blocked** (gemini in v6.0B) | fallback + log `provider_blocked` |
| **Budget stop** | auto-downshift one tier + fallback — ดู [§8](#8-budget-warning--stop--auto-downshift) |

### Fallback priority chain

```
1. chatSearchOrchestrator (skipGemini paths)
2. Role-specific templates (buyer / seller / dealer)
3. chatHelpOnboardingTemplates
4. Static error copy — no API retry loop
```

### Rollback playbook

1. SuperAdmin: **Emergency kill switch** → `NONGA_AI_EMERGENCY_KILL_SWITCH=true`
2. หรือ: set `NONGA_AI_MODE=off`, `NONGA_AI_FIRST_ENABLED=false`
3. หรือ: downshift high → standard → low → off ทีละขั้น
4. **ไม่กระทบ** lead submit / reveal / outcome / settlement routes

## 8. Budget Warning / Stop & Auto-Downshift

| Level | Threshold | Behavior |
|-------|-----------|----------|
| **Monitor** | always | log tokens/cost per request |
| **Daily budget warning** | ≥ 80% `NONGA_AI_BUDGET_DAILY_LIMIT` | alert SuperAdmin — AI continues |
| **Monthly budget warning** | ≥ 80% `NONGA_AI_BUDGET_MONTHLY_LIMIT` | alert + recommend downshift |
| **Budget stop** | 100% daily or monthly limit | **auto-downshift** one tier (high→standard→low→off) + fallback template |

### Auto-downshift on budget stop

```
high + budget stop → standard
standard + budget stop → low
low + budget stop → off
off → remain off, template only
```

Log event: `budget_stop_downshift` with `fromTier`, `toTier`, `limitType: daily|monthly`

## 11. Flag → Runtime Resolution (conceptual)

```
effectiveMode =
  if NONGA_AI_EMERGENCY_KILL_SWITCH → off
  else if !NONGA_AI_FIRST_ENABLED → off
  else NONGA_AI_MODE

effectiveProvider =
  if effectiveMode === off → none
  else if v6.0B → mock only (gemini/openai → blocked)
  else NONGA_AI_PROVIDER

canCallAi(flow) =
  effectiveMode !== off
  AND flow NOT IN noGoZones
  AND !budgetStopActive
  AND perFlowToggle[flow] !== off
```

**v6.0B:** function above is **spec only** — ไม่ implement ใน runtime รอบนี้
