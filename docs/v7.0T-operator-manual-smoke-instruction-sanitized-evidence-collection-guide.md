## 5. Manual smoke steps (operator)

> ขั้นตอนอ่านง่ายสำหรับ operator — login เองแบบ manual เท่านั้น

| Step | การทำงาน (operator) | ข้อควรระวัง |
|------|----------------------|--------------|
| ST-1 | เปิด staging URL | staging เท่านั้น — ห้าม production |
| ST-2 | login เองด้วยวิธี manual | ห้ามส่ง credential/OTP/password ให้ agent หรือ paste ที่ใด |
| ST-3 | ตรวจ landing / dashboard | สังเกตว่าโหลดได้ตามคาด — ไม่คัดลอกข้อมูลจริง |
| ST-4 | ตรวจ dealer / authenticated area | ดูเฉพาะ scope ของ dealer ตนเอง |
| ST-5 | ตรวจ lead queue / inquiry surface | **ไม่คัดลอกข้อมูลจริง** (ไม่ copy phone/email/name/plate/VIN) |
| ST-6 | ตรวจว่าไม่เห็น cross-dealer lead | ถ้าเห็นข้อมูล dealer อื่น → ABORT ทันที |
| ST-7 | logout / session cleanup | ปิด session ให้เรียบร้อย — ไม่ capture token/cookie |

**กฎ:** manual smoke steps ST-1..ST-7 ทำโดย **operator เท่านั้น** — agent ไม่ login, ไม่รับ credential, ไม่อ่าน session; operator สังเกตผลแล้วบันทึกเป็น sanitized text only
