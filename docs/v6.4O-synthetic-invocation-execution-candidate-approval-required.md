## 2. Purpose

### Core question

> ถ้าอนาคตจะทดสอบ real provider invocation ด้วย synthetic payload จริง ต้องมี payload แบบไหน ต้องผ่าน gates อะไร ต้องหยุดตรงไหน ต้อง verify อะไร และต้องขอ approval แยกอะไรบ้าง ก่อนจะ invoke provider หรือเปิด Gemini?

| v6.4O คือ | v6.4O ไม่ใช่ |
|-----------|-------------|
| Execution-readiness packet | Gemini invocation |
| Synthetic payload contract (future) | Prompt/provider sending |

| # | Gate | Required Evidence | Pass Criteria | Blocker if Missing | Owner / Approval |
|---|------|-------------------|---------------|-------------------|------------------|

| PX-02 | **Synthetic invocation approval** | Invocation ack separate | Explicit synthetic invoke approval | Assumed auto → **REJECT** | Owner |
| PX-03 | **Staging-only environment approval** | Environment = staging | Production forbidden | Production → **HARD BLOCK** | Owner + ops |
| PX-04 | **Secret wiring completed separately** | v6.4N/Q completion record | Wiring in approved future slice | Unwired → **BLOCK** | Security |
| PX-05 | **Secret binding verified by metadata only** | Binding metadata, no value | No secret in logs/repo | Secret exposed → **STOP** | Security |
| PX-06 | **Real provider activation approval** | Activation ack separate | No provider ON without approval | Auto-activate → **REJECT** | Owner |
| PX-07 | **Cost cap approval** | Cap values documented | Caps approved | Cap unset → **BLOCK** | Owner |
| PX-08 | **Kill switch approval** | Kill switch verified | Switch reachable | Unavailable → **STOP** | Ops |
| PX-09 | **Allowlist approval** | Allowlist configured | Surfaces limited | Missing → **BLOCK** | Engineering |
| PX-10 | **Rate limit / quota approval** | Quota policy documented | Limits defined | No quota → **HOLD** | Ops |
| PX-11 | **Redaction/logging contract approval** | v6.4K contract ack | Contract satisfied | Gap → **BLOCK** | Engineering |
| PX-12 | **Synthetic payload fixture review** | v6.4M fixtures pass | No real data | Real data → **STOP** | Engineering |
| PX-13 | **No user data guarantee approval** | FF-01..FF-14 checklist | All forbidden blocked | Gap → **BLOCK** | Engineering |
| PX-14 | **Monitoring metadata-only approval** | v6.4K §4 schema | No raw content logged | Raw logging → **STOP** | Engineering |
| PX-15 | **Fallback behavior approval** | Fallback test record | Deterministic fallback works | Untested → **BLOCK** | Engineering |
| PX-16 | **Rollback plan approval** | §9 acknowledged | Rollback owner named | No plan → **BLOCK** | Owner |
