## 7. Metadata-Only Verification Rules

อนาคต verify ได้ **เฉพาะ metadata** — ห้าม print secret value หรือ dump env:

| Verify Item | Allowed Method | Forbidden Method |
|-------------|----------------|------------------|
| Secret binding exists | Cloud Run service metadata / IAM audit | Print secret value |
| Env var binding name | Service spec metadata | `process.env` dump |
| Secret version reference | SM version metadata | Read secret payload |
| Service account access | IAM policy metadata | Export credentials |
| Real Gemini state | `realGeminiEnabled: false` | Provider invocation |
| Network state | `networkCallMade: false` | Live API call |
| User data | None sent | Any real payload |

**v6.4N invariant:** `realGeminiEnabled: false`, `networkCallMade: false`, no provider invocation, no user data sent
