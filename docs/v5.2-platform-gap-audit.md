# V5.2 Platform Gap Audit & Navigation Hardening

Date recorded: Tuesday May 26, 2026

Scope: audit user-facing routes, menus, and major feature surfaces after the v5.1 closed staging candidate passed core staging smoke. This checkpoint does not include secrets, passwords, tokens, or private user identifiers.

## Goal

Harden Nong A navigation for closed staging and the future public beta path without changing the core flows that already passed staging.

Core flows protected in this audit:

- Firebase role/auth behavior for member, dealer, admin, and superadmin.
- Dealer Portal create/save Draft.
- Draft publish guard.
- Chat-to-Draft.
- New image upload and render.
- `/api/health`.
- Firebase auth headers.
- Dealer scope isolation.

## Summary

Nong A is currently suitable for closed staging/internal demo of the core marketplace and dealer flows. Several platform surfaces exist as UI prototypes, sandbox tools, or simulated business systems. These should not be presented as production-ready features until they have real backend contracts, persistence, billing/payment integration, and public-beta copy.

Navigation hardening in this checkpoint:

- Hides sandbox AI/SEO growth tools from production/staging main navigation.
- Hides billing, boost, onboarding tour, and legacy dealer dashboard links from production/staging profile navigation.
- Keeps Dealer Portal visible to dealer/admin users.
- Keeps Chat-to-Draft and Sell flow visible to dealer/admin users only.
- Replaces placeholder footer resource links with disabled Coming Soon labels instead of live placeholder links.

## Hardening Notes

- Header main nav now hides sandbox tools in non-dev real staging/production builds.
- Dealer-only actions (`chat`, `sell`) are shown only to dealer/admin users.
- Profile dropdown no longer links production/staging users to billing, boost, onboarding, or the legacy dealer dashboard.
- Dealer Portal remains the supported dealer back office surface.
- Footer resource links no longer navigate to placeholder destinations.
