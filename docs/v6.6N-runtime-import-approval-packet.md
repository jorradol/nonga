## 6. Import mode proposal

### Recommended mode for first runtime import round

| Setting | Proposed value | Rationale |
|---------|----------------|-----------|
| **Disposition** | **Draft-only** — `processSmartInventoryImport({ drafts: rows, published: [] }, owner)` | ไม่ expose buyer-visible listings |
| **Published bucket** | `published: []` (zero rows) | ห้าม auto-publish |
| **Listing status** | Draft records only — `status: draft` or `needs_review` | Admin review ก่อน publish |
| **Marketplace visibility** | **No new published cars** | `listingStatus: published` path ไม่ถูกเรียก |
| **Auto-publish** | **Disabled** | ไม่เรียก `publishDealerDraftToMarketplace` |
| **Buyer/user visibility** | **None** | ไม่มี public listing exposure |
| **Image download** | Per-row from private Drive — **only after runtime import approval** | แยก gate |
| **Smart disposition override** | Force all 10 rows → `drafts` bucket regardless of confidence score | ป้องกัน smart-import auto-publish |

### Owner context per partition

แต่ละ partition import แยก commit ด้วย `ImportOwnerContext`:

```
{ dealerId: 'sim-1thor', ownerId: 'owner-sim-1thor', ... }
{ dealerId: 'sim-2thor', ownerId: 'owner-sim-2thor', ... }
{ dealerId: 'sim-3thor', ownerId: 'owner-sim-3thor', ... }
```

**Do NOT** use default `buildThorAutoOwnerContext()` (→ `thor-auto`) สำหรับ sim batch import

### Batch tracking

| Field | Proposed value |
|-------|----------------|
| `importBatchId` | `thor-activation-batch-v1` (tag ใน audit log / commit metadata) |
| `importedAt` | ISO timestamp at commit |
| `importedBy` | `admin-manual` or operator id |

ใช้ `importBatchId` สำหรับ rollback/cleanup
