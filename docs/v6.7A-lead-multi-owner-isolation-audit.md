## 5. Dealer lead access path

### Queue read (works for dealers)

`GET /api/seller/listings/:listingId/buyer-lead-queue`:

1. Load listing by id
2. `canViewSellerQueueForListing(auth, listing)` → admin **or** `canManageListingWithScope(scope, listing)`
3. `canManageListingWithScope`: dealer matches when `resolveCarDealerId(car) === scope.dealerId`

```311:318:src/server/ownerListingAccess.ts
export function canManageListingWithScope(
  scope: OwnerRequestScope,
  car: MarketplaceCarRecord
): boolean {
  if (scope.isAdmin) return true;
  if (scope.dealerId && resolveCarDealerId(car) === scope.dealerId) return true;
  return Boolean(scope.ownerId && scope.ownerId === car.ownerId);
}
```

### Queue mutations (dealer gap)

Skip/reveal/outcome routes check:

```106:107:src/server/buyerLeadQueueRoutes.ts

        return res.status(403).json({ success: false, message: "ไม่มีสิทธิ์ข้ามลีดนี้ครับ" });
```

For dealer listings: `lead.sellerId = "owner-sim-1thor"` but `auth.uid` = Firebase user id — **never equal**. Dealers can **view** queue but cannot **act** unless admin.

### Dealer portal

`dealerPortalRoutes.ts` has **zero lead endpoints**. Inventory/dashboard only. Real lead UI flows through **My Listings** (`/api/seller/*`), not dealer portal routes.

### Legacy `DealerLeads.tsx`

Hardcoded to `dealer-nongbot-01` via `useAnalytics` — disconnected from `BuyerLead` engine and sim partitions.

## 6. Member-owned listing lead path

**Supported at creation and queue read:**

- Member listing: `ownerId = member Firebase uid`, no `dealerId`
- Lead: `sellerId = listing.ownerId` (member uid)
- `canManageListingWithScope`: member when `scope.ownerId === car.ownerId`
- Skip/reveal/outcome: `lead.sellerId === auth.uid` ✅ aligns for members
- UI: `MyListingsView` → `ListingLeadQueueSection` per owned listing

**Member consumer seller flow:** When signed-in member is in sell flow, `shouldRunBuyerLeadCaptureTurn` is suppressed unless capture session already active (`chatMemberPendingListing.ts`).

**Dealer cannot see member leads:** Dealer scope requires `dealerId` match on listing; member listings have no `dealerId`.
