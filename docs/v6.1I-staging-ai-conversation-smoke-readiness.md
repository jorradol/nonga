## 2. Shadow Smoke vs Conversation Smoke

### Shadow smoke (ทำแล้วบางส่วน — v6.1B..H.4)

| Property | Detail |
|----------|--------|
| **Route** | `POST /api/admin/sales-brain-shadow-smoke` |
| **Who** | admin/superadmin only |
| **Input** | Fixed synthetic cases SS-01..SS-08 — **no custom prompt** |
| **Output** | Admin debug panel only — `userVisibleOff:true`, redacted |
| **Public impact** | **none** |
| **Real provider** | SS-01 only (when flag on) — verified v6.1H.4 |

### AI conversation smoke (ขั้นถัดไป — internal/staging)

| Property | Detail |
|----------|--------|
| **What it tests** | Multi-turn Sales Brain adapter behavior — intent, guardrails, fallback, budget |
| **Where** | **staging only** — admin-only route หรือ closed-pilot harness |
| **Who sees AI output** | **admin debug / shadow sink only** — ไม่แสดงต่อ public user |
| **Public `/chat`** | **ยัง legacy** — `NONGA_AI_USER_VISIBLE_ENABLED=false` |
| **Data** | Synthetic/mock listing only — **no real stock, no PII** |

> **ชัดเจน:** AI conversation smoke ในแผนนี้ = **ทดสอบบทสนทนา AI แบบ internal บน staging** ไม่ใช่การเปิด AI ให้ผู้ใช้ทั่วไปเห็นใน `/chat`
