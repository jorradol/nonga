## 15. Admin-Assisted Workflow

```
Owner/Admin → รับข้อมูลรถจาก dealer
           → ใส่/จัดข้อมูลใน staging/admin tool (manual)
           → ขอ AI draft (เมื่อมี execution approval แยก + cost guard)
           → Review draft ทุกข้อความ
           → แก้ไข/approve ก่อนส่งให้ dealer หรือ publish
           → Dealer ใช้ข้อความที่ approved แล้วเท่านั้น
```

**Rules:**
- ทุก AI output ต้องผ่าน manual review
- ห้าม auto-forward AI output ไปลูกค้า
- ห้าม auto-publish
- Admin เป็นคนกด approve ทุกครั้ง
