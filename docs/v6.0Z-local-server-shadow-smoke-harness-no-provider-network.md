## 1. Vision & Scope

### เป้าหมาย v6.0Z

สร้าง **local/server shadow smoke harness** สำหรับ `evaluateSalesBrainShadowRuntime` เพื่อ:

- ทดสอบ server-side shadow behavior แบบปลอดภัย (mock provider only)
- ยืนยัน **user-visible response เป็น legacy เสมอ**
- ยืนยัน **ไม่มี raw PII** ใน shadow debug/log JSON
- ยืนยัน **paid provider network disabled**

### Out of scope (v6.0Z)

- Cloud Run / Hosting / Firestore deploy
- `gcloud run services update` / env changes
- Staging debug HTTP endpoint
- Real customer data / phone / tent stock
- User-visible AI

## 5. Assertions

Harness verifies for every case:

| Assertion | Requirement |
|-----------|-------------|
| `userVisibleResponse` | Always equals input legacy text |
| Shadow debug JSON | No raw phone / email / contact data |
| Provider | `mock` only when shadow active |
| Network | `SALES_BRAIN_REAL_PROVIDER_NETWORK_ENABLED=false` |
| Paid Gemini | Not called — real adapter throws |
| Fallback | Deterministic when flags invalid / kill switch / budget missing |
| Production | `production_default_off` — shadow not allowed |
| No-go zones | payment/settlement/reveal paths — visible legacy unchanged |
