## 4. Architecture

```
Public /chat (browser)
  useChat → chatSearchOrchestrator → wireShadowChatPath (flags-only)
  legacy response → user (unchanged 100%)

Admin-only sink (server, v6.1K)
  POST /api/admin/chat-shadow-sink
    → adminApiAuth
    → runSalesBrainChatShadowSink (synthetic CP-01..CP-05)
    → evaluateSalesBrainShadowRuntime (mock shadow)
    → optional invokeChatShadowRealProvider (CP-02 only)
    → buildRedactedChatShadowSinkPayload
    → JSON response (sinkOnly, userVisibleOff) — NOT sent to public user
```

### Env flags

| Flag | Staging target | Notes |
|------|----------------|-------|
| `NONGA_AI_USER_VISIBLE_ENABLED` | **`false`** | v6.0R hard block unchanged |
| `NONGA_AI_ADMIN_SHADOW_REAL_PROVIDER_ENABLED` | `true` (existing) | SS-01 admin route — unaffected |
| `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` | **`false`** default | Set `true` only for CP-02 live pilot |
| `NONGA_AI_EMERGENCY_KILL_SWITCH` | `false` | Rollback: set `true` |
| `NONGA_AI_BUDGET_DAILY_LIMIT` | `5` | Unchanged |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | `50` | Unchanged |

### No browser provider call

- `NONGA_AI_*` env vars live on Cloud Run — not in client bundle
- `useChat.ts` / `chatSearchOrchestrator.ts` use `wireShadowChatPath` only — no `evaluateSalesBrainShadowRuntime`, no `GoogleGenAI`, no `GEMINI_API_KEY`
