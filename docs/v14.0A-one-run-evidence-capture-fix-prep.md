## 3) Root cause summary (read-only analysis)

Observed in `src/components/admin/OwnerFirebaseTokenHelperPanel.tsx`:

1. one-run response fields were parsed in handler logic.
2. panel mainly emitted a single status line and auto-cleared it.
3. no persistent structured evidence section existed for owner rubric review.
4. `userVisibleText` was not rendered as a dedicated sanitized evidence field.
5. missing-answer condition had no explicit warning banner.

Result: owner had run lock evidence, but not enough answer-quality evidence.
