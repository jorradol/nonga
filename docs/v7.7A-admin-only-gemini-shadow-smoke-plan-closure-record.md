## 10. สรุปสาระสำคัญของ v7.7 plan

- **Admin-only shadow principle:** ผลลัพธ์ AI (Gemini draft) ให้ admin เห็นเพื่อเทียบกับ deterministic output เท่านั้น — buyer/public ห้ามเห็น (no buyer-facing exposure)
- **Input policy:** ส่งให้ AI ได้เฉพาะ sanitized inventory summary / public car facts / deterministic intent / allowed context
- **Forbidden input fields:** phone, full license plate, VIN, full UID, secret, API key, internal price, wholesale price, raw owner/dealer private data, raw lead/contact data
- **Output policy:** AI ช่วยได้เฉพาะภาษา/น้ำเสียง/คำอธิบาย ห้ามแต่งข้อมูลรถ ห้ามการันตีไฟแนนซ์ ห้ามข้าม consent/final confirmation ห้ามชวนส่ง lead เอง ห้ามแสดง queue count ฝั่ง buyer
- **Deterministic authority map:** search result source / car cards / lead capture / phone capture / consent preview / final confirmation / queue policy / dealer-owner isolation / public DTO redaction
- **Fallback policy:** AI fail / timeout / unsafe output / hallucination risk / policy block / prompt injection ⇒ fallback deterministic ทั้งหมด
- **Shadow comparison method:** admin เทียบ deterministic vs AI draft, AI output ไม่ถูกส่งให้ buyer, บันทึก sanitized
- **Logging/redaction:** ห้าม log raw PII / plate / VIN / phone / secret / API key — ใช้ scenario id / reason code / pass-fail
- **Kill switch drill + Go/No-Go criteria:** ออกแบบไว้แล้ว — ต้องผ่านก่อนเปิด shadow รอบจริง
