## 4. Manual Smoke Success Criteria (Future Admin-Only Run)

- provider call เกิดเฉพาะ admin/manual boundary เท่านั้น
- output ต้องไม่หลุด secret / PII / prompt ดิบ
- fallback ต้องพร้อมทำงานทันทีเมื่อ provider fail
- quota/cost ต้องไม่เกิน cap ที่กำหนด
- buyer/public route ต้องไม่ได้รับผลกระทบ
- lead sending flow ต้องไม่ถูกแตะ

## 5. Manual Smoke Fail / Stop Criteria

หยุดทันทีถ้าเกิดข้อใดข้อหนึ่ง:

- พบ log มี secret/PII/prompt ดิบ
- มี network หรือ cost anomaly
- fallback ไม่ทำงานตามที่คาด
- buyer/public path ถูกกระทบ
- lead flow ถูกแตะ
- kill switch ปิด/เปิดกลับไม่ได้ทันที
- พบ secret ใน repo หรือ output artifact

## 6. Rollback / Stop Instruction

เมื่อพบความเสี่ยง:

1. ปิด manual smoke flag ทันที
2. เปิด kill switch ทันที
3. ลบ/rotate secret ทันทีถ้าสงสัยหลุด
4. กลับ deterministic fallback ทันที
5. หยุดทดสอบทันทีเมื่อพบ network/cost/log ผิดปกติ
6. ห้าม push secret หรือ evidence ที่มี PII/secret
