## 1. Vision & Scope

### เป้าหมาย v6.2B.4 (execution record slice)

สร้าง **Real Stock Data Package Dry-run Execution Record** แบบ **redacted summary** สำหรับบันทึกผล dry-run ตรวจ data package 5–10 คัน **นอก repo**:

- กำหนด **metadata ปลอดภัย** — ไม่ใส่ชื่อจริง/ข้อมูลรถจริงใน git
- กำหนด **result summary** — counts + coded no-go reasons only
- กำหนด **rights/consent, PII/image, quality, stale, AI grounding** result blocks
- ยืนยัน **import gate** — GO ใน ops ไม่เท่ากับ import
