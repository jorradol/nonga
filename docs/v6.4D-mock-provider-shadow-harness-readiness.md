## 4. Mock Provider Contract

### Provider kinds

| Kind | Meaning |
|------|---------|
| `mock` | Shadow/readiness simulation — deterministic, labeled mock |
| `disabled` | Default OFF gate path — deterministic copy, not labeled mock |
| `stagingRealReadiness` | STAGING_REAL blocked — fallback only, not enabled |

### Input (`MockAiPublicSafeInput`)

| Field | Rule |
|-------|------|
| `surfaceId` | One of v6.4B `AiControlSurfaceId` |
| `fields` | **Allowed prompt fields only** — forbidden keys blocked |
| `sessionSeed` | Optional deterministic seed — **not a UID** |

### Output (`MockAiProviderResult`)

| Field | Rule |
|-------|------|
| `text` | Public-safe copy after guard chain |
| `metadata.mock` / `metadata.shadow` | Explicit mock/shadow labeling |
| `metadata.realGeminiEnabled` | Always **`false`** |
| `metadata.network` | Always **`false`** |
| `metadata.persistence` | Always **`false`** |
| `deterministicHash` | Stable hash from allowed fields + surface |

### Entry points

- `runMockAiProvider(input, { shadowSimulation?: boolean })`
- `applyMockOutputGuardChain(text)`
- `detectForbiddenPromptFields(fields)`
- `deterministicMockHash(...)`

## 6. Guard / Fallback Chain

| Step | Behavior |
|------|----------|
| 1 | Reject / record forbidden prompt fields |
| 2 | Generate deterministic draft via buyer-friendly / golden seller helpers |
| 3 | `passesOutputGuard(text)` |
| 4 | On fail → `BUYER_FRIENDLY_SAFETY_DISCLAIMER` (deterministic fallback) |
| 5 | Metadata records `outputGuardApplied`, `fallbackUsed`, `outputGuardOnFail: deterministic` |

Policy source: `AI_OUTPUT_GUARD_POLICY` (v6.4B)
