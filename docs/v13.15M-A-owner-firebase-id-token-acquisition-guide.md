## 4) Owner manual steps (ภาษาไทยแบบปฏิบัติจริง)

1. เข้าระบบ staging ด้วยบัญชี Firebase owner/admin ตาม flow ปกติของระบบ
2. ยืนยันว่า session เป็น signed-in จริง (ไม่ใช่ guest/anonymous)
3. ดึง Firebase ID token จาก signed-in session โดยใช้วิธีของระบบที่อ้างอิงในโค้ด (`getCurrentUserIdToken()` / `getFirebaseAuthHeaders()`)
4. ตั้งค่า token ใน local shell/operator environment เท่านั้น (ชั่วคราว)
5. ห้าม paste token ลง chat เด็ดขาด
6. ห้าม echo token ลง terminal/log/docs
7. หลังใช้งานเสร็จให้ล้าง token ออกจาก session ทันที

คำสั่งย้ำสำหรับลุงเด่น/operator:

**ให้ตั้งค่า token ใน local shell/operator environment เท่านั้น แล้วรายงานกลับมาแค่ present/missing หรือ status code**
