## 1. บทนำสำหรับลุง/แอดมิน

### Closed pilot คืออะไร

| หัวข้อ | แนวทาง |
|--------|--------|
| **ใครเข้าได้** | เฉพาะคนที่ลุง **เชิญรายคน** — ยังไม่เปิดรับสมัครทั่วไป |
| **public signup** | **ยังปิด** — หน้าสมัครสมาชิกใช้ไม่ได้ |
| **ระบบ** | รอบ **ทดลองบน staging** — ไม่ใช่ production เต็มรูปแบบ |
| **เป้าหมาย** | ให้ผู้ทดลองลองคุยกับ **น้องเอ** ค้นหา/ลงประกาศ แล้วส่ง feedback |

### ลำดับงานก่อนส่ง LINE (ทีละคน)

1. **สร้างบัญชีใน Firebase Authentication** (Console โปรเจกต์ `nonga-ce93c`) — อีเมลที่ login ได้จริง  
2. ส่ง **Password reset** หรือวิธีตั้งรหัสทาง LINE ส่วนตัว (ห้ามโพสต์รหัสในกลุ่ม)  
3. Login แอดมิน → เปิด https://nonga-ce93c.web.app/admin/pilot-users  
4. กรอก **อีเมลผู้ทดลอง** → เลือก role (member / dealer) → บันทึก — **ไม่ต้อง copy UID เอง** (ระบบหาให้)  
5. ส่งข้อความ LINE ตามกลุ่ม (ข้อ 2–4 ด้านล่าง) + ลิงก์ staging  
6. บันทึกในตารางติดตาม (ข้อ 5)

### ข้อควรจำ

- **อย่าสัญญาว่าขายได้แน่นอน** หรือมีผู้ซื้อทันที — รอบนี้ทดสอบระบบ  
- **อย่าพูดค่าคอมมิชชั่น** — ยังไม่มีระบบชำระเงินจริง  
- น้องเอ **ไม่รับประกันสภาพรถ** — ผู้ซื้อต้องตรวจรถและเอกสารจริง  
- ถ้า provision ไม่ผ่าน → ตรวจว่าอีเมลมีใน Firebase Auth ก่อน

## 2. ข้อความ LINE — ผู้ซื้อรถมือสอง

ปรับ `[ชื่อ]` แล้วคัดลอกทีละก้อนได้

### 2.1 เชิญเข้าร่วมทดลอง

```
สวัสดีครับ/ค่ะ [ชื่อ]

ทีม Nong A ขอเชิญทดลองระบบ “น้องเอ” ช่วยค้นหารถมือสองแบบคุยในแชทครับ/ค่ะ
รอบนี้เป็นระบบทดลองแบบเชิญเท่านั้น ยังไม่เปิดให้สมัครเองทั่วไป

ถ้าสนใจร่วมทดลอง แจ้งกลับได้เลยครับ/ค่ะ จะส่งลิงก์และวิธีเข้าใช้งานให้
```

### 2.2 ส่งลิงก์ + วิธีเริ่มใช้

```
ลิงก์ทดลอง: https://nonga-ce93c.web.app

วิธีเริ่ม (ไม่ต้องสมัครเอง):
1) เปิดลิงก์ → หน้าแรกเป็นแชทกับ “น้องเอ”
2) พิมพ์สิ่งที่อยากได้ เช่น “อยากได้รถ SUV งบไม่เกิน 8 แสน กรุงเทพ”
3) รอการ์ดรถหรือคำตอบในแชท
4) กด “ดูรายละเอียดในแชท” เพื่ออ่านข้อมูลและรูป (ไม่ต้องออกจากแชท)

บอกงบ ยี่ห้อ/รุ่น ปี จังหวัด จะได้คำแนะนำตรงขึ้นครับ/ค่ะ
```

### 2.3 ข้อควรระวัง (ส่งคู่กับลิงก์)

```
ข้อสำคัญก่อนใช้งานครับ/ค่ะ:

• รอบนี้เป็นระบบทดลอง — ฟีเจอร์บางอย่างอาจปรับตาม feedback
• น้องเอช่วยแนะนำจากข้อมูลประกาศ — ไม่ใช่การรับประกันสภาพรถ ไมล์ หรือเอกสาร
• ก่อนตัดสินใจซื้อ ควรดูรถจริง ทดลองขับ และตรวจเล่มทะเบียน/สัญญากับผู้ขายโดยตรง
• ปุ่ม “สนใจรถ” ยังเป็นแบบทดลอง — ยังไม่ใช่การจองหรือซื้อจริง

ติดปัญหาแจ้งลุงทาง LINE นี้ได้เลยครับ/ค่ะ
```

## 3. ข้อความ LINE — ผู้ขายรถบ้าน

ปรับ `[ชื่อ]` `[อีเมล]` แล้วคัดลอกทีละก้อน

### 3.1 เชิญทดลองลงขายกับน้องเอ

```
สวัสดีครับ/ค่ะ [ชื่อ]

ทีม Nong A ขอเชิญทดลอง “ลงขายรถกับน้องเอ” ครับ/ค่ะ
ส่งรูปและข้อมูลรถในแชท น้องเอช่วยร่างประกาศ แล้วลงแสดงในตลาดทดลองของเรา

รอบนี้เชิญเท่านั้น ยังไม่เปิดให้สมัครเองทั่วไป
ยังไม่รับประกันว่าจะมีผู้ซื้อติดต่อภายในกี่วัน — โฟกัสที่ทดสอบว่าระบบใช้งานสะดวกไหม

ถ้าสนใจ แจ้งกลับได้ครับ/ค่ะ
```

### 3.2 เตรียมรูปและข้อมูล

```
ก่อนเริ่ม รบกวนเตรียมครับ/ค่ะ:

รูปรถ 6–10 รูป (อย่างน้อย 3 รูป) — หน้า ข้าง หลัง ภายใน เลขไมล์ ห้องเครื่องถ้ามี
เบลอป้ายทะเบียนได้ถ้ากังวลเรื่องความเป็นส่วนตัว

ข้อมูลที่พิมพ์ให้น้องเอ:
• ยี่ห้อ / รุ่น / ปี
• ราคาที่ต้องการขาย (บาท)
• เลขไมล์ / เกียร์ / สี
• จังหวัดหรือพื้นที่นัดดูรถ
• จุดเด่น 2–3 ข้อ

อย่าใส่ในรูปหรือแชท: บัตรประชาชน ใบหน้า เล่มทะเบียน สัญญาไฟแนนซ์ เลขบัญชี หรือข้อมูลส่วนตัวเกินจำเป็น
```

### 3.3 ส่งลิงก์ + login + flow ลงประกาศ

```
ลิงก์ทดลอง: https://nonga-ce93c.web.app

บัญชี login (อีเมล): [อีเมล]
(รหัสผ่าน / ลิงก์ตั้งรหัส: ส่งแยกทาง LINE ส่วนตัว)

ขั้นตอนโดยย่อ:
1) Login → เปิดแชทกับน้องเอ
2) ส่งรูป + รายละเอียดรถตามที่เตรียม
3) ทำตามปุ่มในแชท เช่น “บันทึกประกาศ”
4) ติ๊กยืนยันความถูกต้องของรูป/ข้อมูล (ถ้าระบบถาม)
5) กด “ลงตลาด” เมื่อพร้อม
6) ดูผลที่เมนู “ประกาศของฉัน”

เบอร์โทรของคุณอาจยังไม่แสดงบนหน้าตลาดสาธารณะในรอบทดลอง — ทีมจะประสานติดต่อครับ/ค่ะ
ติดปัญหาแจ้งลุงได้เลย
```

### 3.4 ย้ำ PDPA / ความเป็นส่วนตัว

```
ย้ำเรื่องความปลอดภัยข้อมูลครับ/ค่ะ:

✓ ส่งได้: รูปตัวรถ ภายใน ไมล์ ข้อมูลรถที่ลงประกาศ
✗ ไม่ควรส่ง: บัตร ใบหน้า เล่มทะเบียนเต็ม สัญญา หรือเลขบัญชีในแชท

คุณรับผิดชอบความถูกต้องของข้อมูลและรูปที่ส่งครับ/ค่ะ
```

## 4. ข้อความ LINE — ดีลเลอร์ / เต็นท์รถ

ปรับ `[ชื่อ]` `[อีเมล]` `[ชื่อเต็นท์]` แล้วคัดลอกทีละก้อน

### 4.1 เชิญทดลองระบบเต็นท์

```
สวัสดีครับ/ค่ะ [ชื่อ] ([ชื่อเต็นท์])

ทีม Nong A ขอเชิญทดลองระบบจัดการประกาศรถสำหรับเต็นท์ครับ/ค่ะ
ใช้แชทกับ “น้องเอ” ช่วยสร้าง Draft ตรวจใน Dealer Portal แล้วลงตลาดทดลอง

รอบนี้เป็น closed pilot บน staging — ยังไม่ใช่ production เต็มรูปแบบ
ยังไม่เปิดรับดีลเลอร์สมัครเองทั่วไป

ถ้าสนใจร่วมทดลอง แจ้งกลับได้ครับ/ค่ะ
```

### 4.2 ส่งลิงก์ + บทบาทดีลเลอร์

```
ลิงก์ทดลอง: https://nonga-ce93c.web.app

บัญชี login (อีเมล): [อีเมล]
(รหัสผ่าน / ลิงก์ตั้งรหัส: ส่งแยกทาง LINE ส่วนตัว)

หลัง login:
• แชทกับน้องเอ → อธิบายรถหรือส่งรูป → ได้ Draft
• เปิด Dealer Portal: https://nonga-ce93c.web.app/dealer
• ตรวจรูป แก้ข้อมูล แล้วกดลงตลาด

ระบบมี publish guard — ถ้าข้อมูลหรือรูปไม่ครบ จะบอกว่าขาดอะไรก่อนลงจริง
```

### 4.3 Paste Import (ถ้าเต็นท์ใช้นำเข้าหลายคัน)

```
ถ้าต้องการนำเข้าหลายคันจากตาราง/ข้อความ (ทีมเปิดให้เป็นรายกรณี):

• ใช้เมนูนำเข้าคลังรถ (Paste Import / Smart Import) ตามที่ลุงชี้
• วางข้อมูลตามตัวอย่าง → อัปโหลดรูป → บันทึกเป็น draft → ตรวจก่อน publish

คู่มือตัวอย่าง: https://nonga-ce93c.web.app/samples/dealer-import-guide.md

ยังเป็นรอบทดลอง — ขอ feedback ถ้าขั้นตอนไหนงงครับ/ค่ะ
```

### 4.4 ข้อควรระวัง (ดีลเลอร์)

```
ข้อสำคัญครับ/ค่ะ:

• รอบทดลอง — ไม่สัญญายอดขายหรือ lead จริงครบทุกช่องทาง
• น้องเอช่วยร่าง/สรุป — ไม่แทนการตรวจสอบสภาพรถหรือเอกสารจริง
• อย่าส่งข้อมูลลูกค้าที่อ่อนไหวในแชทเกินจำเป็น

ติดปัญหาแจ้งลุงทาง LINE นี้ได้เลย — ขอบคุณที่ร่วมทดลองครับ/ค่ะ ปังปุริเย่
```

## 6. Template ขอ feedback หลังทดลอง

ส่งหลังผู้ทดลองใช้งาน 1–3 วัน (ปรับ `[ชื่อ]`)

### 6.1 แบบสั้น — ตอบกลับ LINE นี้ได้เลย

```
สวัสดีครับ/ค่ะ [ชื่อ]

ขอบคุณที่ร่วมทดลอง Nong A ครับ/ค่ะ
รบกวนตอบสั้น ๆ 3 ข้อ (พิมพ์กลับ LINE นี้ได้เลย):

1) ใช้งานโดยรวมง่ายไหม (1–5 หรือ ง่าย/ปานกลาง/ยาก)
2) ติดตรงไหนหรืองงขั้นตอนไหนบ้าง
3) อยากให้เพิ่มหรือปรับอะไรในรอบถัดไป

ไม่ต้องกลัวว่าจะว่าระบบไม่ดี — feedback ช่วยปรับให้ดีขึ้นครับ/ค่ะ
ขอบคุณมากครับ/ค่ะ
```

### 6.2 แบบมี Google Form (ถ้าลุงมีลิงก์)

```
สวัสดีครับ/ค่ะ [ชื่อ]

ขอบคุณที่ร่วมทดลอง Nong A ครับ/ค่ะ
รบกวนกรอก feedback สั้น ๆ ที่นี่ได้เลย (ใช้เวลา 2–3 นาที):

[ใส่ลิงก์ Google Form]

หรือถ้าสะดวก ตอบกลับ LINE นี้ 3 ข้อก็ได้:
1) ใช้ง่ายไหม
2) ติดตรงไหน
3) อยากให้เพิ่มอะไร

ขอบคุณมากครับ/ค่ะ — ปังปุริเย่
```

### 6.3 คำถามเสริม (ใส่ใน Form ถ้าต้องการ)

- รูปขึ้นถูกและครบไหม
- น้องเอแนะนำ/สรุปรถช่วยได้แค่ไหน
- ใช้มือถือหรือคอมพิวเตอร์
- กลุ่มผู้ใช้: ผู้ซื้อ / ผู้ขายรถบ้าน / ดีลเลอร์
