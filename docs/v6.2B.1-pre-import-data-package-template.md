## 1. Vision & Scope

### เป้าหมาย v6.2B.1 (template slice)

สร้าง **Pre-import Data Package Template** และ **sample manifest แบบ placeholder** สำหรับเตรียม batch รถจริง 5–10 คัน ก่อน import เข้า staging controlled pilot:

- กำหนด **โครงสร้าง manifest JSON** ที่ ops/engineering ใช้เตรียมข้อมูล
- ให้ **sample placeholder** ที่ไม่มีข้อมูลจริง — ใช้เรียนรู้ schema เท่านั้น
- ระบุ **consent flags** ที่ต้องเป็น `true` ก่อน import จริง
- ระบุ **forbidden fields** ชัดเจน
- **Docs/tests/package only** — ไม่ runtime, ไม่ deploy, ไม่ import

## 3. Vehicle Record Template

แต่ละคันใน batch (5–10 คัน) ต้องมีฟิลด์ตาม schema ด้านล่าง:

| Field | Type | Placeholder example | Notes |
|-------|------|---------------------|-------|
| `listingId` | string | `pilot-placeholder-listing-001` | dummy opaque ID — **no real UID** |
| `sourceId` | string | `pilot-placeholder-source-001` | source system ref — masked |
| `make` | string | `Toyota` | canonical make |
| `model` | string | `Corolla Altis` | canonical model |
| `year` | number | `2019` | 4-digit |
| `trim` | string | `1.6 G` | optional |
| `price` | number | `429000` | THB — placeholder value |
| `mileage` | number | `85000` | km |
| `transmission` | enum | `automatic` | auto / manual / CVT |
| `fuel` | enum | `petrol` | petrol / diesel / hybrid / EV |
| `color` | string | `ขาว` | no PII |
| `province` | string | `กรุงเทพมหานคร` | **province only** — not full address |
| `photoPlaceholders` | array | `["placeholder-photo-front-001.jpg", ...]` | **not real URLs** until sanitized |
| `highlights` | string | sanitized description | no phone/LINE/address |
| `checkNotes` | string | `ต้องตรวจสภาพจริง` | caveats |
| `listingStatus` | enum | `available` | available / reserved / sold |
| `sellerDisplayName` | string | `ดีลเลอร์ตัวอย่าง A` | **non-PII placeholder** |
| `sourceUpdatedAt` | ISO8601 | `1970-01-01T00:00:00.000Z` | placeholder timestamp |
| `updatedAt` | ISO8601 | `1970-01-01T00:00:00.000Z` | placeholder timestamp |

ดูตัวอย่างเต็มใน `docs/examples/v6.2B.1-real-stock-sample-manifest.placeholder.json`

## 4. Consent Flags Template

ทุกคันต้องมี object `consent` — **ทุก flag ต้องเป็น `true` ก่อน import จริง**

| Flag | Meaning | Placeholder value |
|------|---------|-------------------|
| `sellerConsent` | seller/dealer ยินยอมใช้ใน pilot | `false` (placeholder) |
| `imageRightsConfirmed` | มีสิทธิ์ใช้รูป | `false` (placeholder) |
| `piiReviewed` | ผ่าน PII scan | `false` (placeholder) |
| `staleChecked` | สถานะ/ราคา/รูป ตรวจแล้ว | `false` (placeholder) |
| `rollbackReady` | rollback procedure พร้อม | `false` (placeholder) |

**Placeholder manifest:** ทุก consent = `false` — บ่งบอกว่ายังไม่พร้อม import

## 5. Forbidden Fields & Content

### 5.1 Forbidden in manifest / data package

| Category | Examples | Rule |
|----------|----------|------|
| เบอร์โทรจริง | `0812345678`, `08-1234-5678` | ❌ **forbidden** |
| ชื่อเจ้าของจริง | ชื่อ-นามสกุล seller | ❌ **forbidden** — use sellerDisplayName placeholder |
| LINE ID จริง | `@realuser`, LINE QR text | ❌ **forbidden** |
| ที่อยู่จริง | บ้านเลขที่, ซอย, แขวง | ❌ **forbidden** — province only |
| เลขทะเบียนเต็ม | `กข 1234 กรุงเทพ` | ❌ **forbidden** |
| UID จริง | Firebase UID 28 chars | ❌ **forbidden** |
| prompt จริง | chat/user prompts | ❌ **forbidden** |
| secret / env dump | API keys, `.env` values | ❌ **forbidden** |
| customer data จริง | buyer phone, buyer name | ❌ **forbidden** |

### 5.2 Forbidden in photos (image package — not in git)

| Content | Rule |
|---------|------|
| บัตรประชาชน / ใบเล่ม / เอกสารทะเบียน | ❌ reject |
| สัญญา / หลักฐานการเงิน | ❌ reject |
| เบอร์โทร / LINE / ที่อยู่ในรูป | ❌ reject or blur |
| ป้ายทะเบียนอ่านได้ | ❌ mask before use |

### 5.3 Forbidden in repo (this slice)

| Item | Rule |
|------|------|
| Real vehicle listing data | ❌ do not commit |
| Real customer PII | ❌ do not commit |
| Real photo URLs with PII | ❌ do not commit |
| Import commands / scripts that mutate DB | ❌ not in v6.2B.1 |
| `gcloud` / `firebase deploy` commands in manifest | ❌ forbidden |

```json

    "schemaVersion": "v6.2B.1-placeholder",
    "placeholderOnly": true,
    "realStockImportBlocked": true,
    "batchLimitMin": 5,
    "batchLimitMax": 10
  }
}
```

Real data packages must **not** include `placeholderOnly: true` and must pass ops review before any import execution slice.
