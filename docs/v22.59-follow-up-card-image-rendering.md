2. Q2/Q3 use session-first bridge path → `pilotSessionCardsToChatCarCards` → `imageUrl=""`, `imageUrls=[]`, `hasImage=false`.
3. v22.58 client applied server `carCards` over local orchestrated cards (which still had Q1 images).
4. Result: cards remained, images stripped. Q4 used inventory-backed rehydrate → images OK.

Not a Marketplace/upload/image-store defect — Corolla images already work on Q1 and Marketplace.
