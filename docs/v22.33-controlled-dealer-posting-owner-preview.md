### Intended product path (for owner browser later)

```text
1. Invite/pilot dealer logs in (public signup OFF)
2. Dealer Portal → Drafts (or Sell wizard)
3. Fill brand / model / year / price / mileage + images

6. Owner/admin: GET /api/admin/listings/pending-review
7. Owner/admin: POST /api/admin/listings/:id/approve → published

```

**Approval UI status:** **API-first**. There is no dedicated admin “pending queue” screen yet. Dealer Portal inventory UI still largely treats non-`hidden` as “on market” visually — backend gate is correct; UI badge polish is a follow-up.
