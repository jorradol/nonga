## 6. `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED` Decision

| Option | Recommendation |
|--------|----------------|
| **`false` (keep)** | ✅ **Recommended for v6.1L.2 pilot** |
| `true` | ❌ **Not recommended** for first user-visible pilot |

### Rationale — keep `false`

| Reason | Detail |
|--------|--------|
| Separate path | CP-02 admin sink (`/api/admin/chat-shadow-sink`) ≠ public user-visible chat |
| Risk | `true` enables real Gemini on **admin** CP-02 only — no benefit to allowlisted tester UX |
| Guardrails | v6.1K.5 validated kill switch on CP-02 — keep sink off unless separate admin pilot |
| User-visible pilot | ควรทดสอบ **intended user-visible path** ไม่ปน admin sink Gemini |

### If ever enabled separately (not v6.1L.2)

- Requires separate approval + CP-02 smoke matrix
- Still does **not** replace user-visible path
- Rollback: `NONGA_AI_CHAT_SHADOW_REAL_PROVIDER_ENABLED=false`
