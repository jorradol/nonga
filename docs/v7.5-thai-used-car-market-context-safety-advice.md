# v7.5 — Thai Used-car Market Context + Safety Advice Layer

ต่อยอดจาก v7.4 (AI answer naturalness + card narrative fusion) โดยเพิ่ม "บริบทตลาดรถมือสองไทย"
แบบเบา ๆ และ "ชั้นคำเตือนความปลอดภัย" ให้คำตอบของน้องเอเป็นธรรมชาติและช่วยลูกค้าได้จริง
**ทั้งหมดเป็น deterministic / mock-safe ไม่เรียก Gemini จริง ไม่เปิด user-visible AI**

## Scope (final ที่อนุมัติ)

- **market context = topics + weave**
- **safety advice = trigger-only 1 บรรทัด**
- **topics = full 4 หัวข้อ** (`cityVsUpcountry`, `hiddenCosts`, `monthlyBudget`, `paymentSafety`)

## Flow ที่แก้

1. **Advisor path เดิม** (`detectBuyerAdvisorTopic` → `buildBuyerAdvisorReply`):
   เพิ่ม 4 หัวข้อใหม่ patterns เป็น "คำถามเชิงคำแนะนำ" ที่เจาะจง จึงไม่แย่ง vehicle search
   และไม่ชน finance calculator (ซึ่งต้องมีตัวเลขจริง)
2. **Search reply (orchestrator)**: หลังได้ scored reply + memory opener (v7.4)
   - ถ้ามีสัญญาณ budget/finance → ต่อท้าย market-context note 1 บรรทัด
   - ถ้าข้อความมี trigger การโอน/มัดจำ/จอง/นัดดูรถ → ต่อท้าย safety nudge 1 บรรทัด
   - ถ้าไม่เข้าเงื่อนไข → ไม่เพิ่มอะไร (คำตอบไม่ยาว/ไม่แข็ง)

## Guardrails ที่ยืนยัน

- **No invented car facts**: ไม่อ้างเลขไมล์ / อัตราสิ้นเปลือง / ประวัติซ่อม / เคลม / ไฟแนนซ์เฉพาะคัน / ราคาตลาดเฉพาะรุ่น — มี test `INVENTED_FACT_RE`
- **No guarantee / no over-claim**: `USED_CAR_ADVICE_OVERCLAIM_FORBIDDEN` บล็อกการการันตีสภาพ/ไฟแนนซ์ผ่าน/ราคาตลาด
  (อนุญาตเฉพาะ disclaimer เชิงปฏิเสธ เช่น "ไม่ได้การันตีสภาพ…")
- **Safety = trigger-only 1 บรรทัด**: ไม่มี trigger → คืน `null`
- **Market context = weave เบา ๆ 1 บรรทัด**: ไม่มี budget/finance → คืน `null`
- **Routing**: topic ใหม่ไม่แย่ง search (single-area search ไม่กลายเป็น advisor) และไม่ชน finance calc (ต้องมีตัวเลข)
- **Lead flow v7.1–v7.4 ไม่กระทบ**: ไม่แตะ payload / consent / final confirmation / dealer isolation / data model;
  search reply ไม่มี consent/contactPhone/queue count
- **ไม่เรียก Gemini จริง / ไม่เปิด user-visible AI**: `skipGemini === true`, deterministic (output ซ้ำเท่ากัน)
