## 7. Listing Draft Workflow

**Flow:** raw vehicle data → clean data → listing copy draft → social caption draft → admin review → manual publish

| Step | Stage | Owner | v6.6F scope |
|------|-------|-------|-------------|
| 1 | **Raw vehicle data** | Dealer/admin provides offline | Define fields only |
| 2 | **Clean data** | Admin normalizes units, masks plate, removes PII | Checklist validation |
| 3 | **Listing copy draft** | Admin or future back-office AI draft | **Manual draft in v6.6F** — no Gemini |
| 4 | **Social caption draft** | Admin or future back-office AI draft | **Manual draft in v6.6F** — no Gemini |
| 5 | **Admin review** | ลุงเด่น or designated admin | Required gate — see §8 |
| 6 | **Manual publish** | Admin only — Facebook/LINE/website manual | **Not in v6.6F** — needs separate publish approval |

### AI boundary (future — not v6.6F)

- AI ใช้ได้ **เฉพาะหลังบ้าน / ช่วย draft** เมื่อได้ **approval แยก**
- AI **ห้าม** auto-publish
- AI **ห้าม** ตอบลูกค้าจริง
- Gemini กับข้อมูลรถจริง → **stop + separate approval**

### Workflow rules

- **ยังไม่ auto-publish** — **Auto-Publish Enabled? = No**
- **ยังไม่ให้ AI ตอบลูกค้าจริง**
- ทุก draft ต้องผ่าน admin review ก่อน publish (แม้ในอนาคต)
- Publish จริง = **manual approval แยก** — not from v6.6F

## 8. Admin Review Boundary

**ทุก listing / caption ต้องผ่านลุงเด่นหรือแอดมินที่ได้รับมอบหมายก่อนเผยแพร่**

### Admin must verify

| # | Check |
|---|-------|
| 1 | ราคา — ตรงกับที่ dealer ยืนยัน |
| 2 | รุ่น / ยี่ห้อ / ปี — ไม่สลับ |
| 3 | เลขไมล์ — ตรงกับรูป/เอกสาร |
| 4 | เงื่อนไขไฟแนนซ์ — ดาวน์ / ผ่อน / ธนาคาร ถูกต้อง |
| 5 | โปรโมชัน — ไม่ over-promise |
| 6 | ข้อความโฆษณา — ไม่ misleading, ไม่ claim ที่ตรวจไม่ได้ |
| 7 | จุดซ่อม/ตำหนิ — เปิดเผยตามจริง |
| 8 | ไม่มี PII ลูกค้าปลายทางใน copy |

### Stop rule

> **ถ้าข้อมูลไม่มั่นใจ → หยุด → ไม่เผยแพร่**

- ไม่ publish แบบ "แก้ทีหลัง"
- ไม่ bypass review เพราะรีบ
- ไม่ใช้ draft ที่ admin ยังไม่ sign off
