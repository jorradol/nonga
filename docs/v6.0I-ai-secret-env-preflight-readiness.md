## 1. Vision & ขอบเขต v6.0I

### เป้าหมาย

ตรวจความพร้อมของ **AI env/secrets** ก่อนเปิด paid AI provider จริงบน **staging/closed pilot** โดย:

- **Read-only / describe เท่านั้น** — ไม่ update env, ไม่ access secret values
- ยืนยัน project/service/region ถูกต้อง
- ยืนยัน secret **references** (ชื่อ) และ control flags design
- ยืนยัน budget/kill switch/SuperAdmin brake พร้อมในแผน
- **ไม่เรียก paid AI API** ใน v6.0I

### v6.0I ทำอะไร / ไม่ทำอะไร

| ทำ (รอบนี้) | ไม่ทำ (รอบนี้) |
|-------------|----------------|
| Preflight doc + static tests | Deploy Cloud Run / Hosting / Firestore rules |
| Read-only command spec | เปิดหรือแก้ env/secrets จริง |
| Secret **names** only | สร้าง secret ใหม่ |
| Redacted env inspection plan | แสดงค่า secret จริง |
| Checklist before stage J/K/L | เรียก paid AI API |
| | `gcloud secrets versions access` |
| | `gcloud run services update` |
| | fetch network ใน test script |
| | เปลี่ยน user-visible runtime behavior |

## 3. Read-Only Preflight Plan

### Phase I steps (manual — when approved to run outside CI)

```
1. Verify gcloud project = nonga-ce93c
2. Describe nonga-staging (env var NAMES + secret refs only — redact values in notes)
3. Describe secret resources by NAME (GEMINI_API_KEY, OPENAI_API_KEY) — existence only
4. Confirm budget limit env names present or documented as TODO before stage L
5. Confirm kill switch + SuperAdmin controls documented (v6.0H / v5.6J)
6. Record preflight pass/fail in ops log — no secret values in log
```

### Env inspection (redacted)

เมื่อ describe Cloud Run service ให้บันทึกเฉพาะ:

- ชื่อ env var: `NONGA_AI_MODE`, `NONGA_AI_PROVIDER`, …
- ค่า **non-secret** ที่ปลอดภัย: e.g. `NONGA_AI_MODE=off`
- secret **reference name** เช่น `GEMINI_API_KEY` → Secret Manager ref
- **ห้าม** copy ค่า secret ลง repo, Slack, หรือ test log

## 4. Target Env (Future — Not Applied in v6.0I)

> **v6.0I ไม่ apply env เหล่านี้** — เป็น target สำหรับ staging closed pilot (stage L) หลัง preflight pass

| Flag | Staging closed pilot target | Production |
|------|----------------------------|------------|
| `NONGA_AI_PROVIDER` | `gemini` or `openai` | **blocked** (stay `mock` / unused) |
| `NONGA_AI_MODE` | **`high`** | **`off`** |
| `NONGA_AI_FIRST_ENABLED` | **`true`** | **`false`** |
| `NONGA_AI_EMERGENCY_KILL_SWITCH` | **`false`** when enabling (ready to set `true`) | **`false`** |
| `NONGA_AI_BUDGET_DAILY_LIMIT` | set before enable | unset / N/A |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | set before enable | unset / N/A |

**production default = off** — ไม่เปิด paid AI บน production จนกว่าผ่าน closed pilot + ลุง review แยก

## 5. Secret Names (Server-Only)

| Secret name | Purpose | Client bundle |
|-------------|---------|---------------|
| `GEMINI_API_KEY` | Gemini paid API (server proxy) | **❌ never `VITE_*`** |
| `OPENAI_API_KEY` | OpenAI paid API (server proxy) | **❌ never `VITE_*`** |

### Rules

- ห้ามใส่ **secret value** ใน repo, docs, test output, หรือ CI logs
- ห้าม log ค่า secret แม้ redacted บางส่วน — ใช้ “present: yes/no” เท่านั้น
- Preflight ตรวจ **existence** ของ secret resource via `gcloud secrets describe` — **ไม่** access versions

## 7. Exact Read-Only Commands

> **v6.0I test script ไม่รัน commands เหล่านี้** — เป็น runbook สำหรับ operator เมื่อได้รับอนุมัติแยก

### Verify project

```bash
gcloud config get-value project
# Expected: nonga-ce93c
```

### Describe staging Cloud Run (env names + secret refs)

```bash
gcloud run services describe nonga-staging \
  --project=nonga-ce93c \
  --region=asia-southeast1 \
  --format="yaml(spec.template.spec.containers[0].env)"
```

บันทึกผลแบบ redacted — ระบุชื่อ env และ secret ref เท่านั้น

### Describe secret resource (existence — no value)

```bash
gcloud secrets describe GEMINI_API_KEY --project=nonga-ce93c
gcloud secrets describe OPENAI_API_KEY --project=nonga-ce93c
```

ถ้าชื่อ secret จริงใน GCP ต่างจากตาราง — บันทึก **ชื่อจริง** ใน ops log (ไม่ใช่ค่า)

### Optional: IAM read-only

```bash
gcloud secrets get-iam-policy GEMINI_API_KEY --project=nonga-ce93c
```

## 8. Forbidden Commands (v6.0I)

| Command | Reason |
|---------|--------|
| `gcloud secrets versions access` | **ห้าม** — เปิดค่า secret |
| `gcloud secrets versions add` | **ห้าม** — สร้าง/อัปเดต secret |
| `gcloud run services update` | **ห้าม** — เปลี่ยน env/runtime |
| `gcloud run deploy` | **ห้าม** — deploy |
| `firebase deploy` | **ห้าม** — deploy |
| Any paid AI API call | **ห้าม** — ยังไม่ถึง stage L |

| Rule | Detail |
|------|--------|

| Secret status | `GEMINI_API_KEY: exists=true` — never the key string |
| Repo / docs | secret **names** only — no values |

## 10. No-Go Zones & Fallback (Still Enforced)

เมื่อเปิด real AI ในอนาคต zones ต่อไปนี้ **ยังบังคับ** (จาก v6.0H):

- revenue write, settlement write, payment, invoice
- contact reveal without consent
- hallucinated listing facts
- credit-risk label / “ติดบูโร”
- legal/financial advice as final truth

**Fallback:** provider error / budget hit / kill switch → legacy deterministic (`chatSearchOrchestrator` + templates)
