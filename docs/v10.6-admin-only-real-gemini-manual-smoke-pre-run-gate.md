## 4. Pre-Run Gate Checklist

### Repository Gate

- branch must be `feature/chat-image-attachment-v1`
- HEAD must match the commit approved by owner
- local HEAD = origin HEAD
- working tree clean
- no untracked risky files
- no files outside approved scope

### Approval Gate

- owner explicit approval exists
- approval wording matches Option A / equivalent
- approval allows only one admin-only manual smoke run
- approval does not allow production/deploy/public route/buyer-facing AI/real lead

### Secret / Environment Gate

- `GEMINI_API_KEY` exists only in local/admin environment
- secret value is not printed
- secret value is not committed
- no `.env` or secret file is added to repo
- operator confirms env source without exposing value
- no secret in repository/log/output

### Data Gate

- synthetic data only
- no real customer data
- no phone number
- no VIN
- no plate
- no PII
- no Thor Auto private inventory data unless already sanitized and explicitly allowed

### Runtime Safety Gate

- admin-only path only
- buyer/public path isolated
- real lead sending disabled or unrelated
- deterministic fallback verified
- kill switch verified
- log redaction verified
- abort criteria reviewed

### Cost / Quota Gate

- one run only
- very low prompt count
- no loop
- no batch
- no normal test hitting Gemini
- abort if quota/cost looks unexpected
