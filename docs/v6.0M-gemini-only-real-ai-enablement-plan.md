## 1. Vision & Gemini-only Scope

### เป้าหมาย v6.0M

ปรับแผนเปิด real paid AI ให้ใช้ **Gemini เท่านั้น** ในรอบแรก โดย:

- โปรเจกมี **`gemini-api-key`** ใน Secret Manager และ Cloud Run mount แล้ว (v6.0L preflight)
- ลุง **ไม่ได้ใช้ OpenAI** — OpenAI เป็น **optional future-only / no-op** ในรอบแรก
- ยัง **ไม่เรียก paid AI API จริง**
- ยัง **ไม่เปิด env/secrets จริง**
- ยัง **ไม่เปลี่ยน user-visible response**
- **ยังไม่พร้อมนำเข้าสต๊อกจริง** จนกว่าจะผ่าน **staging AI conversation smoke** (stage P+)

## 4. Approval Gate & Phrase (v6.0M)

1. v6.0L preflight **pass** — gemini secret exists, AI flags absent
2. Budget limits **กำหนดในแผนก่อน enable** (daily + monthly)

4. No-go zones **hard blocked** in code/tests
5. **ลุงพิมพ์ approval phrase ตรงตามข้อความด้านล่าง** — Gemini-only, staging closed pilot only

## 5. Hard No-Go Zones

AI (mock or real Gemini) **ห้าม** produce actions or user-facing claims ใน zones ต่อไปนี้:

| Zone | Rule | Fallback |
|------|------|----------|
| **revenue write** | ห้าม AI ใน revenue write | blocked → deterministic template |
| **settlement write** | ห้าม AI ใน settlement write | blocked → deterministic |
| **payment / invoice** | ห้าม AI ใน payment/invoice | blocked → deterministic |
| **contact reveal** | ห้าม reveal contact โดยไม่มี consent | blocked → ask consent / template |
| **listing hallucination** | ห้ามแต่งข้อมูลรถที่ไม่มีใน listing | blocked → askFollowUp / facts-only |
| **credit bureau claims** | ห้ามตีตราเครดิต เช่น ติดบูโร | blocked → refuse + template |
| **financial / legal advice** | ห้ามคำแนะนำการเงิน/กฎหมายแบบฟันธง | blocked → disclaimer + template |

Enforced in: `salesBrainMock`, `salesBrainRealProvider`, v6.0D–J tests, revenue/settlement guardrails (401 unauth on preview APIs).

## 6. Budget, Kill Switch & SuperAdmin Brake

### Budget limits (required before enable)

| Control | Requirement |
|---------|-------------|
| `NONGA_AI_BUDGET_DAILY_LIMIT` | **ต้องกำหนดก่อนเปิด** — numeric cap (USD or token equivalent) |
| `NONGA_AI_BUDGET_MONTHLY_LIMIT` | **ต้องกำหนดก่อนเปิด** — numeric cap |

### Emergency kill switch

| Flag | When enabling | Rollback |
|------|---------------|----------|
| `NONGA_AI_EMERGENCY_KILL_SWITCH` | `false` | set **`true`** → legacy 100%, no Gemini calls |

### SuperAdmin downshift ladder

```
high → standard → low → off
```

- SuperAdmin may downshift at any time via v5.6J controls
- **Budget hit** → auto **fallback/downshift** (warn → stop → downshift mode)
- **Provider error** (Gemini timeout/429/5xx) → **legacy deterministic fallback** (`chatSearchOrchestrator` + templates)
