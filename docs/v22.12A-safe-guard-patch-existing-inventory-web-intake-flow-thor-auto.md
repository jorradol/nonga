## Allowed and forbidden field policy (Thor Auto controlled path)

Allowed public-sale-safe fields only:

- make / brand
- model
- year
- trim
- body type
- transmission
- fuel
- mileage range or public-safe mileage
- public sale price or price range
- vehicle location zone
- public sale description
- sale-approved images
- vehicle sale status (`ready` / `checking` / `reserved`)
- public-safe general notes

Forbidden fields:

- VIN / plate / full registration data
- owner/seller/customer/buyer phone
- private owner or seller personal data
- private dealer notes
- internal cost / internal margin
- bank / transfer / payment data
- token / header / cookie / secret / env
- Authorization header / credential
- PII of any kind
