## 8. Safe session constraints

| Constraint | คำอธิบาย |
|-----------|----------|
| operator login เองเท่านั้น | operator login ด้วยบัญชี dealer ของตนเองในรอบ execution เท่านั้น |
| agent ไม่ login | agent ไม่ login และไม่อ่าน credential ทุกกรณี |
| dealer scope เท่านั้น | session จำกัดเฉพาะ dealer ของตนเอง — ไม่ cross-dealer |
| staging only | ใช้ staging URL เท่านั้น — ห้าม production |
| logout หลังเสร็จ | logout / ปิด session หลัง smoke เสร็จทุกครั้ง |
| no credential sharing | ห้าม credential sharing ทุกกรณี |
| no session/cookie/token capture | ห้าม capture session/cookie/token |
| ไม่เก็บ login data ใน repo/report | ห้ามบันทึก password หรือข้อมูล login ใน repo/report |
| ไม่มี login ใน slice นี้ | operator login จริง **ยังไม่เกิด** ใน v7.0P |

**กฎ:** safe session คือ session ที่ operator ควบคุมเองทั้งหมด — agent **ไม่** login, **ไม่** อ่าน credential/session/cookie/token และ **ห้ามเก็บ credential/session/cookie/token/password ใน repo หรือรายงาน**

## 9. Allowed evidence vs forbidden evidence

| ประเภท | รายการ |
|--------|--------|
| **Allowed (non-PII / status-only)** | status (PASS/FAIL/PENDING/NOT RUN), count (integer), label (own-dealer/masked), option-selection status |
| **Forbidden** | credential / session / cookie / token / password |
| **Forbidden** | screenshot ที่มีข้อมูลลับหรือข้อมูลส่วนตัว |
| **Forbidden** | buyer PII / raw contact / phone / email / real name |
| **Forbidden** | license plate / VIN / raw lead row |
| **Forbidden** | Firestore write / lead mutation (เว้นแต่อนุมัติแยกใน execution slice) |

**กฎ:** evidence ทุกชิ้นต้องเป็น **allowed (non-PII / count-only / status-only)** เท่านั้น — ถ้ามี forbidden evidence โผล่ ต้อง abort และ **ไม่บันทึกลง repo/chat**
