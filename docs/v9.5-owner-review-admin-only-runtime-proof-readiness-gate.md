## 3. Readiness Checklist Before v9.6 (Admin-Only Gemini Proof Preparation)

รายการนี้ต้องผ่านครบก่อนจะเริ่ม v9.6 admin-only Gemini proof preparation:

- admin-only boundary ต้องยังอยู่ครบ และแยกจาก buyer/public path
- kill switch ต้องชนะทุก flag เสมอ
- fallback deterministic ต้องพร้อมและเป็นทางรอดหลัก
- log redaction ต้องป้องกัน PII/prompt/secret
- quota/cost cap ต้องมีและ fail-closed ได้
- env secret ต้องอยู่เฉพาะ environment เท่านั้น ไม่อยู่ repo
- no buyer/public exposure
- rollback plan ต้องชัดและทดสอบได้
- owner approval ต้องชัดเจนก่อน real admin-only proof
