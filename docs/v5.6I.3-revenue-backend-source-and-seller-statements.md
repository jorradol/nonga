# v5.6I.3 — Revenue Records Read-only Backend Source + Seller Statements

## สรุป

รอบนี้เพิ่ม **แหล่งข้อมูลรายได้ read-only จาก backend inventory จริง** เพื่อแก้ปัญหา Admin Revenue ไม่ขึ้นรายละเอียดเมื่อ `adminState.cars` ฝั่ง frontend ไม่ sync กับ server

## Root cause (v5.6I.2)

- Admin Revenue Dashboard derive จาก `adminState.cars` ใน `useAppStore`
- Store นี้ sync จาก marketplace public fetch / admin local state — **ไม่ใช่ authoritative inventory**
- รถที่ owner ปิดการขาย (`pending_sale`) อาจมีอยู่ใน backend แต่ไม่ปรากฏใน `adminState.cars`
- ผล: แม้ staging มี `pending_sale` จริง หน้า Admin Revenue อาจว่าง

## สิ่งที่เพิ่มในรอบนี้

### Backend API (read-only)

| Route | Role | คำอธิบาย |
|-------|------|----------|
| `GET /api/admin/revenue/preview` | admin / superadmin | อ่าน inventory ทั้งหมดจาก repository → filter `pending_sale` → derive preview rows |
| `GET /api/my/revenue/preview` | owner / dealer scope | อ่าน inventory ของ scope ตัวเอง → filter `pending_sale` → seller statement |

### Data source

- `inventoryRepository.listings.listAll()` (admin)
- `inventoryRepository.listings.listByDealer(scope)` (seller/dealer)
- Filter: `saleStatus === "pending_sale"`
- ราคา: `closedDealPrice` ถ้ามี (อนาคต) → fallback `listing.price` + label `"ประมาณการจากราคาประกาศ"`
- Fee: `hundred_thousand_floor_tier` (480,000 → 4,000 / 1,200,000 → 12,000)
- `paidAmount = 0`, `remainingAmount = feeAmount`, `settlementStatus = unbilled`

### Admin UI

- `AdminRevenueDashboardPreview` เรียก `GET /api/admin/revenue/preview`
- มี loading / error / empty states
- ไม่พึ่ง `adminState.cars` อีกต่อไป
- Badge: Preview / Read-only
- Warning: ยังไม่มี payment gateway / invoice / settlement write

### Seller / Member UI

- `MyRevenueStatementSection` ใน My Listings
- เรียก `GET /api/my/revenue/preview`
- แสดงยอดค้างชำระรวม + รายการรถ + ค่าบริการเมื่อขายสำเร็จ
- ไม่แสดง buyer PII / เบอร์ผู้ซื้อ

## Security / Role guard

- Admin route: `adminApiAuth` middleware
- Seller route: `resolveOwnerRequestScope` — member เห็นเฉพาะ `ownerId` ตัวเอง, dealer เห็นเฉพาะ `dealerId` scope
- Response ไม่มี buyer phone / owner phone / buyer PII
- Seller response ไม่ expose masked id ของ party อื่น

## Wording

ใช้: **ค่าบริการเมื่อขายสำเร็จ**, **ยอดค้างชำระ**, **Preview / Read-only**, **ยังไม่มีการเรียกเก็บเงินจริง**

ห้ามใช้: **ค่าคอมมิชชั่น** ใน UI ผู้ใช้ทั่วไป

## ข้อห้ามรอบนี้ (ยังคงเดิม)

- ยังไม่เปิด payment / invoice / settlement write จริง
- ห้าม admin ปรับยอด (จะเป็น **v5.6I.4**)
- ห้ามแตะ Firestore/Storage rules, env/secrets, `NONGA_LEAD_DATA_BACKEND`
- ห้าม deploy production ในรอบ dev นี้

## ก่อนเปิด admin adjustment (v5.6I.4)

ต้องมี:

- audit log (`updatedBy`, `updatedAt`, `reason`)
- dispute / waive / cancel policy
- ไม่เปิด write จนกว่ามี audit + policy ครบ
