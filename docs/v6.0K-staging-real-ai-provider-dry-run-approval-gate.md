## 4. Approval Gate & Phrase

### Gate rules

1. Dry-run checklist **ทั้งหมด pass**
2. v6.0I preflight + v6.0J stub tests **pass**
3. Budget limits **ตั้งค่าในแผน** (ก่อน run enablement command)
4. SuperAdmin brake + kill switch **ยืนยันพร้อม**
5. **ลุงพิมพ์ approval phrase ตรงตามข้อความด้านล่าง** — ไม่มี phrase = ห้ามเปิด real provider

### Required approval phrase (ลุง)

```
อนุมัติให้เปิด real paid AI provider บน staging closed pilot เท่านั้น ตาม v6.0K
```

- ต้องตรงทุกตัวอักษร (ยกเว้น whitespace ปกติ)
- หมายถึง **staging closed pilot only** — ไม่รวม production
- หลัง phrase ยังต้องรัน enablement แยก (DO NOT RUN YET จนกว่าจะได้ phrase)

## 6. Rollback & Kill Switch

### Immediate kill (highest priority)

```bash
# After enablement only — rollback reference
# ⛔ DO NOT RUN YET unless incident

gcloud run services update nonga-staging \
  --project=nonga-ce93c \
  --region=asia-southeast1 \
  --update-env-vars="NONGA_AI_EMERGENCY_KILL_SWITCH=true"
```

Effect: AI off immediately → deterministic legacy response (`chatSearchOrchestrator` + templates)

### Downshift options

| Action | Env change | User-visible |
|--------|------------|--------------|
| Kill switch | `NONGA_AI_EMERGENCY_KILL_SWITCH=true` | legacy 100% |
| AI off | `NONGA_AI_MODE=off` | legacy 100% |
| Disable AI First | `NONGA_AI_FIRST_ENABLED=false` | orchestrator primary |
| SuperAdmin downshift | high → standard → low → off | reduced AI depth |

### Fallback (automatic on provider error)

- Provider error / timeout → **legacy deterministic response**
- Budget hit → downshift or fallback per v6.0H
- Missing listing facts → askFollowUp — no hallucination
