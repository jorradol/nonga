## 2. สคบ. / ฉลากรถยนต์ใช้แล้ว

### 2.1 ข้อมูลประกาศที่ต้องมี / ควรมี

| Field ID | ข้อมูล | ระดับ | หมายเหตุ |
|----------|--------|-------|----------|
| OCP-01 | **ยี่ห้อ / รุ่น / รุ่นย่อย** | ต้องมี | ชัดเจน ไม่ใช้ชื่อทางการตลาดที่ทำให้เข้าใจผิด |
| OCP-02 | **ปีจดทะเบียน / ปีผลิต** | ต้องมี | แยกให้ชัด — ห้ามสื่อว่าเป็นปีเดียวกันถ้าไม่จริง |
| OCP-03 | **เลขไมล์ / ระยะทางที่ใช้งาน** | ควรมี | ระบุว่าเป็นข้อมูลจากผู้ขาย — ต้องตรวจสอบได้ |
| OCP-04 | **ราคาขาย / ช่วงราคา** | ต้องมี | ชัดเจน รวม/ไม่รวมค่าใด — ห้ามซ่อนค่าใช้จ่ายสำคัญ |
| OCP-05 | **สภาพรถโดยรวม** | ควรมี | คำอธิบายทั่วไป — **ไม่ฟันธง** ว่าปลอดชนหนัก/น้ำท่วม |
| OCP-06 | **ประวัติซ่อม / อุบัติ** | ควรมี (ถ้ามี) | ถ้าไม่ทราบ ต้องระบุว่า **ยังไม่ยืนยัน** |
| OCP-07 | **ภาพรถ** | ต้องมี | รูปจริงของรถคันนั้น — ไม่ใช้ภาพสต็อกทำให้เข้าใจผิด |
| OCP-08 | **ผู้ขาย / ประเภทผู้ขาย** | ต้องมี | dealer / private seller — ไม่ปกปิดสถานะ |
| OCP-09 | **พื้นที่ / จังหวัด** | ควรมี | ระดับจังหวัดหรือเขต — ไม่ต้องเปิดที่อยู่เต็ม public |
| OCP-10 | **ข้อจำกัด / หมายเหตุ** | ต้องมี | disclaimer ด้านล่าง §2.3 |

### 2.2 ข้อมูลที่ต้องชัดเจน — ห้ามทำให้ผู้บริโภคเข้าใจผิด

| Rule ID | Rule |
|---------|------|
| CL-01 | ห้ามใช้คำที่ **รับประกัน** สภาพรถโดยที่ระบบ/น้องเอไม่มีหลักฐาน |
| CL-02 | ห้ามแสดงราคา **ต่ำกว่าจริง** เพื่อดึงดูด แล้วเรียกเก็บค่าใช้จ่ายอื่นภายหลัง |
| CL-03 | ห้ามระบุเลขไมล์ **ยืนยันแล้ว** ถ้ายังไม่มีหลักฐานตรวจสอบ |
| CL-04 | ห้ามระบุว่า **ผ่านตรวจศูนย์ / ไม่เคยชน** โดยไม่มีเอกสารอ้างอิงจากผู้ขาย |
| CL-05 | ห้ามใช้ภาพรถคันอื่น / ภาพสต็อกแทนรถที่ขายจริง |
| CL-06 | ห้ามปกปิดว่าเป็นรถ **ติดไฟแนนซ์ / ค้างภาษี / มีข้อจำกัดโอน** — ถ้าทราบต้องแจ้ง |
| CL-07 | ห้ามใช้คำ **"รับประกันจากน้องเอ"** หรือ **"น้องเอตรวจแล้ว"** — ระบบเป็น marketplace ไม่ใช่ผู้ตรวจรถ |

## 3. PDPA / Privacy

### 3.1 Public fields vs Internal/Private fields

| Visibility | ตัวอย่าง field class | Rule |
|------------|---------------------|------|
| **Public (buyer-facing)** | ยี่ห้อ, รุ่น, ปี, ราคาขาย, สภาพโดยรวม, จังหวัด, รูปที่ redact แล้ว | แสดงได้บน marketplace / chat cards |
| **Internal-only** | ทะเบียนเต็ม, wholesale price, seller contact raw, import manifest row | **ห้าม** public default |
| **Private / restricted** | เบอร์โทร, LINE, ที่อยู่เต็ม, เอกสาร, บัตร, ใบเล่ม, สัญญา, หลักฐานการเงิน | **ห้าม public** — reveal ต้องมี gate แยกในอนาคต |

### 3.2 ทะเบียนรถ — internal-only / masked

| Rule ID | Rule |
|---------|------|
| PLT-01 | **ทะเบียนเต็ม** ต้อง **internal-only** หรือ **masked** — ไม่แสดง public default |
| PLT-02 | Public API DTO **ห้ามมี** `licensePlate` field (ตาม v6.2B.13 — verified **0** public plate) |
| PLT-03 | รูปรถ public ต้อง **blur/mask ป้ายทะเบียน** (v6.2C) |
| PLT-04 | ห้ามใส่ทะเบียนเต็มใน chat response / search card |

### 3.3 ข้อมูลที่ห้าม public

| Category | ห้าม public default |
|----------|---------------------|
| เบอร์โทรศัพท์ | ✅ forbidden |
| LINE ID / QR | ✅ forbidden |
| ที่อยู่เต็ม / บ้านเลขที่ | ✅ forbidden |
| เอกสารรถ / บัตรประชาชน | ✅ forbidden |
| ใบเล่ม / สัญญา / หลักฐานการเงิน | ✅ forbidden |
| Raw image URL (original) | ✅ forbidden |
| Seller UID / buyer UID | ✅ forbidden |

### 3.4 Consent — เจ้าของข้อมูล / ผู้ขาย / ดีลเลอร์

| Consent ID | Requirement |
|------------|-------------|
| CNS-01 | ผู้ขาย/ดีลเลอร์ต้อง **ยินยอม** ให้เผยแพร่ข้อมูลที่แสดง public |

| CNS-03 | ข้อมูลติดต่อส่วนตัวต้องมี **consent แยก** ก่อน reveal |
| CNS-04 | รูปรถต้องมีสิทธิ์ใช้งาน — ไม่ละเมิด PDPA ของบุคคลที่ปรากฏในรูป |
| CNS-05 | ต้องมี path **ถอนความยินยอม / ลบข้อมูล** ในอนาคต (implementation slice แยก) |

## 4. กรมการขนส่งทางบก

### 4.1 Checklist โอนกรรมสิทธิ์ (buyer guidance — ไม่ใช่คำแนะนำทางกฎหมาย)

น้องเอ/ระบบควร **แนะนำขั้นตอนทั่วไป** ไม่ **รับทำแทน** หรือ **สนับสนุนโอนลอย**

| Step ID | ขั้นตอน | หมายเหตุ |
|---------|---------|----------|
| DOT-01 | ตรวจ **เล่มทะเบียน** — ชื่อเจ้าของ ตรงกับผู้ขาย | ก่อนจ่ายเงินเต็ม |
| DOT-02 | ตรวจ **ภาษีรถ** — ค้างชำระ / หมดอายุ | ที่กรมขนส่งหรือ e-Service |
| DOT-03 | ตรวจ **สถานะรถ** — ติดไฟแนนซ์ / อายัด / ค้างค่าปรับ | ห้ามโอนถ้ามีข้อจำกัด |

| DOT-07 | ชำระ **ค่าธรรมเนียม / ภาษีโอน** ตามระบบ | ตามกฎหมายปัจจุบัน |
| DOT-08 | รับ **เล่มทะเบียนใหม่** หลังโอนสำเร็จ | ยืนยันชื่อผู้ซื้อ |

### 4.2 ไม่สนับสนุนโอนลอย

| Rule ID | Rule |
|---------|------|
| NTF-01 | ระบบ **ห้ามแนะนำ / อำนวยความสะดวกโอนลอย** |
| NTF-02 | ถ้าผู้ใช้ถามเรื่องโอนลอย น้องเอตอบว่า **ไม่สนับสนุน** และแนะนำโอนถูกต้องตามกฎหมาย |

### 4.3 ตรวจเล่ม / เอกสาร / ภาษี / สถานะรถก่อนซื้อขาย

| Check ID | สิ่งที่ต้องตรวจ |
|----------|----------------|
| PRE-01 | เล่มทะเบียนรถ — ชื่อเจ้าของ สี ตัวถัง เครื่องยนต์ |
| PRE-02 | ภาษีรถยนต์ — ชำระครบ / ใกล้หมดอายุ |

## 6. AI Grounding / Seller Claims

### 6.1 ห้ามน้องเอฟันธงสภาพรถ

| Rule ID | ห้าม | ตอบแทน |
|---------|------|--------|
| AI-01 | ฟันธง **ไม่เคยชน / ไม่เคยน้ำท่วม** | บอกว่าข้อมูลประกาศยังไม่พอ — แนะนำตรวจรถจริง |
| AI-02 | รับประกัน **เลขไมล์แท้** | บอกว่าเป็นข้อมูลจากผู้ขาย — ต้องตรวจสอบ |
| AI-03 | ฟันธง **พร้อมโอน 100%** | แนะนำตรวจเล่ม/ภาษี/ไฟแนนซ์ที่กรมขนส่ง |
| AI-04 | เปรียบเทียบโดยอ้างข้อมูลที่ไม่มีใน listing | ใช้เฉพาะข้อมูลที่ ground ได้ |

### 6.2 ข้อความเมื่อข้อมูลไม่พอ

เมื่อข้อมูลใน listing ไม่เพียงพอ น้องเอต้องตอบ:

> **"ข้อมูลประกาศยังไม่พอ"** — แนะนำสอบถามผู้ขายหรือตรวจรถจริง

| Trigger | Response pattern |
|---------|------------------|
| ถามเรื่องชนหนัก/น้ำท่วม แต่ listing ไม่มี | ข้อมูลประกาศยังไม่พอ |
| ถามเลขไมล์ยืนยัน แต่ไม่มีหลักฐาน | ข้อมูลจากผู้ขาย — ควรตรวจสอบ |
| ถามสภาพเครื่องยนต์เชิงลึก | แนะนำทดลองขับ / ตรวจศูนย์ |

### 6.3 แนะนำตรวจสอบจริง
