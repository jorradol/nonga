## 2. Purpose

### Core question

> ถ้าอนาคตจะเปิด limited staging pilot แบบจำกัด ต้องมี review framework อะไร ต้องเก็บ evidence อะไรแบบ metadata-only ต้องมี success/failure criteria อะไร ต้องตัดสินใจ go/hold/rollback อย่างไร และ v6.4V เองยังไม่เปิด pilot จริงใช่หรือไม่?

v6.4V ตอบด้วย **limited staging pilot review approval packet** — decision template, review evidence contract, success/failure criteria, evidence checklist, future sequence (plan only), result contract, stop/rollback rules

### v6.4V คืออะไร / ไม่ใช่อะไร

| v6.4V คือ | v6.4V ไม่ใช่ |
|-----------|-------------|
| Limited pilot review approval packet | Limited staging pilot start |
| Review criteria checklist | Post-pilot review execution |
| Pre/post pilot review framework | Gemini invocation |
| Static verification framework | Prompt/provider sending |
| Non-executable runbook | Network execution |
| Non-authorization clause | Runtime monitoring/logging |
| Future sequence (plan only) | Automatic pilot approval |
| | Deploy / production promotion |
