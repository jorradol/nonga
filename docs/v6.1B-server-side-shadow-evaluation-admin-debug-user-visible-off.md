## 3. Admin Route & Auth Guards

### Route

```
POST /api/admin/sales-brain-shadow-smoke
Content-Type: application/json
Authorization: Bearer <admin-token>

{ "caseId": "SS-01" }
```

### Auth (via existing `adminApiAuth` on `/api/admin/*`)

| Caller | HTTP | Result |
|--------|------|--------|
| **Unauthenticated** | **401** | no token — blocked before handler |
| **Non-admin** (e.g. dealer Firebase token) | **403** | role not admin/superadmin |
| **Admin / superadmin** | **200** | synthetic case evaluated, redacted payload returned |

### Handler validation

| Input | HTTP | Result |
|-------|------|--------|
| missing `caseId` | **400** | rejected |
| unknown/custom `caseId` | **400** | rejected — SS-01..SS-08 only |
| valid synthetic `caseId` | **200** | `{ success, readOnly, userVisibleOff, providerNetwork: false, data }` |

**Not a public endpoint** — mounted under `/api/admin` with `adminApiAuth` guard only. Admin/superadmin only — no public access.

- Response flags: `userVisibleOff: true`, `providerNetwork: false`, `readOnly: true`
- **No** `GEMINI_API_KEY` value, **no** secret env dump

### Chat path unchanged

- `useChat` / `chatSearchOrchestrator` still use `wireShadowChatPath` flags-only — **not** `evaluateSalesBrainShadowRuntime`
- User-visible chat behavior remains legacy 100%
