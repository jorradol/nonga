## 3. Preview Gates

Preview แสดงเมื่อ **ทุกเงื่อนไข** เป็นจริง:

| Gate | Condition | Default |
|------|-----------|---------|
| PG-01 | `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ENABLED === "true"` | **false** |
| PG-02 | Staging (`a.nongbot.org` or `VITE_FIREBASE_PROJECT_ID=nonga-ce93c`) | deny prod |
| PG-03 | Signed-in (not guest-user-100) | required |
| PG-04 | UID in `VITE_NONGA_BUYER_FRIENDLY_COPY_PREVIEW_ALLOWLIST_UIDS` | empty = deny all |

**Allowlist key แยกจาก AI allowlist** — scope ชัดเจน

[Preview panel]       ← gated (below original)

  ListingDescription(text={previewResult.text})  // only if guardPass

## 5. Mapper Whitelist

**Allowed:** description, brand, model, year, price, mileage, color, fuelType, condition, features, tags, transmission, drivetrain, bodyType, province, sellerType, showroomName

**Forbidden (never mapped):** ownerPhone, ownerId, licensePlate, images, wholesale, id, secret, raw URLs
