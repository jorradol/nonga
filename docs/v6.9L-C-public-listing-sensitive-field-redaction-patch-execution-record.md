## 5. Behavior added

### 5.1 Public DTO field handling

| Category | Fields | Public behavior |
|----------|--------|-----------------|
| Vehicle identifiers | `vin`, `licensePlate`, `plate`, `registration` | **Deleted** from public DTO |
| Internal / wholesale pricing | `wholesalePrice`, `wholesaleInternalPrice`, `internalPrice`, `cost`, `dealerCost` | **Deleted** |
| Duplicate metadata | `duplicateStatus`, `duplicateScore`, `duplicateGroupId`, `duplicateCanonicalId`, `duplicateMatches`, `duplicateReviewedAt`, `duplicateReviewAction` | **Deleted** |
| Internal admin / consent | existing consent/moderation/reports + `imageMetadata` | **Deleted** (existing + extended) |
| Seller contact | `ownerPhone`, `ownerEmail`, `ownerLine`, `contact*` | **Cleared to `""`** (unchanged pattern) |
| Buyer contact on listing payload | `buyerPhone`, `buyerEmail`, `buyerLine`, `buyerContact*`, `buyerName`, `buyerDisplayName` | **Cleared to `""`** |

### 5.2 Description sanitization (minimal, pattern-based)

`sanitizePublicListingDescription()` strips from public `description`:

- Phone-like patterns
- Email / LINE handle patterns
- 17-character VIN-like tokens
- Thai plate-like patterns (with optional hyphen)
- Wholesale keywords (`wholesale`, `ราคาส่ง`, `ราคาหน้าเต็นท์`)

### 5.3 Safe public fields preserved

`brand`, `model`, `year`, `price`, `mileage`, `images`, `title`, `dealerId`, `showroomName`, `ownerName`, and other marketplace display fields remain available as appropriate.
