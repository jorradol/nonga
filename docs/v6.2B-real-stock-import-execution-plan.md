## 4. Vehicle Record Schema / Checklist

### 4.1 Required fields per vehicle record

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| `listingId` / `sourceId` | string | ✅ | temporary or safe opaque ID — **no raw customer ID in git** |
| `make` | string | ✅ | canonical make |
| `model` | string | ✅ | canonical model |
| `year` | number | ✅ | 4-digit, reasonable |
| `trim` | string | preferred | if available |
| `price` | number | ✅ | THB, > 0 |
| `mileage` | number | preferred | km; if missing → flag for AI "ข้อมูลประกาศยังไม่พอ" |
| `transmission` | enum | preferred | auto / manual / CVT |
| `fuel` | enum | preferred | petrol / diesel / hybrid / EV |
| `color` | string | preferred | Thai or EN |
| `province` | string | ✅ | province only — **not full address** |
| `photos` | array | ✅ min 3 | sanitized URLs/refs — see §5 |
| `highlights` | string | preferred | sanitized, no PII |
| `knownIssues` / `checkNotes` | string | optional | e.g. "ต้องตรวจสภาพจริง" |
| `listingStatus` | enum | ✅ | `available` only at import |
| `updatedAt` | timestamp | ✅ | last known update |
| `sourceUpdatedAt` | timestamp | preferred | from source system |
| `sellerDisplayName` | string | ✅ | **non-PII** — e.g. "ดีลเลอร์ A" / "เจ้าของรถ" — **no full name** |

### 4.2 Schema validation checklist (per car)

| # | Check | Pass criteria |
|---|-------|---------------|
| VR-01 | listingId safe | opaque, no PII embedded |
| VR-02 | make/model/year | present + valid |
| VR-03 | price | present + > 0 |
| VR-04 | province | present, not full address |
| VR-05 | photos | ≥ 3, passed image gate §5 |
| VR-06 | listingStatus | `available` at import time |
| VR-07 | sellerDisplayName | no full name / no phone |
| VR-08 | no forbidden fields | phone, LINE, address, full plate masked |

### 4.3 Forbidden fields in vehicle record

| Field | Rule |
|-------|------|
| sellerPhone | ❌ **forbidden** |
| sellerLineId | ❌ **forbidden** |
| fullAddress | ❌ **forbidden** |
| fullLicensePlate | ❌ **mask** — province only if needed |
| vinFull | ❌ **mask** |
| ownerFullName | ❌ **forbidden** — use sellerDisplayName only |
| internalCost / margin | ❌ **forbidden** |

## 5. Image Safety Gate

### 5.1 Hard reject conditions

| # | Condition | Action |
|---|-----------|--------|
| IS-01 | รูปเห็นบัตรประชาชน | ❌ **reject** — do not import |
| IS-02 | รูปเห็นใบเล่ม / เอกสารทะเบียน | ❌ **reject** |
| IS-03 | รูปมีเบอร์โทร / LINE / QR contact | ❌ **reject** or crop/blur |
| IS-04 | รูปมีที่อยู่เต็ม (ป้าย/เอกสาร) | ❌ **reject** or crop |
| IS-05 | รูปไม่มีสิทธิ์ใช้ | ❌ **reject** |
| IS-06 | รูปไม่ตรงกับรถจริง | ❌ **reject** or replace |

### 5.2 License plate handling

| Rule | Detail |
|------|--------|
| Default | **mask / blur** plate if visible |
| Exception | show province-only context if product requires — never full plate in AI reply |
| Readable plate in photo | must blur before import |

### 5.3 Image rights

| Requirement | Rule |
|-------------|------|
| Ownership | seller/dealer confirms rights |
| Third-party watermarks | reject unless licensed |
| Stock photo mismatch | reject — must match actual car |

### 5.4 Image review checklist (per car)

| # | Step | Owner |
|---|------|-------|
| IR-01 | Visual scan for ID/docs/plates | ops |
| IR-02 | OCR scan for phone/LINE patterns | eng (future tooling) |
| IR-03 | Match photos to make/model/color | ops |
| IR-04 | Confirm image rights on file | ops |
| IR-05 | Sign-off before import | ops |

## 6. Stale / Rollback Procedure

### 6.1 Delist individual vehicle

| Trigger | Procedure |
|---------|-----------|
| รถขายแล้ว (sold) | set `listingStatus=sold` → exclude from buyer search immediately |
| รถจองแล้ว (reserved) | set `listingStatus=reserved` → optional exclude from search |
| ราคาเปลี่ยน | update `price` + `updatedAt` before next AI session |
| รูปไม่ตรง / ข้อมูลผิด | freeze listing → fix or delist |
| Seller ถอน consent | **immediate delist** + remove from pilot batch |

### 6.2 Hide entire pilot batch

```text
# Procedure (future v6.2B.1 execution — DO NOT RUN in v6.2B planning)
1. Set pilotBatchVisible=false (or equivalent flag) on staging
2. Verify buyer search returns no pilot cars
3. Verify allowlisted tester sees fallback / no pilot cars in results
4. Log batch hide event in execution record (no PII)
```

### 6.3 Rollback import (bad data)

| Step | Action |
|------|--------|
| RB-01 | Stop import pipeline immediately |
| RB-02 | Mark all batch listings `delisted` / remove from search index |
| RB-03 | If PII leak → incident record + notify ops |
| RB-04 | Document rollback reason in execution record |
| RB-05 | Re-run go/no-go §8 before re-import |

### 6.4 Verify buyer search excludes delisted cars

| Test | Expected |
|------|----------|
| Search after sold status | delisted car **not** in results |
| Search after batch hide | **no** pilot batch cars in results |
| Compare/refine after delist | AI does not reference delisted carCards |
| Guest search | legacy path unchanged — no pilot leak |

### 6.5 Execution record after import (future v6.2B.1)

Execution record must include (no PII):

| Field | Content |
|-------|---------|
| date | import execution date |
| batch size | N cars (5–10) |
| approval phrase | confirmation phrase used |
| git commit | execution slice commit |
| staging revision | Cloud Run revision after import |
| smoke results | AI grounding smoke §7 summary |
| rollback readiness | confirmed Tier 1–3 from v6.1L |
