## 8. Likely root cause

Cloud Run **live image** บน staging อาจยังไม่มี **v5.6I.13 durable Firestore settlement wiring** ที่ branch ปัจจุบัน — แม้ env flags ถูกต้อง runtime ยังทำงานแบบ **in-memory per-instance**:

- duplicate `requestId` ไม่ dedupe ข้าม request/instance
- conflict fingerprint ไม่คืน **409**
- ไม่มี docs ใน settlement Firestore collections
