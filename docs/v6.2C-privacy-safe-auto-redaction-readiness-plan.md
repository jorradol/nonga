## 3. Redaction Modes

| Mode ID | Mode | Default | Notes |
|---------|------|---------|-------|
| RM-01 | **Default auto blur/mask** | ✅ **default** | ป้ายทะเบียน + PII ที่ detect ได้ |
| RM-02 | **Optional Nong A sticker/mascot overlay** | optional | branded overlay เช่น หัวน้องเอ — user เลือกได้ |
| RM-03 | **Crop/remove region** | fallback | ใช้เมื่อ blur/mask ไม่ปลอดภัยพอ |
| RM-04 | **Reject image** | required path | รูปมีเอกสาร/บัตร/ใบเล่ม/สัญญา/หลักฐานการเงิน หรือ redact ไม่ได้อย่างปลอดภัย |

### Mode selection rules

- **Default:** blur/mask สำหรับป้ายทะเบียนและข้อมูลส่วนตัวที่ detect ได้
- **Optional:** Nong A mascot/sticker overlay สำหรับ branded look — ไม่แทน privacy check
- **Unsafe redaction:** crop/remove หรือ reject — ห้าม publish รูปที่ยังมี PII มองเห็นได้
- **Sensitive document:** reject หรือส่ง manual review — ไม่ auto-publish

## 4. Confidence and Manual Review

| Confidence | Action | Publish/import |
|------------|--------|----------------|
| **High** | auto redaction + preview | allowed **after** user confirms preview |
| **Medium / Low** | require **manual review** | blocked until reviewer pass |
| **Unknown / sensitive document** | reject หรือ manual review only | blocked |
| **Any fail / uncertain** | show **"ต้องตรวจรูปนี้ก่อนเผยแพร่"** | blocked |

### Privacy status gate

| Status | Meaning |
|--------|---------|
| `pass` | redaction complete + preview confirmed (or manual review pass) |
| `pending_review` | medium/low confidence — รอ reviewer |
| `reject` | sensitive document หรือ redact ไม่ได้ |
| `fail` | privacy check fail |

**No publish/import until privacy status is `pass`.** ห้าม publish รูปที่ยังไม่ผ่าน privacy check.

### Manual review fallback (required)

- ต้องมี ops/reviewer path เมื่อระบบไม่มั่นใจ
- reviewer ตัดสิน pass / reject / request re-upload
- ไม่มี manual fallback → **NO-GO** สำหรับ feature rollout

## 5. Image Lifecycle

```
upload (original) → scan → redact → preview → user confirm → publish/import (redacted only)
         │                              │
         └── private/internal only       └── redacted = public/marketplace image
```

| Stage | Storage | Visibility |
|-------|---------|------------|
| **Original image** | private/internal bucket/path | seller + ops only — **never public** |
| **Redacted image** | public/marketplace path | buyer-facing listing only |
| **Preview** | transient / signed URL (future) | seller only — before confirm |
| **Logs** | audit metadata only | **no PII** — no raw image URL in logs |

### Lifecycle rules

| Rule | Requirement |
|------|-------------|
| Original remains private | ✅ required |
| Redacted is only public image | ✅ required |
| Preview before publish/import | ✅ required |
| User confirmation before use | ✅ required |
| No raw image URL in repo/docs | ✅ required |
| No PII in logs | ✅ required |
| No publish without privacy pass | ✅ required |

## 6. UX Flow

### Happy path (future implementation)

1. **User uploads car photos** — seller/dealer อัปโหลดรูปรถ
2. **น้องเอ scans for private details** — detect plate, phone, LINE, address, documents
3. **น้องเอ shows redacted preview** — blur/mask default หรือ Nong A sticker ถ้าเลือก
4. **User chooses mode** — blur/mask หรือ Nong A sticker overlay (optional)
5. **User confirms before publish** — ยืนยันว่ารูปพร้อมเผยแพร่
6. **Publish/import gate** — ผ่าน privacy status `pass` เท่านั้น

### Uncertain path

| UX message | Trigger |
|------------|---------|
| **"ต้องตรวจรูปนี้ก่อนเผยแพร่"** | medium/low confidence, sensitive region, หรือ document detected |
| Re-upload prompt | reject — ขอรูปใหม่ที่ไม่มีเอกสาร/PII |
| Manual review queue | ops reviewer ตรวจก่อน approve |

### UX principles

- แสดง preview ชัดเจน — before/after หรือ overlay preview
- ไม่ซ่อน warning — ถ้า redact ไม่มั่นใจ ต้องบอก user
- Default safe — blur/mask เปิดอยู่เสมอ; sticker เป็น optional เพิ่มเติม
