# v5.6I.4b — Admin Revenue Adjustment Modal UX Polish

## ปัญหา UX (จาก manual smoke)

- Modal สูงเกินจอ ส่วนล่าง/Footer ถูกบัง ต้อง scroll หาไม่เจอ
- ฟอร์มดูดิบ ทุก field เท่ากัน ไม่รู้ลำดับกรอก
- พื้นหลังตารางรกรบกวนสายตา
- Mobile ใช้งานยาก

## แก้ไข (frontend-only)

### Modal layout

- `max-w-3xl` (~768px), `max-h-[90vh]`, body scroll ได้ (`overflow-y-auto`)
- Header + footer แยกชัด (ไม่ scroll หาย)
- Overlay `bg-black/80 backdrop-blur-md`, ล็อก `body` scroll
- ปิดด้วย X / Escape / คลิก backdrop เมื่อไม่ submitting

### Header

- หัวข้อ «ปรับยอดค่าบริการ»
- ชื่อรถ / listing
- badge Manual / Admin only
- ข้อความ «ยังไม่มีการชำระเงินจริงผ่านระบบ»

### Summary

- Grid 3 ช่อง: ค่าบริการทั้งหมด / ชำระแล้ว / ยอดค้างชำระ (ตัวเลขใหญ่)

### Form

- ขั้นที่ 1–4 ตาม action
- Helper text เปลี่ยนตาม action
- Validation ฝั่ง client → ปุ่มยืนยัน disabled จนกรอกครบ
- Error ใต้ field + error ใน footer

### ไม่เปลี่ยน

- Settlement adjustment API / rules
- Backend routes
- Payment / invoice behavior
