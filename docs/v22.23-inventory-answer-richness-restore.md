## 3) Root cause

1. **v22.21/v22.22** replaced old UI CTAs with neutral openers, but `buildFoundIntro` in `chatSearchReplyCopy.ts` only returned found-count + soft follow-up. Helpers `summarizeOneLine` / car narratives were unused.
2. For **allowlisted signed-in** users, Cloud Run bridge may activate pilot path (`buyer.search`), and `buildBuyerSearchPilotCopy` previously returned shallow “คัดมาให้ N คัน… กดดูการ์ด” text that overwrote the orchestrator reply.
3. `resolvePilotOrchestrationHint` preferred session cards and often omitted freshly orchestrated card fields, so pilot copy could not summarize price/mileage.

`Hosting UI → signed-in bridge → Cloud Run /api/ai/chat-user-visible-orchestrate → tryOrchestrateChatReplyCore → buyerScoredMarketplaceSearch (brand/model) → runMarketplaceChatSearch → buildMarketplaceSearchIntroCopy / buildFoundIntro`

| `chatSearchReplyCopy.ts` | Rich single/multi car narratives from safe fields; optional sparing `ปังปุริเย่!` via `maybeOptionalInventoryCheer` |
