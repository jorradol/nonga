## 1. Current Status After v10.0

สถานะล่าสุดที่ยืนยันแล้ว:

- manual smoke path prep มีแล้วใน admin runtime-proof surfaces
- manual smoke execution ยัง fail-closed โดย default
- `realProviderExecutionAllowed` ยัง protected
- normal tests ยังไม่ยิง Gemini จริง
- no real API key/secret in repo
- ไม่มี buyer-facing/public route/real lead sending/deploy/production activation

## 2. Preconditions Before Any Future Manual Smoke Execution

ต้องผ่านครบทุกข้อก่อนเริ่มทดสอบจริงในอนาคต:

- owner explicit approval เป็นลายลักษณ์อักษรและระบุช่วงเวลาชัดเจน
- ใช้เฉพาะ admin-only/manual proof boundary เท่านั้น
- secret อยู่ใน environment เท่านั้น (เช่น `GEMINI_API_KEY`)
- secret env-only policy must be enforced
- ห้ามใส่ API key/secret จริงใน repo
- ต้องมี kill switch rollback พร้อมใช้งานทันที
- ต้องตั้ง quota/cost cap ต่ำมากและตรวจสอบได้
- ต้องยืนยัน log redaction พร้อมใช้งาน
- deterministic fallback ต้องพร้อมและตรวจสอบได้
- ต้องไม่มี buyer-facing AI
- ต้องไม่มี public route
- ต้องไม่มี real lead sending
- no real lead sending
- ต้องไม่มี production/deploy activity
- no deploy

## 3. Manual Smoke Boundary Rules (Operator/Admin Only)

- จำกัดเฉพาะ operator/admin เท่านั้น
- ห้ามรันจาก buyer/public path
- ห้ามใช้ข้อมูลลูกค้าจริงทุกชนิด
- ห้ามใช้เบอร์โทรจริง, VIN จริง, ทะเบียนจริง, หรือ PII จริง
- ใช้เฉพาะ safe test prompt ที่ไม่โยงตัวบุคคล
- หลังทดสอบต้องตรวจว่า logs/output ไม่มี prompt ดิบ, secret, หรือ PII หลุด

## 5. Rollback / Stop Instructions

ถ้าพบความเสี่ยงหรือพฤติกรรมผิดปกติ:

1. ปิด manual smoke execution flag ทันที
2. เปิด kill switch ทันที
3. กลับ deterministic fallback mode
4. หยุดทดสอบทันทีเมื่อพบ network/cost/log anomaly
5. ถ้าสงสัย secret leak ให้ลบ/rotate secret ทันที
6. บันทึก incident และขอ owner re-approval ก่อนเริ่มใหม่
