## 4) Root cause

Inventory availability replies are **deterministic templates**, not an LLM regression and not caused by the chat-image fix.

Path:

1. `tryOrchestrateChatReply` → `tryBuyerScoredMarketplaceReply` / `runMarketplaceChatSearch`
2. Intro text from `chatSearchReplyCopy.buildFoundIntro` (and scored CTA lines in `buyerScoredMarketplaceSearch`)

Hardcoded UI instruction lines were appended after every hit:

- “น้องเอจัดการ์ดไว้ด้านล่างให้แล้ว”
- “กด 'ดูรายละเอียดในแชท' …”
- routine “ปังปุริเย่!” on single-match intros

That made answers sound like system/UI instructions instead of a Thai sales assistant.

## 5) Fix

| Path | Change |
|------|--------|
| `chatSearchReplyCopy.ts` | Natural singular/multi/no-match openers; soft buyer follow-up instead of UI CTAs; no routine cheer |
| `buyerScoredMarketplaceSearch.ts` | Brand/model availability lookups use natural inventory intro; scored soft follow-ups replace UI CTAs |
| Card display / images | unchanged |

## 6) Before / after examples

### Honda CRV 2019 (1 match)

**Before:**  
`ค้นเจอ 1 คันที่ตรงสเปกครับ Honda CRV ปี 2019` + UI CTA + `ปังปุริเย่!`

**After:**  
`มีครับลุง — Honda CRV ปี 2019 ตอนนี้มี 1 คัน เดี๋ยวน้องเอเปิดการ์ดให้ดูครับ` + soft help follow-up (no UI CTA / no cheer)

### Toyota Camry 2019 (2 matches)

**Before:**  
`เจอ 2 คันที่ตรงเงื่อนไข ในตลาด Nong A ครับ` + UI CTA

**After:**  
`มีครับลุง เจอ Toyota Camry อยู่ 2 คันในตลาดตอนนี้ เดี๋ยวน้องเอแสดงการ์ดให้เทียบกันครับ` + compare/help invite

### No match

**Before:** system “ค้นจากรายการจริงเท่านั้น…”

`ยังไม่เจอ … ในตลาดตอนนี้ครับลุง ถ้ารับรุ่นใกล้เคียง น้องเอช่วยหาปีใกล้กันหรืองบใกล้กันให้ได้ครับ`
