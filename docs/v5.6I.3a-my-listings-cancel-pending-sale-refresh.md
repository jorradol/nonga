# v5.6I.3a — Auto Refresh My Listings After Cancel Pending Sale

## ปัญหา

หลัง owner กด “ยกเลิกดีล / กลับไปขายต่อ” สำเร็จ:

- Backend ถูกต้อง: รถกลับเข้าตลาด, revenue preview ไม่มี `pending_sale` แล้ว
- แต่หน้า My Listings ไม่อัปเดตทันที — ต้อง refresh browser เอง

## Root cause

1. **My Listings list** — หลัง cancel ใช้แค่ `setMyCars` patch จาก response แต่ไม่ `refetch` จาก `GET /api/my/listings` จึงอาจค้าง state เก่า (badge `pending_sale`, ปุ่ม cancel block)
2. **MyRevenueStatementSection** — โหลด `/api/my/revenue/preview` ครั้งเดียวตอน mount ไม่มี trigger refetch หลัง cancel

## วิธีแก้ (frontend only)

ใน `MyListingsView.handleCancelPendingSale` หลัง API success:

1. `await load()` — refetch listings จาก backend
2. `setRevenueRefreshKey(k => k + 1)` — trigger revenue section refetch
3. `await fetchCars()` — sync marketplace store (เดิมมีอยู่แล้ว)

`MyRevenueStatementSection` รับ prop `refreshKey` และ refetch เมื่อ key เปลี่ยน

## ข้อห้ามรอบนี้

- ไม่เปลี่ยน backend cancel/relist policy
- ไม่เปิด payment / invoice / settlement write
- ไม่แตะ rules / env / Gemini
