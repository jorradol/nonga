## 4) Runtime repository selection

| Question | Finding |

| Multi-instance memory | **Inconsistent** — each Cloud Run instance has its own Map; v22.47 one-instance pin was required **because of memory**, not Firestore |
| Accidental cross-instance drift | Possible only while on memory with scale > 1 |

**This task did not set `NONGA_LEAD_DATA_BACKEND` and did not switch staging.**
