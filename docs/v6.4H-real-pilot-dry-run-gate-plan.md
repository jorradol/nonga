## 3. Real Pilot Gate Checklist

ก่อนเปิด real Gemini pilot ในอนาคต (post v6.4H) ต้องผ่าน **ทุก gate** — approval แยกทุกขั้น:

| # | Gate Name | Required Evidence | Pass Criteria | Explicit Blocker | Owner / Approval | Rollback Note |
|---|-----------|-------------------|---------------|------------------|------------------|---------------|
| G-01 | **Owner approval gate** | Signed owner approval record (out-of-band) | Owner explicitly approves staging real pilot | No approval → **STOP** | Owner / superadmin | Revert to OFF immediately |
| G-02 | **Staging-only scope gate** | `environment === "staging"` verified | Production target forbidden | `production` env → **HARD BLOCK** | Owner + ops | No production deploy |
| G-03 | **Allowlist gate** | Allowlisted tester UIDs configured (masked in audit) | `allowlistConfigured === true` | Missing allowlist → **BLOCK** | Superadmin | Remove allowlist → pilot OFF |
| G-04 | **Cost cap gate** | Daily + per-surface + per-user caps set | All caps non-null | `capsConfigured === false` → **BLOCK** | Superadmin | Cap exceeded → deterministic fallback |
| G-05 | **Kill switch gate** | Kill switch tested manual OFF | `killSwitch.active === false` | Kill switch ON → **IMMEDIATE STOP** | Superadmin | Kill switch → provider DISABLED |
| G-06 | **Secret Manager path approval gate** | SM resource `gemini-api-key:latest` approved path documented | Path approved — no key in repo | Unapproved path → **BLOCK** | Owner + ops | Revoke SM access |
| G-07 | **No raw prompt / PII logging gate** | Audit schema uses maskedActorId only | No full UID / raw prompt / secret in logs | PII in logs → **STOP** | Engineering + owner | Purge logs + disable |
| G-08 | **Redaction verification gate** | Redaction test pass on synthetic fixtures | `redactPiiForSalesBrainLog` / output guard verified | Redaction fail → **BLOCK** | Engineering | Fallback only |
| G-09 | **Fallback behavior gate** | Deterministic fallback on guard fail / cap / error | `AI_OUTPUT_GUARD_POLICY.onFail: deterministic` | Non-deterministic fallback → **BLOCK** | Engineering | Force deterministic route |
| G-10 | **Mock-vs-real comparison gate** | v6.4D shadow harness matrix PASS baseline | No regression vs SH-01..SH-06 | Harness fail → **BLOCK** | Engineering | Stay on mock only |
| G-11 | **Rate limit / quota gate** | Per-user/session + daily caps enforced in plan | Quota model documented and configured | Quota unset → **BLOCK** | Superadmin | Cap → fallback |
| G-12 | **Error handling gate** | Provider errors map to fallback — no user-visible leak | Errors redacted, no secret in error payload | Secret/PII in error → **STOP** | Engineering | Disable provider |
| G-13 | **Monitoring gate** | Audit events: requestId, guardResult, fallbackReason | Monitoring plan defined — redacted fields only | No audit plan → **BLOCK** | Ops + engineering | Disable + review logs |
| G-14 | **Rollback gate** | Rollback steps documented (kill switch + revert) | Rollback tested in dry-run checklist | No rollback plan → **BLOCK** | Owner + ops | Execute rollback immediately |
| G-15 | **Separate deploy approval gate** | Deploy approval record separate from pilot approval | No deploy without explicit deploy approval | Deploy without approval → **STOP** | Owner | Revert deploy |
| G-16 | **Post-pilot review gate** | Review checklist after pilot window | Owner sign-off on outcomes / incidents | Unreviewed pilot → no extension | Owner | End pilot window |

### Static authority references (v6.4B/E/F)


## 4. Pilot Dry-Run Sequence

**Plan only** — v6.4H ไม่ execute sequence นี้จริง เป็น checklist สำหรับอนาคต:

| Step | Action | Stop If |
|------|--------|---------|
| 1 | Confirm branch/HEAD clean, working tree clean | Dirty tree or wrong branch |
| 2 | Re-run `test:v64b`, `test:v64d`, `test:v64f`, `test:v64g`, `test:v64h` | Any test FAIL |
| 3 | Confirm staging-only target (`environment === "staging"`) | Production detected |
| 4 | Confirm allowlist configured (masked UIDs) | Allowlist missing |
| 5 | Confirm cost caps set (daily + per-surface + per-user) | Caps null |
| 6 | Confirm kill switch OFF and tested | Kill switch ON |
| 7 | Confirm redaction verified on synthetic fixtures | Redaction fail |
| 8 | Confirm Secret Manager path approved (`gemini-api-key:latest`) | Path not approved |
| 9 | Prepare deployment approval request (separate document) | — |
| 10 | **STOP** — request explicit owner approval before any deploy or real call | Proceed without approval |

**Critical rule:** Step 10 is mandatory hard stop. No step after 10 may execute in v6.4H.
