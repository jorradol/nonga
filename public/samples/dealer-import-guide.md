เอกสารนี้อธิบายรูปแบบไฟล์ที่ระบบ **Inventory Import** รองรับ เพื่อให้เต็นท์รถเตรียมข้อมูลและอัปโหลดได้ถูกต้อง

| รายการ | รายละเอียด |

## คอลัมน์ที่จำเป็น (ต้องมี)

ระบบต้อง map คอลัมน์เหล่านี้ก่อนนำเข้าได้ (ชื่อหัวคอลัมน์ยืดหยุ่น — ระบบจับคู่อัตโนมัติ):

| ฟิลด์ระบบ | ชื่อหัวคอลัมน์ที่แนะนำ | รูปแบบที่รองรับ |
|-----------|------------------------|----------------|
| **brand** | แบรนด์, ยี่ห้อ, brand | ข้อความ เช่น `Suzuki`, `Toyota` |
| **model** | รุ่น, model | ข้อความ เช่น `Ertiga`, `Fortuner` |
| **year** | ปีรถ, ปี, year | ตัวเลข ค.ศ. เช่น `2022` (1980–ปีถัดไป) |
| **price** | ราคา, ราคาขาย, price | ตัวเลขบาท **ไม่มีสัญลักษณ์** เช่น `589000` หรือ `589,000` (ระบบลบ comma) |

## รูปภาพ (imageUrls)

### รูปแบบ URL

- ต้องขึ้นต้นด้วย `http://` หรือ `https://`
- ลิงก์ตรงไปยังไฟล์รูป (jpg, png, webp) หรือ CDN ที่อนุญาตให้ดาวน์โหลดได้
- **ไม่แนะนำ** ลิงก์ Google Drive / Facebook album ที่ต้องล็อกอิน (มักดาวน์โหลดไม่สำเร็จ)

### หลายรูปต่อ 1 คัน

คั่น URL ด้วย **เครื่องหมายจุลภาค (,)** หรือ **ขึ้นบรรทัดใหม่** หรือ `|` หรือ `;`

ตัวอย่างในเซลล์เดียว:

```text
https://example.com/car1.jpg,https://example.com/car2.jpg
```

หรือ

```text
https://example.com/car1.jpg
https://example.com/car2.jpg
```

### พฤติกรรมระบบหลังนำเข้า

1. ระบบ **ดาวน์โหลดรูปจาก URL อัตโนมัติ** (รวม Google Drive ที่เปิดสิทธิ์ดูได้) ผ่าน image storage repository
2. เมื่อ `NONGA_IMAGE_BACKEND=firebase-storage` รูปถูกเก็บใน Firebase Storage และ marketplace/detail/chat ใช้ URL ที่ทนทานข้าม Cloud Run instance
3. เมื่อ `NONGA_IMAGE_BACKEND=file` รูปอยู่ที่ `data/listing-images/` และเสิร์ฟที่ `/storage/listings/{carId}/...` — **ไม่ทนทานบน Cloud Run** (เหมาะกับ local เท่านั้น)
4. **ไม่ใช้ hotlink** แหล่งภายนอกเป็นรูปหลักหลังนำเข้าสำเร็จ
5. ถ้าดาวน์โหลดบางรูปไม่สำเร็จ → **คำเตือนเท่านั้น** แถวยังนำเข้าได้ และใช้ placeholder เมื่อไม่มีรูปที่เก็บสำเร็จ
6. ถ้าไม่มี URL รูปเลย → คำเตือน + ใช้รูป placeholder

สูงสุด **12 รูป** ต่อคัน

### รูปจากผู้ขายและการยินยอม (สำคัญ)

- รูปที่ผู้ขายส่งสามารถแสดงได้ตามที่ส่งมา หากผู้ขายยืนยันว่ามีสิทธิ์เผยแพร่และยินยอมให้ใช้เพื่อประกาศขาย
- **ไม่บังคับ** เบลอ/ครอปป้ายทะเบียนในรูปก่อนนำเข้า — แม้ในภาพอาจเห็นป้ายได้
- กด **Confirm Import** ถือเป็นการยืนยันสิทธิ์เผยแพร่ + ยินยอมแสดงรูปเพื่อประกาศขาย
- ระบบยัง **ไม่เปิดเผย** ทะเบียนเต็ม / VIN / เบอร์โทร / ที่อยู่ในช่องข้อความและ API สาธารณะที่ระบบควบคุม
- ไม่มีระบบเบลอป้ายอัตโนมัติในรอบนี้

## ขั้นตอนนำเข้าในระบบ

1. Admin → **นำเข้าคลังรถ**
2. อัปโหลด CSV/XLSX
3. **Preview** → ตรวจหัวคอลัมน์
4. **Column Mapping** → จับคู่ฟิลด์ (หรือกด Auto Mapping)
5. **Clean & Validate** → แก้ error ก่อนนำเข้า
6. **Confirm Import** → รอดาวน์โหลดรูป
7. ตรวจผล **สถานะดาวน์โหลดรูปภาพ** แล้วไป Marketplace
